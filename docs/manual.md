# Зеленогорье — руководство

Как пользоваться платформой: игроку, мастеру, общему экрану и тому, кто держит сервер.
Установка прода на Mac mini здесь не повторяется — она в [ops.md](ops.md). Что сделать до, во время и после игры — [session-checklist.md](session-checklist.md).

## 1. Что это

Платформа для сессий НРИ «Зеленогорье». Три экрана, один адрес:

| Экран | Где открывают | Что там |
|---|---|---|
| Игрок (`/player`) | телефон, лучше как установленное приложение (PWA) | карточка персонажа, броски d10/d20, общая лента, дневник |
| Мастер (`/gm`) | ноутбук | всё о персонажах, противник, лента с пояснениями, запросы, заметки, сцены, участники |
| Общий экран (`/table`) | ТВ или ноутбук, трансляция в Discord | картинка и текст сцены, последние 5 публичных бросков, признаки перегрузки |

Главное правило: мастерское к игроку и на стол не уходит. Скрытые черты, заметки мастера, перегрузка, противник, подсказки ИИ видит только мастер. Игрок получает ровно то, что мастер раскрыл.

ИИ работает только на сервере и только советует мастеру:
- **Jev** (TypeSafe) — быстрые суждения: не выдаёт ли текст скрытую черту, похоже ли действие на зелёную магию и т. п.;
- **Claude** — пишет черновики сводок персонажа.

Ничего в игре ИИ сам не меняет и игроку не отвечает.

## 2. Быстрый старт (разработка, на Mac)

Нужен Node 24 и файл `~/.config/zelenogorye/.env.development` (права 600).

```
npm install
npm run setup:dev      # комната, имя мастера, пароль (от 8 символов). Запишите код комнаты.
npm run seed:dev       # тестовые персонажи и частично открытые карты (по желанию)
npm run dev            # сервер 127.0.0.1:3001 + Vite на 5173
```

Vite печатает два адреса: `Local` — для самого Mac, `Network` — для телефона в той же Wi-Fi.

Вход мастера: открыть адрес → код комнаты → своё имя → пароль.

Тестовые входы dev-базы (код комнаты, PIN) — в [dev-data.md](dev-data.md).

Один браузер помнит одну сессию на адрес. Чтобы на одном Mac одновременно сидеть мастером, игроком и столом, открывайте их по разным адресам: `localhost:5173`, `127.0.0.1:5173`, `<IP мака>:5173`. Другой вариант — разные браузеры или приватное окно.

Начать с чистой dev-базы: остановить `npm run dev`, удалить `data/dev.sqlite*` и `data/media`, затем `npm run setup:dev` и `npm run seed:dev`.

## 3. Вход и участники

### Пригласить игрока или общий экран

Мастер → «Участники» → блок «Пригласить»: «Имя», «Роль» («Игрок» или «Общий экран») → «Создать ссылку». Появится ссылка с кнопками «Копировать» и «Отправить».

- Ссылка одноразовая и действует 7 дней.
- Её можно спокойно слать в Telegram, Discord, iMessage: превью мессенджера ссылку не тратит. Она гасится только нажатием кнопки входа.
- Из терминала: `npm run invite:dev -- --name "Имя"` (для стола добавить `--role table`).

### Первый вход игрока

Игрок открывает ссылку → «<Комната>: приглашение для <Имя> (Игрок)» → придумывает PIN из 6 цифр, вводит его ещё раз → «Войти как <Имя>».

Дальше браузер помнит вход 180 дней.

Выйти — «⋯» справа в шапке → «Выйти…» → «Выйти». Перед выходом спрашивается подтверждение: вернуться можно только с PIN (мастеру — с паролем), а случайно задеть кнопку на телефоне легко.

### Посмотреть без входа (только в разработке)

На dev-сервере и QA-хосте на странице входа под «Дальше» — «Посмотреть без входа»: «Мастер», «Игрок», «Стол». Это отдельная «Демо-комната» с тестовыми персонажами, сценой и частично открытыми картами; рабочая комната её не видит и наоборот. ИИ там выключен. Сменить роль — «⋯» → «Выйти…» в шапке и подтвердить (у стола — «Выйти»). В проде этой кнопки нет.

### Вход с другого устройства

Любое устройство, адрес сайта → «Код комнаты» (6 символов) → «Дальше» → выбрать себя в списке → PIN (мастер — пароль) → «Войти».

- В списке только те, кто уже задал PIN или пароль. Общего экрана там нет: он входит только по ссылке.
- 5 неверных PIN подряд блокируют вход этому участнику на 15 минут: «Слишком много попыток. Подождите и попробуйте снова.». Других участников это не задевает.

### Забыл PIN, потерял телефон, стол отключился

Мастер → «Участники» → «Новая ссылка» у нужного участника. Игрок входит по ней и задаёт новый PIN; старый перестаёт подходить.

Статусы в списке участников:
- «ждёт входа по ссылке»;
- «вошёл, PIN задан»;
- «вошёл, выдана новая ссылка»;
- «подключён» (стол);
- «ссылка истекла».

Забыл пароль мастера:
- dev: `npm run setup:dev -- --reset-gm-password`;
- прод: `ZG_ENV_FILE=~/.config/zelenogorye/.env node ~/srv/zelenogorye/current/server/dist/setup.mjs --reset-gm-password`.

Старые сессии мастера при этом закрываются.

### Установить как приложение (PWA)

Работает только по HTTPS, то есть на проде, по домену.
- iOS: Safari → «Поделиться» → «На экран Домой».
- Android: Chrome → меню → «Установить приложение».

Приложение открывается без адресной строки, экран во время игры не гаснет (на iOS — с версии 18.4).

На iOS установленное приложение не видит вход, сделанный в Safari. Если оно просит войти — код комнаты и PIN.

### Уведомления

Колокольчик справа вверху включает push-уведомления на этом устройстве (понадобится разрешение браузера). Приходят, только когда приложение не на экране:
- мастер решил по твоему предложению на карте («Идём в …» или «Предложение отклонено»);
- мастер ответил на запись в дневнике (текст ответа — в приложении, в уведомлении его нет);
- в открытом городе появился слух или задание;
- пришло письмо твоему персонажу («От …»);
- опубликована новая глава летописи;
- мастер разобрал твоё дело между сессиями («Итог дела»);
- мастер принял или отклонил твой сказ;
- мастер предложил даты («Когда играем?»), назначил или отменил игру; напоминания за сутки и за час;
- «Игра начинается» — мастер зовёт за стол.

Нажатие по уведомлению открывает нужную вкладку. На иконке установленного приложения — число вкладок с непрочитанным. На iOS уведомления работают только в установленном приложении (см. выше); в Safari колокольчик подскажет это. Если колокольчика нет — на сервере уведомления не настроены (раздел 9). Выключить — тем же колокольчиком.

### Индикатор связи

Справа вверху на каждом экране:
- «На связи»;
- «Переподключение…»;
- «Нет связи»;
- «Нужно войти».

После обрыва (лифт, метро, свернул приложение) всё догоняется само: пропущенные броски и правки карточки приходят без перезагрузки страницы. Когда на сервере выходит новая версия, страница один раз перезагружается сама.

## 4. Игроку

Весь экран игрока оформлен в теме его персонажа (цвета, шрифты, узор, рамки — как у карточки; тему может сменить мастер); пока персонажа нет — в оформлении «Зеленогорье». Кнопка в шапке «Авто / День / Ночь»: «Авто» — тема как задумана, «День» и «Ночь» — её светлый и тёмный вариант.

**Оболочка.** Кроме цветов, у темы своя «оболочка» — устройство экрана: у сказочных тем раскрытая книга с закладками-лентами, у летописи — пергамент с буквицей и ярлыками на полях, у аниме — страница манги с главами, у киберпанка — неоновый интерфейс, у «Терминала» — экран наручного прибора, у хоррора — папка дела с полароидом, у «Пикселя» — 8-битная игра, у «Паспорта» — бланк со штампом и другие (всего 16, список — `docs/design-shells.md`). Кнопки, поля и разделы те же — меняется их вид и место: на компьютере разделы могут быть сверху, слева или справа. Лоток кубика тоже в стиле оболочки: блюдо, сургучная печать, радар, циферблат, полароид. «Оформление» (выбор темы на своём устройстве) меняет и оболочку.

Внизу экрана панель вкладок: «Броски», «Карточка», «Фигурка», «Дневник», «Карта». Между ними можно листать пальцем влево-вправо; у каждой вкладки своя прокрутка. Повторное нажатие на открытую вкладку возвращает к её началу. Открытая вкладка запоминается. Красная точка у «Карточки» значит, что мастер что-то раскрыл или поменял; у «Дневника» — что мастер ответил. Точка исчезает, когда вкладка на экране.

**На компьютере** (окно шире ~1100 пикселей и мышь) экран игрока — «разворот»: слева разделы закладками (с номерами), в середине открытый раздел на всю ширину, справа всегда лоток бросков и «Лента». На «Бросках» в середине — «Лента» крупно, справа — лоток; на «Карте» правая колонка прячется, карта на всю ширину. Клавиши 1–6 открывают разделы (Броски, Карточка, Фигурка, Дневник, Летопись, Карта). Бросок — смахнуть мышью по лотку или «Бросить». Карточка на широком экране — в две колонки, у фигурки превью слева. Листы («Новая запись», «Оформление», заметка на карте) открываются панелью справа; закрыть — крестик, Esc или щелчок мимо.

**Что видит мастер.** Пока приложение открыто, мастер видит, в сети ли ты (или приложение свёрнуто), какая вкладка открыта и что примерно на ней происходит: бросаешь кубик, выбираешь оформление, правишь вещь, какая часть фигурки открыта, пишешь запись в дневнике, какая карта, место или раздел города открыты. Набранный текст мастер не видит; про дневник — только «пишет запись», без вида записи: запись «Только мне» этим не выдаётся.

### Броски

Сверху лоток с кубиком.
1. Выбрать кубик: «d10» или «d20».
2. Выбрать, кто увидит: «Всем» или «Мне и мастеру». Второй вариант не видят другие игроки и стол.
3. По желанию написать подпись, например «прыгаю через ручей». «Ввод» (на клавиатуре телефона — «Перейти») сразу бросает и закрывает клавиатуру.
4. Нажать «Бросить d20» (или d10) — или смахнуть пальцем по лотку: кубик полетит в сторону смахивания, быстрое смахивание — сильнее.

Число выбрасывает сервер, не телефон: кубик катится по-настоящему и ложится нужной гранью вверх. Под лотком появляются число и исход со значком (лавровый венок — крит, череп с трещиной — критический урон, клевер — бросок удачи…; значок только помогает глазу, исход всегда написан словами); на Android телефон коротко вибрирует на ударах; на iPhone (iOS 18 и новее) — лёгкий отклик при нажатии «Бросить», на ударах и посадке — как получится (iOS разрешает отклик только сразу после касания). Без 3D (старый телефон, «Уменьшить движение» в системе) — просто число.

Ниже — «Лента» со всеми видимыми тебе бросками; новые строки въезжают сверху. Свой бросок появляется в ленте, когда кубик лёг. «Все» / «Мои» — показать все броски или только свои (выбор запоминается). Если мастер поправил бросок, в ленте будет «· исправлено мастером».

Если связь пропала: «Нет ответа от сервера.» и кнопки «Повторить» / «Отмена». «Повторить» безопасно: второго броска не будет, даже если первый на самом деле дошёл.

Что значат результаты — в разделе 6.

### Карточка

Карточка оформлена как в рандомизаторе: у каждой вселенной и жанра свой вид (Сайлент Хилл — «Туман», Ведьмак — «Медальон» и т. д.), шрифты, узор, орнамент под именем. Кнопка «Оформление · …» над карточкой открывает лист с образцами тем: можно выбрать любую для себя (только на этом устройстве, мастер и стол видят как обычно) или вернуть «Как у персонажа». Выбор применяется сразу. Портрет (если мастер его загрузил в рандомизаторе) поворачивается по нажатию, а нажатие по карточке пускает частицы темы. С включённым «Уменьшить движение» в системе частиц нет, портрет только мигает. Шрифты тем и оболочек входят в приложение и подгружаются при первом показе темы (по нескольку десятков килобайт), дальше работают и без сети; пока шрифт не пришёл, карточка показывается запасными.

Здесь то, что мастер уже раскрыл:
- портрет, имя, откуда родом, уровень силы (словом, если мастер разрешил; числа игрок не видит);
- «Ремесло в Зеленогорье»;
- раскрытые черты: категория, название, суть, открытые ступени, иногда цена;
- «Что-то происходит» — подсказки к тому, что ещё не раскрыто, без названий;
- «Снаряжение» — своё: «Добавить» и «Изменить» открывают лист снизу («Что это», «Подробности»), «Удалить» — двумя нажатиями. Мастер видит изменения сразу;
- «Состояния» (раны, проклятия, усталость) и «Связи» (кто кому кем приходится) — их ведёт мастер;
- «Вступление» и «Переход» — тексты от мастера, если он их опубликовал (идут сразу под шапкой).

Пока ничего не раскрыто: «Мир пока присматривается к тебе.». Если персонажа ещё нет: «Мастер ещё не выдал тебе персонажа.».

Карточка обновляется сама за 1–2 секунды после действий мастера.

### Фигурка

Пиксель-арт фигурка персонажа — её увидят мастер, стол и другие игроки: на карте и в бою на общем экране.
- Сверху превью: стрелки «‹» «›» поворачивают фигурку, «Стоит» / «Идёт» / «Удар» / «Ранен» — показать анимацию.
- Ниже части: «Тело» (телосложение и кожа), «Лицо», «Волосы», «Борода», «Одежда», «Броня», «Плащ», «Ноги», «Обувь», «На голове», «Оружие». Нажать часть → выбрать вариант из миниатюр → цвет кружком. «Нет» убирает необязательную деталь.
- Оружие задаёт удар в бою: меч, сабля, булава, секира, кинжал — удар; копьё — выпад; лук — выстрел; посох — заклинание.
- «Случайно» — собрать случайную фигурку. «Сохранить фигурку» — сохранить (до этого изменения видны только тебе).

Пока мастер не выдал персонажа, собрать фигурку нельзя. Картинки деталей загружаются при первом открытии вкладки и потом работают без сети. «Авторы графики» внизу — художники открытого набора LPC, из которого собраны фигурки, автор моделей 3D-карты и авторы значков (game-icons.net).

### Дневник

Записи идут карточками, новые сверху. «Новая запись» открывает лист снизу (он поднимается над клавиатурой). Выбрать вид записи и написать текст:

| Вид | Кто видит | Зачем |
|---|---|---|
| «Дневник» | ты и мастер | что случилось, что почувствовал, о чём догадываешься |
| «Вопрос мастеру» | ты и мастер, у мастера — сразу как запрос | спросить мастера во время игры, не перебивая |
| «Только мне» | только ты | личное. Мастер не видит её никак, ИИ её не читает |

→ «Сохранить» (у вопроса — «Отправить мастеру»). Неотправленный текст хранится на телефоне: если закрыть лист или приложение, или пропала связь, он дождётся — кнопка тогда называется «Черновик». Ответ мастера появляется в карточке записи («Мастер: …»), у вопроса пометка меняется на «есть ответ». Лист закрывается свайпом вниз, тапом по затемнению или «Отмена».

У каждой записи — «Изменить» (тот же лист) и «Удалить» (двумя нажатиями: «Точно удалить?»). При правке можно поменять и вид записи. Если сделать запись «Только мне», мастер перестаёт её видеть сразу, а всё, что ИИ успел о ней сказать мастеру, стирается. Вопрос, на который мастер уже ответил, остаётся вопросом: поправить можно только текст.

**Следующая игра.** Когда мастер предложил даты, сверху «Дневника» появляется «Когда играем?» — отметь у каждой «Буду», «Может быть» или «Не смогу» (видно, кто как ответил). Когда дата назначена — «Следующая игра»: дата, обратный отсчёт («через 3 дня», «завтра в 19:00»), те же три кнопки явки и «В календарь» (файл для календаря телефона). Напоминания приходят за сутки и за час. Прошедшая игра из карточки исчезает сама.

**До следующей сессии.** Карточка сверху «Дневника»: чем твой персонаж займётся до следующей игры — тренировка, ремесло, разузнать, навестить, подработать, отдых или своё, плюс пара слов как именно. Мастер это видит; поменять можно, пока мастер не разобрал. На следующей игре (или раньше) мастер пишет итог — он появится в карточке, придёт уведомление. После начала новой сессии можно выбрать новое дело, прошлое с итогом остаётся видно, пока нет нового.

**Письма.** Сверху «Дневника» появляются письма твоему персонажу от жителей мира — когда мастер их отправит. Непрочитанное письмо выделено рамкой; нажми, чтобы прочитать (откроется листом). «Ответить» — один ответ, его можно переписать; ответ видит мастер. О новом письме приходит уведомление (если включены), на вкладке — значок. Писем нет — раздела нет.

### Летопись

Главы кампании, которые публикует мастер после сессий: что случилось, кто что сделал, чем кончилось. Новые сверху; нажми, чтобы прочитать целиком. Под главой может быть викторина «Что ты помнишь?» — 3 вопроса по 3 варианта. Ответить можно один раз, разом на все; потом видно, что верно, и счёт «N из 3» — его видит и мастер. О новой главе приходит уведомление, на вкладке — значок.

### Карта

Вкладка «Карта» — то, что мастер уже открыл; остальное под туманом. По умолчанию — пергаментная карта, «3D (проба)» — объёмная, как в Mount & Blade (горы, леса, города и деревни из домов). Отряд — фигурки персонажей игроков (без фигурок — зелёный значок), двигается вживую. Фигурки на подставках — персонажи (зелёная, твой — на золотой) и противники (красная), которых мастер поставил на карту; когда мастер их передвигает, они идут к новой точке.

**На телефоне карта — на весь экран:** шапка прячется, название карты, «‹ Мир», кнопки земель, «3D (проба)» и «+ Заметка» — поверх карты, справа колонка: поиск, компас (в 3D), «К отряду», «Вся карта», внизу справа — мини-карта. Масштаб — двумя пальцами. Телефон можно повернуть: в альбомной ориентации вкладки уходят в узкую колонку слева (значки), карточка места — панелью справа, экран города — в две колонки. Удобнее всего в установленном приложении (PWA, «На экран Домой»): там не мешают панели Safari.

**Как двигать:** один палец (или мышь) — тащить землю; два пальца — приблизить, отдалить и повернуть; на компьютере — колесо к курсору, правая кнопка — повернуть и наклонить, клавиши W A S D (или стрелки) — ехать, Q / E — поворот, + / − — масштаб, пробел — к отряду, N — на север, Home — вся карта. Чем ближе, тем ниже камера: видно горизонт. Издали подписи деревень прячутся, чтобы не мешать.

**Кнопки поверх карты:** «Найти» — поиск места по названию (камера летит к нему); справа — «+» / «−», компас (показывает север, нажать — повернуть на север), знамя — «К отряду», рамка — «Вся карта»; в углу — мини-карта с рамкой того, что сейчас на экране (нажать — перелететь; «×» прячет её). Наведение мышью на табличку — вид места и подзаголовок.

**Города.** Нажать на табличку места (или выбрать его в поиске) — камера летит к нему, открывается карточка: знамя фракции, вид места, правитель, фракция, население, описание. Войти в город можно, только когда отряд рядом (у его стен); издали в карточке — «Войти можно, когда отряд будет рядом», а что внутри (места, слухи, кто здесь) не видно вовсе. Отряд ушёл — экран города закрывается. «Войти в город» — экран города как в Mount & Blade: слева меню — «Обзор», места в городе (замок, таверна, рынок… — у каждого вида свой значок), «Слухи и задания» (слух — значок разговора, задание — свиток), «Кто здесь»; справа — выбранное: описание, кто там (имя, фигурка, роль). Фон — картинка города, если мастер её добавил (сначала проявляется размытый набросок, затем сама картинка); иначе за экраном виден сам город — камера медленно кружит над ним. «Покинуть город» (или Esc, «×» на телефоне) — обратно к карте. Слухи появляются по одному, когда мастер их откроет (иногда — в назначенный им час). У слуха видно, кто первым его услышал — тот, кто первым открыл «Слухи и задания», когда слух уже был. Внизу раздела — «Рассказать сказ»: слух или байка от твоего персонажа (до 1000 знаков) уходит мастеру; примет — её увидят все с подписью «рассказал(а) …», нет — придёт уведомление, что не принята. Свои сказы, пока их не рассмотрели, видны только тебе с пометкой «ждёт мастера»; не больше трёх на город. Всё, что мастер скрыл, не видно и не угадывается.

**Путь и время в дороге.** Наведение на табличку показывает, сколько идти от отряда («≈ 3 дня пешком»). В карточке места — «От отряда: ≈ 3 дня пешком · ≈ 2 дня верхом», «по дорогам» или «часть пути — без дороги», а сам путь — золотой линией на карте (только по открытым дорогам; без дороги идти дольше). «Предложить мастеру идти сюда» — мастер увидит предложение; у тебя — «Предложено мастеру — ждём ответа» и «Отменить». Решение мастера приходит уведомлением. Одно предложение на карту: новое заменяет прежнее. Другие игроки твоих предложений не видят.

**Отряд в пути.** Отряд на карте — фигурки персонажей игроков (у кого собрана фигурка во вкладке «Фигурка»; без фигурок — зелёное знамя). Когда мастер ведёт отряд, фигурки идут по дорогам несколько секунд (у всех, кто смотрит на карту) и встают в новом месте.

**Отряд разделился.** Мастер может разделить отряд: тогда на карте несколько отрядов, под каждым — имена персонажей, твой — в золотой рамке (и на мини-карте). Каждый ходит сам по себе, может быть и на другой карте. «К отряду», пробел, путь и дни в карточке места, «Предложить мастеру идти сюда» и вход в город — от твоего отряда: войти в город можно, только когда рядом твой отряд. Твоё предложение ведёт твой отряд. Если твоего отряда на этой карте нет или мастер его спрятал — «Где сейчас твой отряд, на этой карте не видно». Спрятанный мастером отряд не виден никому из игроков.

**Переход между картами.** На карте мира — кнопки земель со своей картой («Раздолье ›»); нажатие внутри такой земли — кнопка «Раздолье: открыть карту ›». Камера наезжает на землю, и открывается её карта; «‹ Мир» — обратно (карта мира открывается на той земле, откуда вернулись).

**«3D (проба)» / «Пергамент»** наверху переключает пергаментную карту (по умолчанию) и объёмную; выбор запоминается на устройстве. На слабом устройстве, без WebGL2 или в облегчённом режиме (`?lite=1`) — всегда пергамент.

**Заметки:** «+ Заметка» → нажать на место на карте → текст → «Сохранить». Заметка — жёлтая булавка с номером; нажать, чтобы изменить или удалить. Заметки видит только сам игрок — ни мастер, ни стол, ни другие игроки.

## 5. Мастеру

Экраны мастера оформлены как рандомизатор «Переход в Зеленогорье» (зелёная палитра, его шрифты и узор). Кнопка в шапке переключает «Авто» (как в системе) → «День» → «Ночь»; выбор запоминается на устройстве. На странице персонажа «Оформление карточки» меняет тему его карточки и экрана игрока («Авто» — по вселенной, иначе по жанру).

**Раскладка.** Слева — разделы со значками: «Игра», «Партия», «Противники», «Стол», «Карты», «Запросы», «Заметки», «Активность», «Участники». У «Запросов» — число вопросов, которые ждут ответа. В середине — страница. Справа — колонка «Сейчас в игре»:
- «Лента» с мини-лотком: броски игроков катятся в нём вживую, по одному (свои броски мастер видит в «Броске мастера»);
- «Запросы» — открытые вопросы игроков, ссылка «Ответить в «Запросах»»;
- «На столе» — что сейчас показано, «Сменить сцену», «Убрать».

Колонка не пропадает при переходах между разделами. Весь экран мастера не шире ~1680 пикселей (на большом мониторе — по центру); «Заметки», «Запросы», «Активность» и «Песочница Jev» — не шире ~880 пикселей, чтобы строки не растягивались. Листы на компьютере — панелью справа. Если окно уже (меньше ~1060 пикселей), колонка открывается кнопкой «Сейчас в игре» в шапке; ещё уже — разделы становятся вкладками сверху.

**Команды (⌘K на Mac, Ctrl+K на остальных)** — или кнопка «Команды и поиск» в шапке. Начните печатать — список сужается; ↑↓ выбрать, ↵ выполнить, Esc закрыть. Что умеет:
- показать сцену на столе (с той же проверкой стражем Jev, что и на «Столе»: если страж сомневается или недоступен, откроется «Стол», сцена не показывается), убрать сцену;
- показать или убрать портрет противника;
- сделать противника из библиотеки противником сессии;
- открыть страницу персонажа;
- бросить d10 / d20 «всем» или «скрытно» — результат приходит уведомлением;
- перейти в любой раздел, «Новый персонаж», «Песочница Jev».

**Горячие клавиши разделов:** G, затем буква (за секунду): I — «Игра», P — «Партия», O — «Противники», T — «Стол», M — «Карты», R — «Запросы», N — «Заметки», A — «Активность», U — «Участники». Пока курсор в поле ввода, не срабатывают.

Результаты действий (сцена на столе, ссылка скопирована, ответ отправлен, бросок исправлен…) появляются уведомлением внизу экрана. Ошибки форм пишутся у полей.

### «Игра»

**«Сессия».** Сверху — «Сессия с <дата>». Перед каждой игрой — «Начать новую сессию» (второе нажатие: «Точно начать новую?»). Заметки прошлой сессии уходят в архив, противник сбрасывается; броски, персонажи и дневники остаются.

**Противник.** «Из библиотеки» — выбрать заранее заведённого противника (раздел «Противники»). Или руками: «Противник» (имя) и «Его уровень силы» → «Задать». Пока противник задан, d10 игроков считаются против его силы (раздел 6). «Убрать противника» — броски снова без поправки. Игроки не видят ни имени, ни силы противника.

**«Бросок мастера».** Слева лоток с 3D-кубиком (бросить можно и смахиванием по лотку), справа d10/d20, видимость «Всем» или «Скрытый». Скрытый не видит никто, кроме мастера: ни записи, ни следа в ленте у игроков. Поле «Кто или что бросает (необязательно)». Броски мастера идут без поправки на силу.

**«Партия»** на «Игре» — плитки персонажей игроков, по нажатию — страница персонажа.

**«Расписание».** Варианты даты (дата и время, длительность, заметка «где, что взять») — игроки голосуют «Буду / Может быть / Не смогу», вы видите, кто как ответил. «Назначить» вариант — остальные убираются, явка начинается заново, игрокам уходит «Игра назначена»; дальше карточка показывает явку и «без ответа». «Напомнить сейчас» — push всем; за сутки и за час напоминания уходят сами. «Отменить» — игрокам «Игра отменена». «.ics» — файл для календаря. Расписание и «Начать новую сессию» не связаны: слот — план, сессия — факт игры.

**«Дела между сессиями».** Карточка появляется, когда игроки выбрали, чем заняты их персонажи до следующей игры (вид и описание). Неразобранные — сверху: поле «Итог для игрока», «Черновик Claude» по подсказке (в запрос уходят канон, имя и открытое описание персонажа, вид и текст дела, подсказка), «Разобрать» — итог уходит игроку с уведомлением. Разобранные свёрнуты, итог можно поправить. Дела прошлых сессий остаются в списке, пока не разобраны.

**«Инструменты».** «Позвать за стол» — push-уведомление «Игра начинается» всем игрокам, у кого включены уведомления; не чаще раза в минуту. Если на сервере нет ключей VAPID, кнопка так и скажет (раздел 9).

**«Лента»** (в правой колонке; на «Игре» — только если колонка не помещается). Последние броски, включая «мастеру» и «скрыто». Под каждым броском игрока — пояснение для мастера:
- сила персонажа и противника, ступени;
- какое правило сработало;
- «Без поправки: …», если сила срезала результат.

Кнопки и подсказки под броском:
- «Исправить» → выбрать результат, «Почему (видит только мастер)» → «Сохранить». Игрок увидит новый результат с пометкой «исправлено мастером», причину — нет.
- «Похоже на зелёную магию (N%)» с кнопками «+1 перегрузки» / «Нет» — подсказка Jev, если включена. Подсказка живёт только в открытой вкладке; после перезагрузки её нет.

### «Партия»

**«Персонажи».** Список: сколько черт, сколько раскрыто и намекнуто, чей персонаж. «Новый» — создать.

**«Перегрузка зелёной магией».** У каждого персонажа есть кнопки «−1», «+1», «Сброс» и пороги «глаза с» (по умолчанию 3) и «кожа с» (6). Признак показывается словами:
- «Зелени не видно»;
- «Глаза зеленеют»;
- «Кожу покрывает изумруд».

«Показать столу» выводит на общий экран плашку «Имя: признак» на 12 секунд, без числа. Игрокам перегрузка не приходит никогда.

### «Противники»

Библиотека противников и NPC: заводятся заранее, до игры. У каждого:
- «Имя», «Уровень силы» (ступень пишется рядом);
- «Заметки мастера (никуда не уходят)»;
- «Добавить портрет»;
- «+ Фигурка» — пиксель-арт фигурка противника (тот же конструктор, что у игрока, листом снизу) для карты и боя на столе. Когда фигурка есть, кнопка показывает её и называется «Фигурка»; в конструкторе — «Убрать фигурку». Вверху конструктора «Человек / Существо»: человек собирается из деталей, как у игрока; существо выбирается целиком — летучая мышь, пчела, змея, слизень, призрак, глаз, червь, большой червь, тыквенный король, цветок-людоед (цвет у существ не меняется). Существа с подписью «издали» (глаз, большой червь, тыквенный король) в бою на столе бьют с места, остальные подходят. У персонажей (и у игрока во вкладке «Фигурка») существ нет.
- «На 3D-карте» — «Фигурка» или объёмная модель: рыцарь, варвар, маг, разбойник, разбойник в капюшоне, скелет-воин, скелет-маг, скелет-разбойник, скелет. Сохраняется сразу. На 3D-карте (у мастера, игроков и на столе) противник стоит моделью, при перемещении идёт и поворачивается по ходу; на пергаменте и в бою на столе — фигурка. Отряд и персонажи игроков всегда фигурками. Скелеты пока без оружия.

Кнопки:
- «Сделать противником» — он становится противником сессии, его сила учитывается в бросках игроков. Если поправить силу, пока он противник, сессия подхватит новую.
- «Показать на столе» / «Убрать со стола» — портрет, имя и фигурка на общем экране. Сила и заметки на стол не уходят никогда. Если показанный противник — ещё и противник сессии, а у него есть фигурка, удары игроков на столе играются как бой (раздел 7).
- «Удалить» (дважды). Если он был противником сессии, имя и сила в сессии остаются.

Игроки противников не видят ни в каком виде.

### Новый персонаж (`/gm/new`)

Три вкладки:
- **«Попаданец».** Задать «Имя», «Обращение», «Откуда», «Вселенная», «Архетип в родном мире», «Профессия» (или «Своя профессия»), «Сид (пусто — случайный)», «Игрок» → «Бросить». В предпросмотре у каждого слота есть «Перебросить» (меняет только этот слот) и «Убрать». «Бросить заново» — всё целиком. «Сохранить персонажа». Тот же сид и те же параметры дают того же персонажа, что и рандомизатор на claude.ai.
- **«Местный».** «Имя», «Обращение», «Описание для игрока», «Заметки мастера (игрок не видит)» → «Создать».
- **«Импорт из рандомизатора».** В рандомизаторе «Экспорт» → JSON, вставить текст или выбрать файл → «Импортировать».

У одного игрока — один персонаж. Если попытаться отдать второго, ничего не изменится, будет ошибка «У этого игрока уже есть персонаж».

### Страница персонажа

Открывается из «Партия» → «Персонажи», с плиток партии на «Игре» или из команд (⌘K). Вверху путь «Партия › Имя».

Шапка:
- «Игрок» — кому отдан персонаж («никому» — снять с игрока).
- «Уровень силы · <ступень>» → «ОК» (или Enter). Переключатель «Показывать игроку ступень силы»: игрок увидит слово («Монструозный»), но не число.
- «Оформление карточки».
- «Экспорт JSON» — файл для рандомизатора.

Справа — «Как увидит игрок»: точная карточка игрока, обновляется сразу после изменений. На узком экране — кнопка «Как увидит игрок» в шапке, карточка открывается листом. Колонка «Сейчас в игре» на этой странице — кнопкой в шапке.

Ниже вкладки: «Черты · N», «Лист», «Сводки», «Фигурка» (конструктор пиксель-арт фигурки, как у игрока, плюс «Убрать фигурку»; игрок может менять свою фигурку сам), «Заметки» («Описание для игрока» у местного и «Заметки мастера» — сохраняются кнопкой «Сохранить»).

**«Лист»** — снаряжение, состояния и связи персонажа.
- У каждой записи: название, «Текст для игрока», «Заметка мастера (игрок не видит)», переключатель «видна игроку».
- Выключенный переключатель прячет запись целиком (рамка пунктиром): игрок не узнает ни о ней, ни о том, что что-то спрятано. Так можно подложить предмет, о котором персонаж пока не знает.
- Внизу: раздел, название → «Добавить» (или Enter).
- Снаряжение правит и игрок; у таких записей пометка «последним правил игрок».

**Черты.** У каждой черты:
- ступень «−» / «+»: Спит → Пробуждение → Освоение → Мастерство → Предел. Меняется на экране сразу; если сервер не принял (нет связи) — уведомление «Не получилось…», и страница возвращается к тому, что на сервере. Рядом может быть подсказка о рекомендуемом уровне силы для ступени; она ничего не запрещает;
- на «Пределе» — выбор одной из двух развилок;
- «Игрок видит: ничего / только подсказку / черту»;
- переключатели «Раскрыть черту» и «Показать цену», ползунок «Показать ступеней: N из M» — тоже сразу на экране, с откатом при ошибке;
- «Подсказка игроку (проверяет Jev)» → «Сохранить подсказку». Если черта не раскрыта, игрок увидит подсказку в блоке «Что-то происходит», без названия;
- «Для мастера» — правда о черте, признаки до раскрытия, признаки перегрузки, первое проявление, крючки, что делать, если игрок догадался рано или игнорирует.

Все изменения доходят до игрока за 1–2 секунды.

**Страж утечек.** Перед сохранением подсказки Jev проверяет, не выдаёт ли она слишком много. Возможные предупреждения:
- «Подсказка почти раскрывает эту черту (оценка N из 4)»;
- «Похоже, выдаёт другую скрытую черту «…»»;
- «Проверка недоступна (Jev не ответил)».

Дальше решаете вы: «Сохранить всё равно» или «Поправить». Жёстко блокируется только служебный маркер `СЕКРЕТ-МАСТЕРА` (его ставят в тестовые данные).

**«Сводки»** (вкладка, у попаданцев) — тексты от Claude:

| Сводка | Для кого | Публикация |
|---|---|---|
| «Сводка для мастера» | только мастер; с зацепками и тем, куда это может привести | нет, есть «Проверить выдумки» |
| «Вступление для игрока» | игрок; строится только из того, что игрок уже видит | «Опубликовать игроку» |
| «Сцена перехода» | игрок; как он попал в Зеленогорье | «Опубликовать игроку» |

Порядок работы:
1. Выбрать тон и лицо (для игроковых).
2. «Написать» (основная модель) или «Быстрый черновик» (быстрее, проще). Если текст уже есть, кнопка называется «Переписать», и новый текст снова не опубликован.
3. Поправить руками → «Сохранить правку».
4. «Опубликовать игроку». Перед публикацией Jev ищет выдумки (утверждения, которых нет в данных персонажа) и утечки скрытых черт. Если что-то нашёл — список и «Опубликовать всё равно» / «Поправить».
5. «Снять с публикации» — убрать у игрока.

Если ключ Claude не задан, на блоке написано «Ключ Claude API не задан…»: писать нельзя, править и публиковать готовое можно.

### «Стол»

«Сцены для стола». У сцены есть:
- «Название»;
- «Текст для стола»;
- «Заметки мастера к сцене (на стол не уходят)»;
- «Добавить картинку» / «Заменить картинку». Подойдёт любое фото до 15 МБ: большое фото телефон сначала сжимает сам (до 2048 px, чтобы не гонять исходник по мобильной сети), а сервер уменьшает до 1920 px, поворачивает как надо и делает превью для списков и размытый набросок, который игроки видят до загрузки картинки.

Кнопки:
- «Сохранить»;
- «Показать на столе», у показанной сцены — «Обновить на столе»; у неё же пометка «Сейчас на столе»;
- «Удалить» (дважды: «Точно удалить?»). Показанную сцену удалить нельзя.

Перед выводом Jev проверяет текст на утечку скрытых черт всех персонажей. Если нашёл — «Текст, похоже, выдаёт скрытую черту «…»» и «Показать всё равно» / «Поправить».

### «Карты»

Три карты: «Мир», «Раздолье», «Замёрзшие земли» (переключатель сверху). Мастер видит всё: скрытые регионы заштрихованы, скрытые места бледнее. Игроки и стол видят только открытое; всё остальное у них под туманом — ни контуров, ни имён, ни числа скрытого. Сначала всё скрыто.

Справа (на узком экране — кнопка «Список»):
- **Регионы** с переключателями «открыт игрокам». Открытие у игроков и на столе — за 1–2 секунды, туман над регионом расходится.
- **Места** — «Все / Открытые / Скрытые», поиск. Нажатие — место на карте, камера наезжает на него.
- **Отряд / Отряды** — где отряд, на какой карте и виден ли он игрокам и столу; «Разделить», «Соединить с…» (ниже).
- **Фигурки** — кто стоит на этой карте (зелёная точка — персонаж, красная — противник), переключатель «видна игрокам». Нажатие — карточка фигурки, камера наезжает на неё.

Инструменты над картой:
- «Выбор» — нажать место, чтобы открыть его карточку; перетащить — переставить.
- «Новое место» — нажать на карту: появится скрытая отметка, справа — её карточка.
- «Партия» — нажать на карту, где сейчас партия (маркер переезжает и с другой карты). Когда отрядов несколько — ставится выбранный.
- «Фигурка» — выбрать рядом «Кого поставить» (персонажи и противники из библиотеки) и нажать на карту. Персонаж встаёт видимым; противник — скрытым (открыть, когда партия его заметит). Персонаж на карте один: поставить его ещё раз — значит перенести. Противника можно поставить сколько угодно раз (стая волков).

**Фигурки** — миниатюры на подставке, как в настольной игре: зелёная подставка — персонаж, красная — противник, у игрока его собственный персонаж на золотой. Перетащить фигурку — переставить; у игроков и на столе она дойдёт до новой точки, повернувшись в сторону движения. Скрытая фигурка у мастера бледная, с пунктирной подставкой; игроки и стол её не получают вовсе. Фигурка показывает пиксель-арт персонажа или противника («Фигурка» на странице персонажа или «+ Фигурка» в «Противниках»); если его нет — круглый жетон с первой буквой имени. Игроки и стол видят имя и внешность — ни силы, ни заметок. Карточка фигурки: «Видна игрокам и столу», «На стол: наехать сюда», «Убрать с карты» (дважды).

**Город** (под карточкой места, кроме отметок) — вкладки:
- «Карточка» — описание (видят игроки), правитель, фракция, население → «Сохранить карточку»; «Картинка города» — фон экрана города у игроков и на столе (без неё — вид города в 3D).
- «Места» — места внутри: вид (замок, таверна, рынок, кузница, храм, гильдия, площадь, ворота, пристань, другое), название, описание (видят игроки), заметка мастера, «Видно игрокам». «+ Место».
- «Слухи» — слухи и задания. Новые скрыты; «Открыть» — игроки увидят его в экране города (в порядке, в каком вы открывали); «Скрыть» — убрать. У каждого — заметка мастера (правда ли это, к чему ведёт). «Открыть в…» — дата и время: слух откроется сам (помечен «откроется …», «Снять» отменяет). У открытого слуха видно, кто первым его услышал. Сказы игроков приходят сюда же, сверху, с автором: «Принять» — ложится открытым слухом с подписью автора (текст можно поправить), «Отклонить» — удаляется; автору в обоих случаях приходит уведомление. О новом сказе вам приходит уведомление «Сказ игрока».
- «Кто здесь» — противники и NPC из «Противников»: кто, где (в городе или в его месте), роль («трактирщик») → «+ Добавить» (добавленные скрыты), «Видно игрокам». Игроки видят имя, фигурку и роль — без силы, заметок и портрета.

**«Набросать»** (в описании, «Набросать места», «Набросать слухи») — черновик от Claude по канону мира, карте, земле, имени и виду места. Описание появляется в поле, места и слухи — списком предложений с «Добавить» у каждого; ничего не сохраняется, пока вы не нажмёте. Заметки мастера в Claude не отправляются. Кнопки нет без ключа Claude API (в демо-комнате черновики работают).

**Отряд в пути.** «Отряд — сюда» в карточке места — отряд сразу оказывается в месте, а у игроков и на столе знамя проходит путь по открытым дорогам (4–12 секунд; на столе камера следует за ним). Путь строится только по тому, что открыто игрокам: если место скрыто, отряд просто переставляется, без пути. Инструмент «Партия» по-прежнему переставляет маркер сразу, без похода.

**Предложения игроков.** Над картой появляется «Предложения игроков», когда кто-то из игроков предложил идти в место (плюс уведомление): кто, куда, сколько дней пешком (когда отрядов несколько — и какой отряд). «Вести отряд» — отряд этого игрока идёт туда (остальные ожидающие предложения его отряда на этой карте закрываются), «Отклонить» — игрок узнает. Jev здесь не участвует: решает мастер.

**Разделить отряд.** Карточка «Отряд» справа → «Разделить» (нужно хотя бы двое персонажей) → отметить, кто отходит → «Отделить». Новый отряд встаёт в той же точке, с той же видимостью; дальше его ведут отдельно. В отряды входят персонажи игроков; новый персонаж попадает в основной отряд. Отрядов — не больше шести.
- Нажатие на название отряда выбирает его (рамка) и показывает на карте; отряд на другой карте — переход на ту карту. Выбранный отряд ставит инструмент «Партия» и ведёт «Отряд — сюда» (в карточке места рядом — выбор отряда).
- Переключатель — «виден игрокам и столу». Спрятанный отряд не уходит никому, в том числе своим игрокам: они не видят его и не могут войти в город.
- «Соединить с…» — отряд вливается в выбранный и встаёт на его место. Основной отряд остаётся основным.
- У игроков под каждым отрядом — имена, их собственный — в золотой рамке. Путь, дни, предложения и вход в город у игрока — от его отряда; на столе видны все открытые отряды.

**«На стол: город»** (место должно быть открыто) — на столе экран города крупно: имя, описание, места в городе, открытые слухи, кто здесь; камера кружит над городом.

Карточка места: «Видно игрокам и столу», «Название», «Вид» (столица, город, деревня, лагерь, храм, крипта, культ, лагерь вампиров, отметка…), «Подпись» (справа, слева, снизу), «Подзаголовок (видят игроки)», «Заметка мастера (никуда не уходит)» → «Сохранить»; «На стол: наехать сюда»; «Удалить» (дважды). Исходные места из карт после удаления не возвращаются.

Деревни на картах сначала без имён — имя можно дать в карточке. Дорога появляется у игроков, только когда открыты оба её конца.

**На стол:** «На стол: вся карта», «На стол: этот вид» (как сейчас на экране мастера), в карточке места — «наехать сюда». Карта на столе заменяет сцену; новая показанная сцена убирает карту. «Убрать со стола» — вернуть сцену.

Подписи «Зелёные долины», «Бладмист» и т. п. на краях Раздолья и Замёрзших земель — это тоже регионы: их можно открывать отдельно. Открытый регион со стрелкой «›» (Раздолье и Замёрзшие земли на карте мира) ведёт на свою карту.

**3D и пергамент.** Карта объёмная (рельеф, леса, горы, города из домов по виду места), управление — как у игрока: тащить, колесо к курсору, правая кнопка — поворот и наклон, WASD, Q / E, пробел — к отряду; поиск места («Найти» — камера летит, открывается карточка места), компас, «К отряду», «Вся карта», мини-карта. Инструменты те же: место и фигурку можно перетащить за табличку или подставку, «Новое место», «Партия», «Фигурка» — нажатие по земле. Скрытые регионы — бледной штриховкой, скрытые места — бледные таблички с пунктиром. Пергамент — по умолчанию, «3D (проба)» рядом с выбором карты включает объёмную (на устройстве запоминается); стол показывает карту в 3D, только если мастер отправил её из 3D. «На стол: этот вид» передаёт центр и масштаб — на столе камера встанет так же, поворот не передаётся (стол всегда смотрит с севером наверху).

### «Запросы»

«Запросы и дневники · открыто N» — записи игроков, кроме личных («Записи «только для меня» сюда не попадают.»). Галочка «только запросы» оставляет одни вопросы.

У каждой записи:
- кто и когда;
- «запрос, ждёт ответа» или «запрос, отвечен»;
- подсказка Jev «Похоже, нащупал: «черта» (N из 3)», если запись описывает проявление скрытой черты.

«Ответ игроку» → «Ответить и закрыть», «Ответить, оставить открытым» или просто «Ответить» для обычной записи. Запросы приходят мгновенно, перезагружать не нужно.

Мастеру тоже приходят push-уведомления (колокольчик в шапке): новый «Вопрос мастеру» и новое предложение на карте — только кто и куда, без текста. Игрок получает уведомление о вашем ответе — тоже без текста.

### «Письма»

Письмо персонажу игрока от кого-то из мира — повод открыть приложение между сессиями. «Новое письмо»: кому (персонаж, выданный игроку; невыданному письмо дождётся владельца), от кого (как увидит игрок), текст, заметка мастера (игроку не уходит), доставить «Сейчас» или «В назначенное время». «Черновик Claude» пишет текст по отправителю и вашей подсказке: в запрос уходят канон мира, имя и открытое описание персонажа, отправитель и подсказка — записи дневника игрока нет. Черновик ложится в поле, вы правите и отправляете.

При доставке игроку приходит уведомление «Письмо · От …» и письмо появляется сверху его «Дневника». В списке у каждого письма состояние: «ждёт» (с временем), «доставлено», «прочитано», «есть ответ» (текст ответа под письмом; вам приходит уведомление). До доставки письмо можно изменить целиком, после — только заметку. «Удалить» убирает письмо и у игрока. Клавиша G, L.

### «Летопись»

Глава кампании по сессии — чтение для игроков между играми. «Новая глава»: сессия (по умолчанию последняя; можно «Без сессии»), заголовок, текст. «Черновик Claude» пишет главу по материалу сессии: ваши заметки, публичные броски (кто, что, исход), записи дневников за время сессии — кроме личных и вопросов мастеру; в подсказке можно сказать, что подчеркнуть. Claude просят не раскрывать тайн, но текст перед публикацией читайте вы. Викторина «Что ты помнишь?»: «Вопросы от Claude» по тексту главы или вручную (до 5 вопросов по 3 варианта, верный отмечен). «Сохранить черновик» — игроки не видят; «Опубликовать» — глава появляется у игроков во вкладке «Летопись», приходит уведомление. «Снять с публикации» и «Удалить» убирают главу у игроков. В списке — ответы игроков на викторину («Целиком и ответы»). Смена вопросов стирает прежние ответы. Клавиша G, C.

### «Заметки»

«Заметки сессии» сохраняются сами через секунду после правки. Значок рядом с заголовком: «Сохранено», «Есть изменения», «Сохраняю», «Не сохранилось» (тогда ниже — пояснение; попытка повторится при следующей правке).

Если те же заметки поменяли в другой вкладке, откроется окно «Заметки изменились в другой вкладке» с текстом той версии и выбором «Взять ту версию» / «Оставить мою». Окно не закрывается, пока не выбрать. Если в другой вкладке начали новую сессию, пока здесь был несохранённый текст, — «Началась новая сессия…» и выбор: «Перенести мой текст в новую» или «Открыть новую, мой текст выбросить». Молча ничего не затирается.

«Прошлые сессии» (ниже, раскрывается нажатием, рядом — их число) — заметки завершённых сессий с датами, только для чтения.

### «Активность»

Что сейчас открыто у каждого игрока. Строка игрока:
- точка и статус: зелёная — «в сети», жёлтая — «свёрнуто» (приложение открыто, но не на экране), серая — «не в сети, был N мин назад» или «ещё не входил»;
- персонаж (если выдан) и имя игрока; «2 устройства», если игрок открыл приложение и на телефоне, и, например, на планшете — тогда показывается то, которым пользовались последним;
- вкладка и действие с «уже N мин»: «Броски — бросает d20», «Карточка — правит вещь», «Фигурка — часть «Волосы»», «Дневник — пишет запись», «Карта — Раздолье», «Карта — карточка «Вереск»», «Карта — в городе «Вереск», Слухи и задания»;
- «Журнал» (раскрывается) — последние 30 смен со временем: «вышел», «свернул (Дневник)», «Карта — Мир».

Набранный текст сюда не попадает. Дневник — только «пишет запись», без вида и без «новая / правка». Обновляется вживую. Журнал хранится в памяти сервера: после перезапуска (или обновления) он пуст, а статусы появятся, когда игроки переподключатся. Короткий обрыв (перезагрузка страницы, смена Wi-Fi на сотовую) — до 3 секунд — в журнал не попадает.

### «Участники»

- Список участников, «Новая ссылка», «Пригласить» — см. раздел 3.
- «Инструменты» → «Песочница Jev» — раздел 8.
- «Состояние»: версия, сколько работает сервер, память, размер базы и картинок, «Последний бэкап», `nginx -t`, «IP Cloudflare». Строки с проблемой подсвечиваются.

Несколько вкладок мастера синхронны: изменение в одной сразу видно в другой.

## 6. Правила бросков

**d10:**

| Выпало | Результат |
|---|---|
| 1 | Провал с осложнением |
| 2–5 | Провал |
| 6–8 | Успех |
| 9 | Сильный успех |
| 10 | Критический успех |

**d20** — «Бросок удачи», сила не учитывается.

**Разница сил** учитывается только в d10 игрока и только когда мастер задал противника. Сравниваются ступени силы, а не числа:

| Ступень | Уровень силы |
|---|---|
| Обычный | 1–50 |
| Героический | 51–100 |
| Монструозный | 101–300 |
| Легендарный | 301–600 |
| Полубог | 601–1000 |
| Божественный | 1001+ |

- Противник на 2+ ступени выше: любой успех становится «Лишь царапина».
- Противник на 2+ ступени ниже: успех — «Критический урон», провал — «Заметный урон».
- Разница в одну ступень или ноль — обычный бросок.

Пример: сила 40 против тролля 400 (Обычный против Легендарного), выпало 10 → «Лишь царапина». В ленте мастера видно «Без поправки: Критический успех».

Правило взято из канона рандомизатора и записано в [decisions.md](decisions.md). Код — `server/src/domain/rolls.ts`.

## 7. Общий экран

1. Мастер → «Участники» → «Пригласить», роль «Общий экран» → ссылку открыть на ТВ или ноутбуке.
2. Стол входит без PIN и без кнопки «Выйти». Если он отвалился — «Новая ссылка».

Экран всегда тёмный, со своей палитрой (не зависит от тем игроков и «Дня/Ночи»), крупные шрифты — чтобы читалось издалека.

На экране:
- сверху тихая строка: комната, связь, «Анимация вкл. / выкл.», «Звук вкл. / выкл.»;
- показанная сцена: картинка во весь экран с медленным наплывом, внизу слева «Сцена», название и текст. Новая сцена плавно перетекает из старой; картинка появляется, только когда полностью загрузилась. Пустой стол — заставка «Зеленогорье»;
- портрет и имя противника, если мастер его показал: портрет проявляется из полосы, имя — следом;
- справа «Броски» — последние 5 публичных бросков;
- признаки перегрузки — стопкой справа внизу, на 12 секунд.

**Бросок на столе.** Когда кто-то бросает «Всем», над сценой катится большой кубик (медленнее, чем на телефоне, до 2,5 с), после посадки — плашка с числом, исходом и именем, потом число улетает в колонку «Броски». Пока кубик катится, в колонке у этой строки «бросает…». Несколько бросков подряд — по очереди. Скрытые броски и броски «мне и мастеру» на стол не попадают вообще.

**Бой на столе.** Если противник сессии из библиотеки показан на столе («Сделать противником» и «Показать на столе» у одного и того же противника) и у него есть фигурка, публичный бросок d10 игрока с фигуркой играется вместо кубика как удар: фигурка игрока выходит слева и бьёт своим оружием (меч — замах, копьё — выпад, лук — выстрел, посох — заклинание), противник справа отвечает по исходу броска:
- критический успех или урон — вспышка, противника отбрасывает, он падает;
- успех, сильный успех, заметный урон — попадание, противник вздрагивает;
- «Лишь царапина» — удар есть, вреда почти нет;
- провал (с осложнением тоже) — «мимо» и ответный удар противника.

Над противником всплывает число, затем — обычная плашка с числом и исходом. Исход решает сервер, сцена только показывает его. Бросок удачи (d20), броски мастера, игрок без фигурки, противник без фигурки или не показанный на столе — обычный 3D-кубик. В облегчённом режиме и с «Анимация выкл.» сцены нет — сразу плашка. Стол узнаёт о противнике только то, что мастер показал: имя, портрет, фигурку; сила и заметки не уходят.

**Отряд в пути на столе.** Когда мастер ведёт отряд, знамя идёт по дороге, камера следует за ним (с «Анимация выкл.» — сразу на месте). Если отряд разделился, на столе видны все открытые отряды с подписями имён.

**Город на столе.** «На стол: город» у мастера — экран города крупно поверх карты: знамя, правитель, описание, кто здесь, места в городе, открытые слухи и задания. Камера медленно кружит над городом (в облегчённом режиме — пергамент без облёта).

**Карта на столе.** Когда мастер показывает карту, она занимает весь экран (только открытое, остальное в тумане и облаках), внизу — её название. Карта объёмная, туман над закрытым медленно клубится; в облегчённом режиме — пергамент. Видимые фигурки персонажей и противников стоят на карте и ходят, когда мастер их передвигает (с «Анимация выкл.» — переставляются сразу). Мастер показал место — камера медленно наезжает на него; открыл регион — туман над ним расходится. Новая сцена убирает карту.

**Облегчённый режим** — без 3D-кубика (сразу плашка), без спор на фоне и без наплыва. Включается сам, если у устройства нет WebGL2, оно слабое или фон начинает тормозить (тогда в строке сверху — «облегчённый режим»); принудительно — адресом `/table?lite=1`.

- Горизонтально (ТВ) броски справа; вертикально (телефон) — сверху, три последних, сцена внизу.
- «Анимация вкл.» / «Анимация выкл.» — выключенная гасит всё движение (кубик, споры, наплыв, переходы); для трансляции в Discord лучше выключить. Настройка запоминается на этом устройстве.
- «Звук выкл.» / «Звук вкл.» — звуки стола (по умолчанию выключены): кубик летит и стучит о пол, крит — колокол, провал — глухой удар; в бою фигурок — замах и удары; смена сцены — шелест страницы, город на столе — дверь. Скрытые броски не звучат. Браузер (особенно телевизора) даёт звук только после нажатия: после перезагрузки кнопка пишет «Звук: нажмите» — достаточно нажать по экрану или кнопку пульта. Телефоны игроков и экран мастера молчат.
- Экран не гаснет, пока страница открыта (по HTTPS).

## 8. ИИ-помощники

| Функция | Где появляется | Флаг в `.env` |
|---|---|---|
| Страж утечек | подсказки к чертам, текст сцены, публикация сводок | `JEV_LEAK_GUARD` |
| Дневник → черта | «Запросы»: «Похоже, нащупал» | `JEV_DIARY_MATCH` |
| Зелёная магия | «Лента» мастера: «Похоже на зелёную магию» | `JEV_GREEN_MAGIC` |
| Заявка → бросок | пока только в песочнице | `JEV_ROLL_INTENT` |
| Сводки Claude | страница персонажа → «Сводки» | `ANTHROPIC_API_KEY`, модели `ANTHROPIC_MODEL_SUMMARY`, `ANTHROPIC_MODEL_DRAFT` |

Флаги Jev в проде по умолчанию выключены. Включать их стоит по итогам песочницы.

- Ответы ИИ видит только мастер. Решение всегда за человеком.
- Записи дневника «Только мне» (только для себя) не уходят ни в Jev, ни в Claude.
- Остальные мастерские тексты и черты уходят во внешние API TypeSafe и Anthropic.
- Если ключа нет, сеть пропала или сервис не ответил, игра идёт дальше: подсказки просто не появляются, а проверки пишут «Проверка недоступна».

**«Песочница Jev»** (`/gm/jev`, «Участники» → «Инструменты») нужна, чтобы проверить Jev на своих текстах до включения функций:
- выбрать функцию: «Страж утечек», «Дневник → черта», «Заявка → бросок», «Зелёная магия»;
- вставить текст, выбрать черты;
- нажать «Спросить».

Каждое нажатие — один платный запрос (копейки). Порядок проверки и таблица для результатов — [test-cases/stage-J0.md](test-cases/stage-J0.md). Пороги записываются в [decisions.md](decisions.md).

Установка и первый запуск прода: [ops.md](ops.md), разделы 1–4. Секреты лежат в `~/.config/zelenogorye/` (права 600) и в git не попадают.

Переменные `.env` (образец — `ops/env.production.example`):

Повседневные команды на проде:

| Задача | Команда |
|---|---|
| Выложить новую версию (сначала закоммитить) | `bash ops/scripts/deploy.sh` |
| Всё ли работает | `bash ops/scripts/status.sh` или «Участники» → «Состояние» |

| Логи | `~/srv/zelenogorye/logs` |

Выкладка прерывает игру на несколько секунд, клиенты переподключаются сами. Хранятся 3 последних релиза.

Бэкапы делаются сами:
- каждые 30 минут, если за последние 3 часа была игра (хранятся 48);
- каждый день в 04:00 (хранятся 30).

Команды разработки:
- `npm run dev` — запустить;
- `npm run typecheck` — проверить типы;
- `npm run build` — собрать;
- `npm run db:generate` — после изменения схемы;
- `npm run db:migrate` — применить миграции (dev применяет их сам при старте);
- `npm run backup:dev` — бэкап dev-базы;
- `npm run vapid:dev` — ключи push-уведомлений для dev (дописывает в `.env.development`, затем перезапустить dev).

## 10. Неполадки

| Что видно | Что делать |
|---|---|
| Карта тормозит | Открыть адрес с `?perf=1` — внизу слева появится счётчик: кадры в секунду, худший кадр, в 3D — вызовы отрисовки и треугольники, время сборки (`?perf=0` — убрать). Сравнить пергамент с живыми фильтрами: `?nobake=1`. Слабое устройство — `?lite=1` (без 3D и эффектов). 3D само снижает чёткость, если кадры долгие (запоминается на устройстве; сбросить — очистить данные сайта). |
| «Ссылка уже использована» | Войти по коду комнаты и PIN («Войти по коду и PIN»). Если PIN забыт — мастер даёт «Новая ссылка». |
| «Срок действия ссылки истёк» | Мастер даёт «Новая ссылка». |
| «Слишком много попыток…» | Подождать 15 минут (время пишется в сообщении) или выдать новую ссылку. |
| «Комната с таким кодом не найдена» | Проверить код: 6 символов, латиница и цифры. |
| Индикатор долго «Переподключение…» | Проверить интернет. На сервере: `bash ops/scripts/status.sh`. Если интернет пропал дома, игра встаёт и для сидящих за столом: весь трафик идёт через Cloudflare. |
| У игрока «Нет ответа от сервера.» при броске | «Повторить», когда появится связь. Дубля не будет. |
| «Ключ Claude API не задан» | Добавить `ANTHROPIC_API_KEY` в `.env` и перезапустить сервер. |
| «Claude API не принял ключ.» / «Нет связи с Claude API.» | Проверить ключ и лимит в Console, сеть. Игра при этом работает. |
| «Проверка недоступна (Jev не ответил)» | Сеть или ключ `JEV_API_KEY`. Решать без проверки или повторить позже. |
| «Картинка не подошла» | Другой формат (лучше JPEG или PNG), до 15 МБ. |
| Бэкап не пишется на внешний диск, «Operation not permitted» | Дать `node` (путь из `which node`) «Полный доступ к диску» в настройках конфиденциальности macOS. |
| После обновления node через nvm службы не стартуют | Заново `install.sh` и скопировать plist (путь к node зашит в plist), см. [ops.md](ops.md). |
| Мастер забыл пароль | `--reset-gm-password`, см. раздел 3. |

## 11. Известные ограничения

- Нет интернета дома — нет игры, даже за столом: всё идёт через Cloudflare.
- iOS до 18.4: в установленном приложении экран может гаснуть.
- На iOS установленное приложение и Safari не делят вход: в приложении входят по коду и PIN.
- Блокировка PIN хранится в памяти сервера и сбрасывается при его перезапуске.
- Кто знает код комнаты, может пятью неверными PIN на 15 минут заблокировать вход конкретному игроку. Для домашней игры это приемлемо.
- Карточка местного персонажа: имя, обращение, описание, заметки, уровень силы и лист (снаряжение, состояния, связи). Черт у местных нет.
- Лист персонажа не входит в «Экспорт JSON» для рандомизатора.
