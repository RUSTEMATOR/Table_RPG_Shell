# Этап 43. Летопись

Запрос Рустема (2026-10-09): из списка «ради чего возвращаться» — п. 2, летопись. После сессии мастер публикует главу: черновик пишет Claude по заметкам сессии, публичным броскам и записям дневников, мастер правит и публикует. Игроки читают главу в приложении, перед следующей игрой — короткая викторина «Что ты помнишь?». Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Глава привязана к сессии** (`session_id`, может быть пустой — глава «между сессиями»). Состояния: черновик (игроки не видят ни главы, ни её факта) и опубликована. Снять с публикации можно; удаление убирает главу у игроков.
- **Материал для черновика Claude** (быстрая модель): канон мира, заметки мастера этой сессии, публичные броски сессии (кто, что, исход), записи дневников за время сессии — кроме личных («только для меня», правило 7) и кроме вопросов мастеру. В подсказке — просьба не раскрывать тайн и писать как главу летописи от третьего лица, 4–7 абзацев, с заголовком. Мастер правит перед публикацией; Jev главу не проверяет (стол и Jev летопись не видят).
- **Викторина** — 3 вопроса по 3 варианта, с верным ответом; черновик вопросов пишет Claude по тексту главы, мастер правит. Игрок отвечает один раз (все вопросы разом), после ответа видит «N из 3» и какие верны. Игроку до ответа уходят только вопросы и варианты — без верных ответов. Мастер видит, кто как ответил. Награда — пока только счёт (жетоны вдохновения — этап 48).
- **Игроку — новая вкладка «Летопись»** (шестая, значок книги): список глав, новые сверху, глава открывается целиком, под ней викторина. Значок непрочитанного на вкладке и на иконке; push при публикации «Новая глава» / заголовок. В «Активности» мастера вкладка появляется как «Летопись», действий внутри не передаётся.
- **Мастеру — страница «Летопись»** (`/gm/chronicle`, клавиша C): главы, редактор (сессия, заголовок, текст, «Черновик Claude», викторина с правкой, «Опубликовать» / «Снять», «Удалить»), ответы игроков.
- Фотографии к главе — этап 53 (к этой же таблице).

Не меняется: заметки сессии, сводки персонажей, записи дневника.

## Шаги
1. **Сервер.** Таблицы `chapter` (сессия, заголовок, текст, викторина JSON, статус, время публикации) и `chapter_answer` (глава, участник, ответы, счёт), миграция 0017; `shared/src/chronicle.ts` (схемы записи, викторины, ответа; `ChapterPlayerSchema` strictObject — вопросы без верных ответов, свой результат; `GmChapter`); события `chronicle:changed`, `chronicle:removed`, `gm:chronicle.changed`; `domain/chronicle.ts` (проекции, материал сессии, подсказки Claude для главы и викторины, проверка ответов); маршруты игрока `GET /api/player/chronicle`, `POST /api/player/chronicle/:id/answer`; мастера `GET/POST /api/gm/chronicle`, `/:id`, `/:id/delete`, `/:id/publish`, `/draft`, `/:id/quiz-draft`, `GET /api/gm/sessions`; push игрокам при публикации.
2. **Игрок.** Вкладка «Летопись» (`PLAYER_TABS`, значок, непрочитанное), список глав, глава целиком, викторина и результат.
3. **Мастер.** Страница «Летопись»: список глав по состояниям, редактор, черновики Claude, викторина, публикация, ответы игроков.
4. **Документы:** руководство (игрок — «Летопись»; мастер — раздел «Летопись»; уведомления), решения, ручные проверки `docs/test-cases/stage-43.md`, статус в плане.
