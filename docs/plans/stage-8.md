# Этап 8. Готовность к первой сессии

Цель: настоящую игру можно провести без терминала посреди сессии. Мастер знает, что проверить до игры, а Рустем — как прогнать генеральную репетицию.

## Шаги (один шаг — один коммит, после каждого `npm run typecheck`)

1. **Сессии в UI.**
   - Сервер: `GET /api/gm/notes/history` — прошлые сессии комнаты (id, начало, конец, текст заметок), новые сверху, только мастеру (`requireGm`). Данные из `game_session` + `session_note`.
   - Клиент `web/src/components/OpponentBox.tsx` → блок «Сессия» в `routes/Gm.tsx`:
     - строка «Сессия с <дата, время>»;
     - кнопка «Начать новую сессию» → «Точно начать новую?» (второе нажатие, сброс на blur, как удаление сцены в `GmTable.tsx`).
     Вызов `POST /api/gm/session/new` (есть). Противник у новой сессии пустой — уже так в `startNewSession`.
   - `routes/GmNotes.tsx`: по событию `gm:session.changed` перечитать заметки (новая сессия — чистый лист). Ниже редактора — свёрнутый список «Прошлые сессии»: дата и текст только для чтения.
2. **Правка и удаление записей дневника** (`web/src/components/Diary.tsx`). API есть: `POST /api/player/diary/:id`, `/delete`.
   - У записи «Изменить» → тот же редактор с выбором вида → «Сохранить» / «Отмена».
   - «Удалить» → «Точно удалить?».
   - Вопрос мастеру с ответом остаётся вопросом: вид у отвеченного вопроса не меняется (кнопки вида скрыты).
   - Сервер (`server/src/routes/playerDiary.ts`): при переводе записи в «только для меня» и при удалении стирать строки `ai_judgment` с `subject_ref` = id записи. Мастерские суждения о тексте, который стал личным, не должны оставаться.
3. **Навигация мастера.**
   - «Назад» со страницы персонажа → `/gm/party` (`routes/GmCharacter.tsx`).
   - `components/GmNav.tsx`: «Запросы · N», где N — открытые вопросы. Начальное значение из `GET /api/gm/diary`, дальше по `gm:diary.changed` / `gm:diary.removed`. Отдельный маленький хук в `web/src/lib/`.
4. **Документы.**
   - `docs/session-checklist.md`: до игры / во время / после.
   - `docs/test-cases/rehearsal.md`: часовая репетиция. Три телефона (два по мобильной сети), ТВ на `/table`, мастер на ноутбуке. Шаги — по ходу игры, блокирующие помечены, ссылки на исходные кейсы stage-N.
   - `docs/test-cases/stage-8.md`.
   - `docs/manual.md`: сессии, правка дневника, ссылка на чек-лист.

## Безопасность
- История заметок — только `/api/gm/*` с `requireGm`.
- Счётчик запросов считается на клиенте мастера из уже приходящих ему событий; игрокам ничего нового не уходит.
- Удаление `ai_judgment` — только записей своей комнаты и своей записи (проверка владельца уже есть в маршруте).
