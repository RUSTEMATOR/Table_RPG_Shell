# Этап 49. Знакомые

Запрос Рустема (2026-10-09): из списка «ради чего возвращаться» — п. 9. Личный список встреченных персонажей мира: кто, где встретили, отношение, своя заметка. Пополняется сам из «Кто здесь», игрок дописывает своё. Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Знакомство записывается сервером**, когда игрок открывает экран города изнутри (отряд рядом) и в «Кто здесь» есть открытые жители: по каждому — строка `acquaintance` (персонаж игрока ↔ противник из библиотеки, место и время первой встречи, время последней). Без персонажа знакомых нет. Скрытые жители знакомыми не становятся — следа скрытого нет.
- **Игрок правит** отношение (не решил / друг / настороженно / враг) и свою заметку (до 1000 знаков). **Заметка — только игроку**: мастер её не видит и в ИИ она не уходит (как записи «только мне»). Отношение мастер видит.
- **Игроку** — карточка «Знакомые» под карточкой персонажа во вкладке «Карточка»: фигурка, имя, роль из последней встречи, «встречен в <место>, <дата>», отношение кнопками, заметка листом. Новые знакомые появляются сразу (событие при записи).
- **Мастеру** — у противника в «Противниках»: «Знакомы: <персонаж> (друг), …». Своей страницы нет.
- Имя и роль берутся из библиотеки и «Кто здесь» вживую (переименовал мастер — поменялось у всех). Портрет противника игроку не уходит (как и прежде), только фигурка.
- Удаление противника из библиотеки убирает знакомство (каскад).

Не меняется: «Кто здесь», видимость жителей, противники.
