# Этап 58. Модели для 3D-карты

Запрос Рустема (2026-10-09): из списка готовых решений — п. 10, больше моделей на 3D-карту. Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Источник — KayKit Halloween Bits 1.0** (Kay Lousberg, CC0), с GitHub по закреплённому коммиту, как Medieval Hexagon и персонажи этапа 34: склеп, могилы, надгробия, мёртвые деревья, алтарь со свечами, фонари, арка-ворота, гроб, кованая ограда, тыква — 14 моделей. Ложатся на места, которые сейчас собраны из руин и камней: крипта, культ, лагерь вампиров; у храма — погост.
- **Без правок отрисовки**: карта рисует все модели одним материалом с атласом Medieval Hexagon. Модели Halloween в инструменте `tools/extract-models/extract.mjs` уменьшаются в 5 раз (масштаб наборов разный) и перекрашиваются: UV каждой вершины переводятся на ближайший по цвету тексель атласа Medieval, своя текстура выбрасывается. Всё по-прежнему в одном `world.glb` (+~100 КБ), версия файла — в `models.json`.
- **Существа (волки, чудища Quaternius)** в этот этап не входят: у Quaternius нет закреплённого источника на GitHub (только архивы с сайта), а KayKit на GitHub отдаёт только уже взятых персонажей и скелетов. Бестиарий (этап 50) показывает 3D-модель, если она есть; новых моделей существ пока нет.
- Цвета — приближённые (ближайший оттенок палитры); на глаз проверяет Рустем (T58.*), при плохом виде модель убирается из `HALLOWEEN_MODELS` и инструмент перезапускается.

## Шаги
1. **Инструмент и модели.** Второй набор в `extract.mjs` (клон по коммиту, масштаб, перекраска), новый `world.glb` и `models.json`.
2. **Места.** Новые модели в `maps3d/settlements.ts`: крипта — склеп, могилы, мёртвые деревья, фонарь, ограда; культ — алтарь и фонари; лагерь вампиров — гробы, фонари, деревья; храм — погост. «Авторы графики» — Halloween Bits.
3. **Документы:** руководство, решения, ручные проверки `docs/test-cases/stage-58.md`, статус в плане.
