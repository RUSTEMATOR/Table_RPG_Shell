# Этап 57. Атмосфера стола: погода, время суток, звук

Запрос Рустема (2026-10-09): из списка готовых решений — п. 11 (погода, время дня, эмбиент на столе). Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`. Модели для 3D-карты (п. 10) — отдельным этапом 58.

## Решения
- **Мастер задаёт атмосферу** в «Столе» — карточка «Атмосфера»: погода (ясно, дождь, гроза, снег, туман, пепел), время суток (день, рассвет, сумерки, ночь), звук (по погоде, тишина, дождь, ветер, костёр, ночь, море). Хранится в `table_state` (миграция 0028), уходит столу в `TableState.atmosphere` (strictObject).
- **Погода рисуется на столе** без библиотек: canvas 2D поверх сцены и карты (дождь — косые штрихи, гроза — дождь и вспышки, снег — хлопья, пепел — тлеющие искры вверх), туман — слои CSS-градиентов. С «Анимация выкл.» и в облегчённом режиме — неподвижная накладка (лёгкая дымка, без частиц).
- **Время суток — цветная накладка** (`mix-blend-mode: multiply`/`soft-light`) над сценой и картой: рассвет — тёплый, сумерки — лиловый, ночь — тёмно-синий с виньеткой. Одинаково для картинки сцены, пергамента и 3D.
- **Звук — синтез Web Audio** в том же AudioContext, что звуки стола (этап 32): шум с фильтрами (дождь, ветер, море с медленной волной), треск костра, сверчки ночью, гром при грозе. Без файлов — не нужно искать лицензии и качать. Играет, только когда звук стола включён; громкость ниже звуков кубиков. «По погоде» — дождь/гроза → дождь, снег → ветер, ночь без осадков → сверчки, иначе тишина.
- Tsparticles и Howler.js не берём: свой canvas и свой синтез в 200 строк вместо двух зависимостей.
- Игрокам атмосфера не уходит (в этом этапе) — только столу.

## Шаги
1. **Сервер.** Колонки `weather`, `daytime`, `ambient` в `table_state` (миграция 0028); `shared` — перечни и подписи, `TableAtmosphereSchema`, `TableState.atmosphere`; `POST /api/gm/table/atmosphere`; проекция стола и мастеру (`GET /api/gm/table/atmosphere`).
2. **Стол.** `tv/TvWeather.tsx` (canvas и туман), `tv/TvDaytime.tsx` (накладка), `tv/ambient.ts` (синтез звука), подключение в `Table.tsx`.
3. **Мастер.** Карточка «Атмосфера» в «Столе».
4. **Документы:** руководство, решения, ручные проверки `docs/test-cases/stage-57.md`, статус в плане.
