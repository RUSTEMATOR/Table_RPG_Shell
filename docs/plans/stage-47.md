# Этап 47. Памятные моменты

Запрос Рустема (2026-10-09): из списка «ради чего возвращаться» — п. 7. Значки за события кампании: первая двадцатка, спас товарища, провал с последствиями, находчивость. Мастер выдаёт одной кнопкой с ленты бросков или вручную; у игрока на карточке — полка моментов; стол объявляет момент. Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Момент — строка `moment`**: персонаж, вид (из перечня со значками: двадцатка, единица, спас товарища, храбрость, находчивость, удача, жертва, открытие, особый), заголовок до 80 знаков, пояснение до 400, ссылка на бросок (если выдан с ленты), заметка мастера, время. Выдаёт только мастер; игрок может только смотреть.
- **С ленты**: у броска игрока кнопка «Момент»: вид подставляется по исходу (крит → «двадцатка», провал с осложнением → «единица», иначе «особый»), заголовок — из подписи броска; мастер правит и выдаёт. **Вручную**: вкладка «Моменты» на странице персонажа — список, добавить, удалить.
- **Игроку** моменты приходят в карточке персонажа (`PlayerCharacter.moments`: вид, заголовок, пояснение, время) — через ту же проекцию `projectForPlayer`, значит с тем же сравнением «изменилось ли видимое» и значком «есть новое» на «Карточке». Полка «Памятные моменты» — внизу карточки, значки по видам, нажатие раскрывает пояснение. Push игроку: «Памятный момент» / заголовок.
- **Стол**: при выдаче — событие `table:moment` (имя персонажа, вид, заголовок), экран стола показывает плашку на несколько секунд, как признаки перегрузки. Текст пояснения столу не уходит.
- Jev и Claude не участвуют. Удаление момента убирает его у игрока и в проекции.

Не меняется: броски и их исправление, лист персонажа.

## Шаги
1. **Сервер.** Таблица `moment` (миграция 0021); `shared/src/moments.ts` (виды и подписи, схемы, `MomentPlayerSchema`, `GmMoment`), `PlayerCharacterSchema.moments`, `GmCharacterView.moments`, событие `table:moment`; `domain/moments.ts`; `projectForPlayer` и `characterView` с моментами; маршруты мастера `POST /api/gm/moments` (по персонажу или по броску), `POST /api/gm/moments/:id/delete`; push игроку, событие столу.
2. **Игрок и стол.** Полка «Памятные моменты» на карточке (значки по видам); плашка момента на столе.
3. **Мастер.** Кнопка «Момент» в ленте (у бросков игроков), вкладка «Моменты» на странице персонажа.
4. **Документы:** руководство, решения, ручные проверки `docs/test-cases/stage-47.md`, статус в плане.
