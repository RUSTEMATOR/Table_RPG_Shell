# Этап 50. Бестиарий

Запрос Рустема (2026-10-09): из списка «ради чего возвращаться» — п. 10. Встреченные чудища открываются в общей коллекции отряда с фигуркой и 3D-моделью; полнота — общая на отряд. Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Чудище — противник из библиотеки с флагом «В бестиарии»** (`npc.bestiary`) и описанием для игроков (`npc.bestiary_text`, до 2000 знаков) — мастер ставит флаг и пишет описание на карточке противника. Знакомые (этап 49) — про людей из «Кто здесь», бестиарий — про тварей, с которыми бились.
- **Открывается**, когда противник становится противником сессии (бой) — автоматически; или мастер нажимает «Открыть в бестиарии». Запись `bestiary_unlock` одна на комнату и противника: коллекция общая на отряд. Закрыть обратно — «Скрыть», запись удаляется.
- **Игрокам** — карточка «Бестиарий» сверху вкладки «Летопись»: «открыто N из M» (M — все чудища с флагом; число закрытых видно — это коллекция, не тайна черт), открытые — фигурка (или модель, если есть) и имя, описание и «встречен <дата>», «бои: K» (сколько сессий был противником); закрытые — силуэты с «?». Сила, заметки мастера и портрет не уходят.
- **Стол** бестиарий не показывает (в этом этапе). Push игрокам при открытии: «Бестиарий» / имя.
- Удаление противника убирает запись каскадом; снятие флага скрывает чудище из списка (и из M).

Не меняется: противники, бой на столе, знакомые.

## Шаги
1. **Сервер.** Колонки `npc.bestiary`, `npc.bestiary_text`, таблица `bestiary_unlock` (миграция 0024); `shared/src/bestiary.ts` (схемы, `BestiaryPlayerSchema`), `NpcWriteSchema` с флагом и описанием, `GmNpc` с `bestiary`, `bestiaryText`, `bestiaryUnlockedAt`, `fights`; событие `bestiary:changed`; `domain/bestiary.ts` (список игрокам, открыть/скрыть, бои); открытие при назначении противника сессии; маршруты игрока `GET /api/player/bestiary`; мастера `POST /api/gm/npcs/:id/bestiary` (открыть/скрыть).
2. **Игрок.** Карточка «Бестиарий» на «Летописи»: открытые с фигуркой и описанием, закрытые силуэтами, полнота.
3. **Мастер.** На карточке противника: переключатель «В бестиарии», описание для игроков, «Открыть в бестиарии» / «Скрыть», «открыт <дата>», «бои: K».
4. **Документы:** руководство, решения, ручные проверки `docs/test-cases/stage-50.md`, статус в плане.
5. **Справочник D&D** (решение Рустема, 2026-10-09: «можно взять бестиарий D&D»): `tools/extract-bestiary/extract.mjs` → `seed/bestiary-srd.json` из SRD 5.1 через Open5e (CC-BY-4.0, 322 чудища: имя, вид, размер, мировоззрение, CR, КД, хиты, скорость, характеристики, особенности и действия коротко). У мастера в «Противниках» — «Из бестиария D&D»: поиск по имени и виду, «Добавить» создаёт противника с флагом «В бестиарии», силой по CR (таблица в `domain/srd.ts`) и статблоком в заметках мастера; имя — английское из SRD, мастер переименует. «Описать (Claude)» в блоке бестиария — русское описание для игроков по статблоку и подсказке мастера. Ссылка на лицензию — в «Авторах графики» и руководстве.
6. **Оформление по темам** (решение Рустема): плитки бестиария рисуются на переменных темы (`--ct-*`), у оболочек — свой вид: книга и летопись — гравюрные рамки, терминал и КПК — моноширинная таблица, пиксель — пиксельные рамки, манга и комикс — жирные обводки, досье — карточки с печатью.
