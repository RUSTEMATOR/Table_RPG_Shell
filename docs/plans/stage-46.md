# Этап 46. Расписание и явка

Запрос Рустема (2026-10-09): из списка «ради чего возвращаться» — п. 6. Голосование за дату следующей игры, назначенная дата с обратным отсчётом и явкой («буду / может быть / не смогу»), напоминание уведомлением, файл для календаря. Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Варианты и назначенная дата — одна сущность** `game_slot` (`kind`: `option` — вариант голосования, `planned` — назначенная игра). Голоса и явка — `game_slot_vote` (участник, ответ `yes | maybe | no`, один на участника на слот). Назначенная игра в комнате одна: «Назначить» вариант делает его `planned`, остальные варианты удаляются; «Отменить» удаляет назначенную.
- **Игроку** — карточка «Следующая игра» сверху «Дневника» (там же дела и письма): назначенная дата, обратный отсчёт («через 3 дня», «сегодня в 19:00», «идёт»), «Буду / Может быть / Не смогу», кто как ответил (имена персонажей), «В календарь» (файл .ics). Голосование — варианты с теми же тремя ответами и именами проголосовавших.
- **Мастеру** — карточка «Расписание» на «Игре»: добавить варианты (дата и время, заметка — где собираемся), голоса по каждому с именами, «Назначить», у назначенной — явка, «Напомнить сейчас», «Отменить», .ics.
- **Напоминания** — общий планировщик: за сутки и за час до назначенной игры push всем игрокам («Игра завтра в 19:00», «Игра через час»); флаги `reminded_day`, `reminded_hour`. Push и при открытии голосования («Когда играем?») и при назначении («Игра назначена»). Прошедшая игра (старт + длительность) из карточки исчезает сама.
- **Календарь** — `GET /api/schedule/:id/ics` (игрок и мастер): один VEVENT, заголовок «Зеленогорье — игра», длительность по умолчанию 4 часа, заметка в описании. Без внешних сервисов.
- Имена в ответах — персонажей (как у слухов); столу расписание не уходит.

Не меняется: сессии («Начать новую сессию» и расписание не связаны: сессия — факт игры, слот — план).

## Шаги
1. **Сервер.** Таблицы `game_slot`, `game_slot_vote` (миграция 0020); `shared/src/schedule.ts` (схемы, `SchedulePlayerSchema`, `GmSchedule`); событие `schedule:changed` (игроку — проекция), `gm:schedule.changed`; `domain/schedule.ts`; маршруты игрока `GET /api/player/schedule`, `POST /api/player/schedule/:id/vote`; мастера `GET /api/gm/schedule`, `POST /api/gm/schedule/options`, `/:id/plan`, `/:id/delete`, `/:id/remind`; `GET /api/schedule/:id/ics`; напоминания в планировщике.
2. **Игрок.** Карточка «Следующая игра»: отсчёт, явка, голосование, «В календарь».
3. **Мастер.** Карточка «Расписание» на «Игре».
4. **Документы:** руководство, решения, ручные проверки `docs/test-cases/stage-46.md`, статус в плане.
