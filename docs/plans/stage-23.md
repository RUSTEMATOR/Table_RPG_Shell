# Этап 23. Фигурки: конструктор пиксель-арт персонажа (LPC)

Решения Рустема (2026-10-06): графика — LPC (Liberated Pixel Cup, открытый набор: CC-BY-SA 3.0 / GPL 3.0 / OGA-BY), у каждого игрока своя фигурка на карте, все три этапа подряд, сначала макеты. Макеты — холст «Зеленогорье — новый интерфейс», ряд «Фигурки — пиксель-арт LPC»: конструктор (день), оружие и удар (ночь), карта мастера с фигурками, бой на столе.

## Шаги
1. **Набор деталей** (`tools/extract-lpc/extract.mjs`): из репозитория Universal LPC Spritesheet Character Generator (закреплённый коммит) — отобранные тела, головы, причёски, одежда, броня, обувь, оружие, нежить для противников. Только нужные анимации (стоит, идёт, удар, выпад, магия, выстрел, ранен). Палитры кожи, волос, ткани, металла. На выходе: `web/public/lpc/**/*.png` (лениво, вне предкэша PWA), каталог `web/src/figure/catalog.json`, палитры, список авторов (`web/public/lpc/CREDITS.csv` и экран «Авторы графики»).
2. **Сборка фигурки на клиенте** (`web/src/figure/`): описание фигурки (тело, кожа, детали и их цвета, оружие) → холст с кадрами нужной анимации: загрузка слоёв, перекраска по палитре, порядок слоёв по z, крупные кадры удара (192×192) у мечей и булав. Кэш по описанию. Компонент `FigureSprite` (кадры по времени, направление, масштаб без размытия).
3. **Сервер:** описание фигурки — у персонажа (`figure`, JSON, схема `FigureSchema` strictObject) и у противника из библиотеки. Игрок правит фигурку своего персонажа, мастер — любую. Фигурка — внешность, её видят все (игрок, стол, другие игроки на карте).
4. **Вкладка «Фигурка» у игрока** по макету: превью с поворотом и анимациями, части (тело, лицо, волосы, одежда, броня, обувь, оружие), варианты миниатюрами, цвета, «Случайно», «Сохранить». У мастера — то же на странице персонажа и у противника.
5. **Документы**, авторы графики.

# Этап 24. Фигурки на карте
1. Таблица `map_token` (карта, координаты, персонаж или противник, видна ли). Видимость: игроку и столу — только видимые фигурки, противники — только открытые мастером.
2. Мастер: фигурки на карте, перетаскивание, «+ Противник на карту», скрыть/показать. Игрок и стол видят перемещения вживую.
3. Документы.

# Этап 25. Бой на столе: бросок как удар
1. Публичный бросок игрока при заданном противнике сессии (из библиотеки, с фигуркой) — сцена на столе: фигурка игрока подходит и бьёт оружием (удар, выпад, выстрел или заклинание), противник реагирует по исходу броска с сервера: крит — вспышка и отлёт, успех — вздрагивает, «лишь царапина» — удар без эффекта, провал — промах и ответный удар. Затем плашка с числом, как сейчас. Без фигурок или без противника — 3D-кубик, как раньше.
2. Облегчённый режим и «Анимация выкл.» — без сцены, сразу плашка.
3. Документы.
