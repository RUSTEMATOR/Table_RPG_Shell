# Этап 59. База: Litestream и страница мастера

Запрос Рустема (2026-10-09): из списка готовых решений — п. 7 (непрерывная копия базы, Litestream) и «интерфейс управления базой данных». Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Litestream** (Apache-2.0) — отдельная служба launchd рядом с сервером: реплицирует `zg.sqlite` с отставанием в секунды в каталог (внешний диск) и/или S3-совместимое хранилище (Backblaze B2, S3). Шаблоны: `ops/templates/litestream.yml`, `ops/templates/com.zelenogorye.litestream.plist`; установка бинарника — `brew install litestream` (делает Рустем, sudo не нужен); восстановление — `litestream restore`, раздел в `docs/ops.md`. Существующие снимки (`backup.mjs`) остаются: Litestream — непрерывная копия, снимки — точки во времени с проверкой целостности.
- **Страница «База»** у мастера (`/gm/database`, клавиша B; в демо-комнате — нет, как «Состояние»):
  - обзор: размер базы, WAL и картинок, режим журнала, число строк по каждой таблице;
  - «Проверить целостность» — `PRAGMA quick_check`;
  - снимки: список (вид, время, размер), «Сделать снимок сейчас» (тот же код, что `backup.mjs`, вид `manual`, хранится 20);
  - Litestream: настроен ли (`LITESTREAM_CONFIG` в env и бинарник найден), последние поколения и снимки реплики (`litestream snapshots`), подсказка, как включить.
- **Чего на странице нет — намеренно**: содержимого таблиц и скачивания снимков. Снимок — вся база, в том числе записи «только для меня» и заметки игроков о знакомых, которые мастер не видит никак (правило 7). Доступ к файлам — у владельца Mac mini через `ops/scripts`, не через интерфейс мастера.
- Код снимка выносится из `cli/backup.ts` в `server/src/ops/backup.ts` (CLI и маршрут зовут одно).

## Шаги
1. **Сервер.** `ops/backup.ts` (снимок, список, хранение), `cli/backup.ts` — тонкая обёртка; `routes/database.ts`: `GET /api/gm/database`, `POST /api/gm/database/check`, `POST /api/gm/database/backup`; Litestream-статус через `execFile` с таймаутом; `config` — `LITESTREAM_CONFIG`, `LITESTREAM_BIN`.
2. **Мастер.** Страница «База», пункт меню.
3. **Ops и документы.** Шаблоны Litestream, `docs/ops.md` (установка, восстановление), руководство, решения, ручные проверки `docs/test-cases/stage-59.md`, статус в плане.
