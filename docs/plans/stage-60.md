# Этап 60. Тактическое поле боя

Запрос Рустема (2026-10-09): из списка готовых решений — п. 9, тактический бой на столе: сетка, фигурки, ходы. Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Шестиугольная сетка** (острый верх, осевые координаты q, r) — своя математика (~40 строк), без `honeycomb-grid`. Размер задаёт мастер: 8–30 по ширине, 6–20 по высоте.
- **Одно поле на комнату** (`battle`): размер, местность (клетки «стена», «труднопроходимо», «вода» — JSON), «открыто» (видят игроки и стол), «ходы игроков» (можно ли игрокам двигать свою фишку), подпись. Фишки — строки `battle_token`: персонаж, противник из библиотеки или метка (подпись), клетка, «скрыта» (засада: видит только мастер).
- **Мастер** — страница «Бой» (`/gm/battle`, клавиша F): создать поле, кисть местности, добавить фишки (персонажи отряда, противники библиотеки, метка), выделить фишку и нажать клетку — переход, скрыть/показать, убрать; «Открыть игрокам и столу», «Ходы игроков вкл/выкл», «Закончить бой» (поле удаляется).
- **Игроки** — карточка «Поле боя» сверху «Бросков», пока поле открыто: сетка с фишками (фигурки), своя в золотой рамке; если ходы разрешены — нажать свою фишку и клетку (в пределах поля, не стена, не занята). **Стол** — поле во весь экран поверх сцены и карты, фишки с именами.
- **Видимость**: скрытые фишки не уходят игрокам и столу совсем; заметки и сила противников — никогда. Проекция — strictObject: `{cols, rows, terrain, tokens: [{id, kind, name, figure, q, r, mine}], playerMoves, title}`.
- Без тумана войны и без расчёта дальности: это доска, правила ведёт мастер. Броски — как обычно в лотке.

## Шаги
1. **Сервер.** Таблицы `battle`, `battle_token` (миграция 0029); `shared/src/battle.ts` (сетка, местность, схемы, `BattlePublicSchema`, `GmBattle`); `domain/battle.ts`; события `battle:changed` (игрокам — проекция с `mine`), `table:battle`, `gm:battle.changed`; маршруты мастера `GET/POST /api/gm/battle…`, игрока `GET /api/player/battle`, `POST /api/player/battle/move`, стола `GET /api/table/battle`.
2. **Отрисовка.** `components/BattleGrid.tsx` (SVG-сетка, фишки с фигурками, выделение, нажатие клетки) — общая для мастера, игрока и стола.
3. **Мастер.** Страница «Бой».
4. **Игрок и стол.** Карточка «Поле боя» у игрока; `tv/TvBattle.tsx` на столе.
5. **Документы:** руководство, решения, ручные проверки `docs/test-cases/stage-60.md`, статус в плане.
