# Этап 38. Оболочки: своя метафора экрана у каждой темы

Решения Рустема (2026-10-08): вместо одной «книги» для всех — 16 оболочек (карта и правила — `docs/design-shells.md`, макеты — холст «Зеленогорье — сказочный вид», страница «Оболочки», одобрены). Тема даёт палитру, шрифты и украшения (`docs/design-packs.md`, `tools/extract-art`), оболочка — устройство экрана. Токенов не жалеть: полная переделка оформления.

Не меняется: компоненты и данные (`web/src/ui/*`, экраны), движок тем `engine.mjs`, раскладки этапа 37 (разворот / пейджер), карточка персонажа внутри (оформление темы), стол (ТВ).

## Устройство
- `web/src/lib/shells.ts`: список оболочек, тема → оболочка, какие части набора украшений оболочка показывает; `data-shell` на `<html>` ставит `skin.ts` вместе с `data-skin`.
- Стили оболочки — `web/src/styles/shells/<оболочка>.css`, грузятся лениво при первом показе (свой чанк, шрифты оболочки — `@import` Google Fonts в начале файла). Правила только под `html[data-shell="…"]` и только на переменных темы (`--ct-*`) — любая тема оболочки выглядит своей.
- Крючки в компонентах (классы без своего вида): `zg-btn` / `zg-btn-<вариант>`, `zg-seg`, `zg-field`, `zg-badge`, `zg-tray`, `zg-roll-result`, `zg-feed-row`, `zg-spread` с областями `zg-nav` / `zg-main` / `zg-aside`, `card-title`, `card-deco`.
- Раскладка разворота по оболочке — через `grid-template-areas` (навигация слева, справа, сверху, внутри «экрана» прибора).
- Мастер — оболочка «Книга» в теме «Зеленогорье».

## Шаги
1. **Основа:** shells.ts, ленивая загрузка, крючки в компонентах, набор украшений (зерно, полоса под заголовком, эмблема, угол — только где оболочка их берёт), области разворота.
2. **Книга, Летопись, Фреска, Тушь.**
3. **Манга, Визуальная новелла, Комикс, Ар-деко.**
4. **Киберинтерфейс, Бортовая консоль, Латунный прибор, Терминал.**
5. **Полевой КПК, Досье, Пиксель, Документ.**
6. **Снимки** каждой оболочки (компьютер и телефон, playwright-cli) — Рустему; правки по ним.
7. **Документы:** руководство, решения, ручные проверки `docs/test-cases/stage-38.md`.
