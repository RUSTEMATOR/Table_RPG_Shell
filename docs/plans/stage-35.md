# Этап 35. Активность игроков у мастера

Решения Рустема (2026-10-08): у мастера новая вкладка «Активность» — по каждому игроку: в приложении ли он (в сети, свёрнуто, не в сети), какая вкладка открыта и что он там делает, крупно («пишет запись», «правит вещь», «Раздолье — Слухи и задания», «бросает d20», «фигурка: голова»). Плюс короткий журнал — последние 30 смен на игрока, только в памяти сервера: без таблицы и миграции, после перезапуска журнал пуст.

Приватность: набранный игроком текст не уходит никогда (дневник, вещи, заметки, поиск, подпись броска). Дневник — одно действие «пишет запись», без вида записи («Дневник» / «Вопрос мастеру» / «Только мне») и без «новая / правка»: по активности мастер не узнаёт, что есть запись «Только мне». Данные только мастеру: `publish(..., {kind:'gm'})` и маршрут с `requireGm`; ни в Jev, ни в Claude. В руководстве игрока — что видит мастер.

Не меняется: вкладки и пейджер игрока, значки непрочитанного, экран стола, база данных.

## Шаги
1. **Общий формат** (`shared/src/presence.ts`). `PLAYER_TABS`; действие игрока — объединение по `kind`, параметры только перечисления и id (`roll {die}`, `card.theme`, `card.item {isNew}`, `figure.edit {slot}`, `diary.write`, `map.view {mapId}`, `map.note`, `map.place {placeId}`, `map.city {placeId, section}`); `PlayerActivitySchema {tab, visible, action}` — `strictObject` на всех уровнях. Для мастера — `GmPlayerPresence` и `GmPresenceLogEntry`. События: `player:activity` (игрок → сервер, без ответа), `gm:presence.changed` (мастеру).
2. **Сервер.** `server/src/realtime/presence.ts` — реестр в памяти: комната → участник → сокеты (видимость, активность), журнал на 30. Показывается последний видимый сокет, иначе последний; число устройств. Запись в журнал — только при смене статуса, вкладки или действия; после смены — `gm:presence.changed` мастеру. Название места — с сервера по id в этой комнате, чужой id отбрасывается. `handlers/presence.ts`: только `role === 'player'`, `safeParse`, не больше 120 событий в минуту на участника (`RateLimiter`), `disconnect`. `GET /api/gm/presence` (`requireGm`): все игроки комнаты, и не входившие.
3. **Игрок сообщает** (`web/src/lib/activity.ts`). Вкладка из `PlayerTabs`, действия — `useActivity(tab, action)` в компонентах; в счёт идёт последнее действие открытой вкладки. Видимость страницы — `visibilitychange`. Отправка с задержкой 400 мс, только при изменении, `volatile`; после переподключения — заново. Где: «Броски» (бросок в полёте), «Карточка» (оформление, вещь), «Фигурка» (часть), «Дневник» (лист записи), «Карта» (карта, заметка, карточка места, экран города и его раздел).
4. **Мастер: «Активность»** (`/gm/activity`, G+A). Карточка игрока: персонаж и игрок, точка статуса, вкладка и действие, «уже N мин», устройства; под ней — журнал. Живое обновление по сокету, время — раз в 30 с.
5. **Документы:** руководство (мастер и игрок), решения, ручные проверки `docs/test-cases/stage-35.md`.
