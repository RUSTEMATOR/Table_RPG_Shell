# Этап 11. Удобства игрока

Цель: игроку удобнее пользоваться дневником и лентой; он видит, где появилось новое. Без Web Push и без новых зависимостей.

## Шаги
1. **Черновик дневника** (`web/src/components/Diary.tsx`). Текст и выбранный вид сохраняются в `localStorage` через `web/src/lib/storage.ts` (ключ на участника), восстанавливаются при открытии, очищаются после успешного «Сохранить». Правка существующей записи (этап 8) черновиком не сохраняется.
2. **Значки непрочитанного** (`routes/Player.tsx`, новый `lib/unread.ts`).
   - «Дневник» — по `diary:changed`, если у записи появился или изменился ответ мастера.
   - «Карточка» — по `character:updated`, если карточка отличается от последней просмотренной.
   - Значок снимается при открытии вкладки. Отметки — в `localStorage`, чтобы значок пережил перезагрузку. Сервер не меняется.
3. **Фильтр ленты** (`components/Feed.tsx`, `lib/feed.ts`): «Все» / «Мои» на вкладке «Броски», выбор запоминается. «Мои» — броски своего участника.
4. **Документы:** `docs/test-cases/stage-11.md`, manual.md.

## Безопасность
- Всё на клиенте, на уже приходящих игроку данных. Новых событий и полей нет.
- Черновик личной записи хранится только на устройстве игрока.
