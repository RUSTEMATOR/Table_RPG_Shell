# Этапы 31–34. Готовые библиотеки: значки, звук стола, существа LPC, 3D-противники

Решения Рустема (2026-10-08): после этапа 30 (push) — четыре готовые библиотеки по порядку: значки game-icons.net, звук на столе из Kenney, существа LPC для противников, 3D-модели KayKit для противников на 3D-карте. Отряд и фигурки игроков остаются LPC: моделей KayKit всего около девяти, а фигурки игроков свои у каждого.

Общее (как у LPC и KayKit, `docs/decisions.md`): библиотеку забирает свой скрипт `tools/extract-*/extract.mjs` с закреплённого коммита или архива (проверка sha256), результат руками не правится; файлы вне предкэша PWA, кэш `CacheFirst`, версия в `?v=`; авторы и лицензии — на экране «Авторы графики» (`credits.json`), даже у CC0.

# Этап 31. Значки (game-icons.net, CC BY 3.0)
1. **Набор** (`tools/extract-icons/extract.mjs`): клон `github.com/game-icons/icons` на закреплённом коммите, список значков в скрипте; на выходе `web/src/ui/icons.json` — только контур (`d`) без чёрной подложки и автор. Авторы — в «Авторах графики».
2. **Компонент** `web/src/ui/GameIcon.tsx`: `<GameIcon name />` цветом текста (`currentColor`) — берёт цвета темы.
3. **Где:** места в городе (`SPOT_KINDS`) — экран города и редактор мастера; «Слух» / «Задание»; исход броска в ленте и на столе — рядом с текстом, не вместо; пустые состояния. Не трогаем: пиктограммы карточки (как в рандомизаторе), значки мест на карте, вкладки.
4. **Документы.**

# Этап 32. Звук на столе (Kenney, CC0)
1. **Набор** (`tools/extract-audio/extract.mjs`): Casino Audio (кубики), RPG Audio, Impact Sounds — архивы kenney.nl с sha256, отбор ~12 звуков в `web/public/sfx/` (`.ogg`, и `.m4a` для Safari и ТВ, если есть ffmpeg), кэш `zg-sfx`.
2. **Проигрыватель** `web/src/tv/sound.ts`: Web Audio, декодирование при первом звуке, громкость, не больше двух голосов.
3. **Стол:** кнопка «Звук вкл. / выкл.» рядом с «Анимация вкл.», запоминается (`zg:table:sound`), по умолчанию выключен — браузер ТВ разрешает звук только после нажатия.
4. **Где:** большой бросок — встряхивание, бросок, стук при посадке, аккорд на крите, глухой звук на провале; бой — замах и удар, ответный удар; смена сцены и открытие места — тихий шелест. Телефоны игроков и экран мастера молчат.
5. **Документы.**

# Этап 33. Существа LPC
1. **Набор:** `tools/extract-lpc/extract.mjs` берёт ещё «[LPC] Monsters» (OpenGameArt, CC-BY-SA 3.0 / GPL 3.0, летучая мышь — OGA-BY 3.0; архив с sha256): лист, размер кадра, ряды по направлениям, какие ряды — стоит / идёт / удар / ранен. В `web/public/lpc/creatures/`, раздел `creatures` в `catalog.json`, авторы.
2. **Схема:** `FigureSchema` — объединение «человек» (как сейчас) и «существо» `{v:1, creature, tint?}`; старые фигурки остаются верными без миграции; наружу — как раньше, через `strictObject` и `.parse()`.
3. **Отрисовка:** `FigureSprite` рисует существо со своего листа тем же API (поза, направление) — карты, отряд, город и бой на столе работают без правок.
4. **Конструктор:** вверху «Человек / Существо», у существа — сетка с превью и цвет. Только у мастера в библиотеке противников; у игрока «Фигурка» — как сейчас.
5. **Документы.**

# Этап 34. 3D-противники на 3D-карте (KayKit, CC0)
1. **Набор:** `tools/extract-models/extract.mjs` добавляет KayKit Character Pack Adventures 1.0 и Skeletons (закреплённые коммиты) с общими анимациями (стоит, идёт, удар, ранен) в отдельный `web/public/models/units.glb` (meshopt) — качается, только когда на карте есть 3D-противник; каталог — `maps3d/units.json`.
2. **Данные:** у `npc` колонка `model3d` (`{id, tint}`, миграция Drizzle); в `MapTokenPublicSchema` — `model` (`strictObject`, может быть null), заполняется только в `server/src/visibility/map.ts` и только у видимых жетонов противников.
3. **Мастер:** в библиотеке противников — «Модель на 3D-карте»: нет или одна из ~9, цвет, превью (ленивый чанк).
4. **3D-карта:** жетон с моделью — экземпляр модели на рельефе: выбор, перетаскивание и скрытие как раньше; в движении идёт, иначе стоит; масштаб под дома. Без модели, отряд и фигурки игроков — LPC, как сейчас. Пергамент 2D и бой на столе не меняются; облегчённый режим — как сейчас.
5. **Документы** (почему отряд остаётся LPC, бюджет моделей, `?perf=1` до и после).
