# Этап 54. Поиск мастера

Запрос Рустема (2026-10-09): из списка готовых решений — п. 6, поиск мастера по всему на SQLite FTS5 (встроен в better-sqlite3). Подробностей не было; решения ниже приняты по умолчанию и записаны в `docs/decisions.md`.

## Решения
- **Индекс — виртуальная таблица FTS5 `search_doc`** (`unicode61 remove_diacritics 2`: регистр и «ё/е» не мешают), колонки `room_id`, `kind`, `ref`, `link` (не индексируются), `title`, `body`. Создаётся при запуске сервера (`CREATE VIRTUAL TABLE IF NOT EXISTS`) — это производные данные, не схема Drizzle; потерять не страшно.
- **Перестройка по подписи комнаты**: перед поиском сервер считает дешёвую подпись (число строк и последнее `updated_at`/`created_at` по каждому источнику комнаты); изменилась — индекс комнаты пересобирается целиком (кампания — сотни, не миллионы строк). Триггеры на два десятка таблиц не нужны.
- **Что ищется (только мастеру)**: записи дневника и запросы — **кроме «только для меня»** (правило 7); ответы мастера; места (имя, описание, правитель, фракция, заметка мастера), места в городе, слухи и сказы; заметки сессий; письма (отправитель, текст, ответ, заметка); главы летописи; дела между сессиями и итоги; противники (имя, заметки, описание бестиария); персонажи (имя, открытое описание, заметки мастера); памятные моменты. **Не ищется**: заметки игроков о знакомых (только игроку), личные записи, ключи и секреты.
- **Запрос**: слова пользователя превращаются в префиксный запрос FTS (`слово*` по каждому, AND), спецсимволы FTS выбрасываются. Ранжирование `bm25`, до 50 результатов, сниппет с подсветкой.
- **Мастеру**: страница «Поиск» (`/gm/search`, клавиша S) — поле, результаты группами по видам со сниппетом и переходом; в палитре команд (Ctrl/Cmd+K) — пункт «Искать «…» везде» открывает страницу с запросом.

## Шаги
1. **Сервер.** `domain/search.ts` (создание таблицы, подпись, пересборка, запрос), `GET /api/gm/search?q=`, `shared` — `GmSearchHit`.
2. **Мастер.** Страница «Поиск», пункт меню, пункт в палитре.
3. **Документы:** руководство, решения, ручные проверки `docs/test-cases/stage-54.md`, статус в плане.
