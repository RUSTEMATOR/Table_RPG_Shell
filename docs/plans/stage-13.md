# Этап 13. Всё приложение в оформлении карточки

Цель: экран игрока — в теме его персонажа (как карточка этапа 12), экраны мастера — в оформлении «Зеленогорье» артефакта. Общий экран `/table` не меняется.

## Шаги
1. **Кожа экрана** (`web/src/lib/cardTheme/skin.ts`): `applySkin(id)` / `useSkin(id)` ставят на `<html>` `data-skin`, `data-frame`, `data-dark` и правило темы в `<style id="ct-skin">` (переменные `--ct-*` из `themeCss`). Мастер — `RoleScreen` с ролью gm → "other". Игрок — `Player.tsx` по `look` своего персонажа, тема запоминается на устройстве.
2. **Стили** (`web/src/styles/app-skin.css`): токены приложения (`--bg`, `--surface`, `--text`, `--accent`, `--primary`, шрифты, радиус) берутся из темы; узор темы — фоном страницы; шапка и вкладки — цветом текста для фона (`--ct-hink`); заголовки — шрифтом названий; у всех `.card` — рамка темы (правила рамок из `card-theme.css`, `.ct-fr` → `.card::before`).
3. **Документы:** `docs/test-cases/stage-13.md`, manual.md, decisions.md.

## Безопасность
- Только оформление. Новых данных и запросов нет: тема игрока берётся из уже приходящей карточки.
