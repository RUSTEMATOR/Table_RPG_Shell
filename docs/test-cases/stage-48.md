# Этап 48 — ручные проверки (искры)

Подготовка: `npm run dev` (миграция 0022 применится сама), `npm run seed:dev`, персонаж выдан игроку 1. Мастер — страница персонажа → «Моменты и искры», «Игра» (лента). Игрок 1 — телефон, «Броски», уведомления включены.

| № | Шаги | Ожидание |
|---|---|---|
| T48.1 | Игрок открывает «Броски». | Над кубиками «Искры: 0», кнопки переброса нет. На карточке строки «Искры» нет. |
| T48.2 | Мастер → «Моменты и искры» → «За что» → «+1 искра». | Бейдж 1, запись «+1 · от мастера». У игрока без перезагрузки «Искры: 1», на карточке «Искры: 1»; push «Искра — Мастер дал искру». |
| T48.3 | Игрок бросает d20 с подписью «прыгаю». После результата — «Переброс за искру». | Кубик бросается снова (тот же d20, та же подпись); «Искры: 0». В ленте у всех два броска, второй — «· переброс за искру». У мастера в журнале «−1 · переброс». |
| T48.4 | Игрок пытается перебросить тот же бросок ещё раз (через DevTools: `roll:request` с `rerollOf` того же id) при наличии искры. | Ошибка `already`; кнопки у перебросанного броска нет. |
| T48.5 | Мастер даёт искру; игрок ждёт 11 минут после броска (или ставит часы) и жмёт переброс. | «Поздно: прошло больше 10 минут.» — искра не потрачена. |
| T48.6 | Бросок «Мне и мастеру» → переброс. | Переброс тоже «Мне и мастеру»: другие игроки и стол его не видят. |
| T48.7 | Мастер в ленте → «Момент» → галочка «И искру» → «Выдать». | У игрока момент на карточке и +1 искра; в журнале «+1 · от мастера» с заголовком момента. |
| T48.8 | Игрок без персонажа (приглашённый) бросает. | Переброса нет; `/api/player/sparks` → `{balance: 0}`. |
| T48.9 | Летопись: игрок отвечает на викторину без ошибок. | +1 искра, push «Искра — За викторину без ошибок»; в журнале «+1 · за викторину». С ошибкой — искры нет. |
| T48.10 | Мастер даёт две искры, игрок перебрасывает два разных броска. | Обе тратятся; при нуле кнопка пропадает. |
| T48.11 | Ответ `/api/player/character`: поле `sparks` — число; `/api/player/sparks` — `{balance}`; стол `/api/table/state` без искр. Кадры ленты: у переброса `reroll: true`, причин начислений нет. | Так. СЕКРЕТ-МАСТЕРА нет. |
| T48.12 | Мастер на телефоне: «Моменты и искры». | Поля помещаются, журнал читаем. |
