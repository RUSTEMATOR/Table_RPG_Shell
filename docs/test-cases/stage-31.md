# Этап 31 — ручные проверки

Подготовка: `npm run dev`, `npm run seed:dev`. Мастер на ноутбуке, игрок на телефоне, стол на ТВ. Отряд у города, в котором есть места и открытые слухи.

| № | Шаги | Ожидание |
|---|---|---|
| T31.1 | Игрок: бросить d20 несколько раз. | Под лотком у исхода — значок (крит — лавровый венок, успех — галочка, провал — крест…), того же цвета, что подпись. В ленте у каждой строки — значок перед исходом. |
| T31.2 | То же в теме с тёмным фоном и в «Ночь». | Значки видны, цвет — как у подписи, не чёрные квадраты. |
| T31.3 | Стол: бросок «Всем». | Плашка большого броска и строка в колонке «Броски» — со значком исхода; пока кубик катится — «бросает…» без значка. |
| T31.4 | Мастер: «Исправить» бросок в ленте — выбор исхода. | В списке у каждого исхода значок. |
| T31.5 | Игрок: войти в город. | В меню у мест — значки по виду (замок, таверна, рынок, кузница, храм, гильдия, площадь, ворота, пристань), у «Слухи и задания» — значок разговора. У выбранного места над названием — вид со значком. Слух — значок разговора, задание — свиток. |
| T31.6 | Стол: «На стол: город». | У мест и слухов — те же значки, крупно. |
| T31.7 | Мастер: редактор места → «Места», «Слухи и задания». | В выборе вида места — значки; на плашке слуха и задания — значок. |
| T31.8 | Новый игрок без персонажа; пустой дневник; лента «Мои» без своих бросков. | Пустые состояния: бледный значок (капюшон, перо с чернильницей, кубики) и прежний текст. |
| T31.9 | «Фигурка» → «Авторы графики». | Абзац «Значки — game-icons.net, CC BY 3.0. Icons made by Lorc, Delapouite, Sbed, DarkZaitzev», ссылки открываются. |
| T31.10 | Карточка персонажа игрока и предпросмотр у мастера. | Пиктограммы черт — прежние (как в рандомизаторе), ничего не поменялось. |
