# Этап 10 — ручные проверки

Подготовка: `npm run dev`, `npm run seed:dev` — у «Тест: Пример» появится лист: видимый нож и связь «Травница», скрытые амулет и проклятие с маркером. Игрок с этим персонажем на телефоне.

| № | Шаги | Ожидание |
|---|---|---|
| T10.1 | Игрок: «Карточка». | «Снаряжение»: «Походный нож». «Связи»: «Травница». Блока «Состояния» нет. |
| T10.2 | **Утечка.** Игрок: DevTools → `/api/player/character` и WS-кадры `character:updated`. Поиск `СЕКРЕТ-МАСТЕРА`, `амулет`, `проклятие`, `textGm`, `visible`. | 0 совпадений. В `items` одна запись, в `conditions` пусто, у `relations` нет `id`. Ничего не говорит о том, что скрытых записей две. |
| T10.3 | Игрок: «Снаряжение» → «Добавить» → «Верёвка» → «Сохранить». | Предмет появился у игрока; у мастера в «Лист» за секунду, с пометкой «последним правил игрок». |
| T10.4 | Игрок: у ножа «Изменить» → другой текст → «Сохранить». Потом «Удалить» → «Точно удалить?». | Изменения видны мастеру сразу; после удаления нож пропал у обоих. |
| T10.5 | Мастер: «Лист» → у «Верёвки» снять «видна игроку». | У игрока верёвка исчезла без перезагрузки. |
| T10.6 | **Утечка.** Игрок в консоли: id верёвки из прежнего ответа → `fetch('/api/player/sheet/items/<id>', {method:'POST', headers:{'content-type':'application/json'}, body: JSON.stringify({title:'x'})}).then(r=>r.status)`. То же с `/delete`. | `404` оба раза, у мастера верёвка не изменилась. |
| T10.7 | Игрок в консоли: `fetch('/api/gm/characters/<любой id>/sheet', {method:'POST', headers:{'content-type':'application/json'}, body: '{"kind":"condition","title":"x"}'}).then(r=>r.status)`. | `403`. |
| T10.8 | Мастер: добавить «Состояния» → «Ранен в плечо», текст для игрока и заметку мастера `СЕКРЕТ-МАСТЕРА: заражение`. | Игрок видит «Состояния: Ранен в плечо — …», заметки нет (поиск маркера → 0). |
| T10.9 | Игрок пишет в название предмета `СЕКРЕТ-МАСТЕРА`. | «Не сохранилось», сервер жив, карточка работает. |
| T10.10 | Мастер: «Как увидит игрок». | Совпадает с телефоном, кнопок правки нет. |
| T10.11 | Местный персонаж: добавить ему связь. | Работает так же. |
| T10.12 | Игрок без персонажа в консоли: `fetch('/api/player/sheet/items', {method:'POST', headers:{'content-type':'application/json'}, body:'{"title":"x"}'}).then(r=>r.status)`. | `404`. |
