# Этап 29 — ручные проверки

Подготовка: `npm run dev`, игрок на iPhone — в Safari и в установленном приложении («На экран Домой»); мастер на ноутбуке. Для низкого экрана — iPhone SE / 13 mini или окно 375×667 в режиме устройства Safari на Mac.

| № | Шаги | Ожидание |
|---|---|---|
| T29.1 | iPhone: «Броски» → нажать в «Что делаю»; «Дневник» → «Новая запись» → текст; «Карта» → поиск места; вход — поле PIN. | Страница не увеличивается ни в одном поле; после закрытия клавиатуры масштаб прежний. |
| T29.2 | Mac (мышь): те же поля у игрока и мастера. | Вид полей не изменился (15 px). |
| T29.3 | iPhone: на карточке и в ленте развести двумя пальцами. | Увеличение двумя пальцами работает. |
| T29.4 | Низкий экран: открыть «Броски». | Кнопка «Бросить d20» видна целиком без прокрутки, над панелью вкладок. На высоком экране лоток крупнее, кнопка тоже видна. |
| T29.5 | iPhone: в «Что делаю» написать «прыгаю», нажать «Перейти» на клавиатуре. | Кубик брошен, клавиатура закрылась, лоток виден; в ленте подпись «прыгаю». Пока кубик катится, «Ввод» второй бросок не делает. |
| T29.6 | Мастер: бросок мастера — лоток и форма. | Лоток прежней высоты (220 px); «Ввод» в подписи бросает. |
| T29.7 | iPhone с iOS 18+: нажать «Бросить»; затем смахнуть по лотку. | Лёгкий отклик при нажатии и при смахивании. Записать, есть ли отклик на ударах и посадке (ожидаемо — может не быть). Android: вибрация на ударах и при результате, как раньше. |
| T29.8 | Игрок: «⋯» в шапке → «Выйти…» → «Отмена». | Диалог «Выйти? Чтобы вернуться, понадобится PIN.» закрылся, игрок на месте, экран нажимается (вкладки, кнопки). |
| T29.9 | «⋯» → «Выйти…» → «Выйти». | Экран входа. Снова войти по PIN — всё на месте. |
| T29.10 | Мастер: «⋯» → «Выйти…». | Текст «…понадобится пароль.»; «Отмена» и «Выйти» работают так же. |
| T29.11 | Стол. | В шапке нет ни «⋯», ни «Выйти». |
| T29.12 | Игрок на узком телефоне: шапка на «Бросках», «Карточке», «Дневнике». | Шапка ниже, чем раньше, название комнаты, связь, «День / Ночь» и «⋯» помещаются в строку. На «Карте» шапки нет (карта на весь экран), как раньше. |
| T29.13 | Тема персонажа с тёмным фоном: «⋯». | Значок виден (цвет шапки темы), меню читается. |
