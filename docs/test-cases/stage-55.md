# Этап 55 — ручные проверки (QR-приглашение и анкета)

Подготовка: `npm run dev` (миграция 0027 применится сама). Мастер — «Игра» → «Пригласить» и «Новый персонаж». Новый игрок без персонажа — телефон.

| № | Шаги | Ожидание |
|---|---|---|
| T55.1 | Мастер → «Пригласить» → имя → «Создать ссылку». | В рамке — ссылка, QR, «Копировать». Нажатие на QR — крупно в диалоге. |
| T55.2 | Телефоном навести камеру на QR. | Открывается ссылка-приглашение, вход проходит как по ссылке. Повторное сканирование — ссылка уже использована. |
| T55.3 | Игрок без персонажа → «Карточка». | «Мастер ещё не выдал тебе персонажа…» и «Анкета персонажа»: поля, жанр и вселенная из справочника (вселенные — по жанру). |
| T55.4 | Заполнить часть, закрыть приложение, открыть. | Черновик на месте. |
| T55.5 | «Отправить мастеру». | «Анкета у мастера», заголовок «· у мастера», кнопка «Сохранить правки» неактивна, пока нет правок. Мастеру — push «Анкета персонажа — от <имя>». |
| T55.6 | Мастер → «Новый персонаж». | Сверху «Анкеты игроков · 1»: строка с именем, жанром, вселенной; раскрыть — ответы. |
| T55.7 | «Заполнить форму по анкете». | В «Попаданце» имя, местоимение, жанр, вселенная и игрок подставлены; тост. «Бросить» → «Сохранить» — персонаж у игрока. |
| T55.8 | После выдачи персонажа. | У игрока — карточка вместо анкеты; у мастера анкета пропала из списка; `POST /api/player/questionnaire` → 409 `has_character`. |
| T55.9 | В анкете написать «СЕКРЕТ-МАСТЕРА». | 400. |
| T55.10 | Другой игрок и стол: `/api/gm/questionnaires`. | 403. Игрок видит только свою анкету. |
