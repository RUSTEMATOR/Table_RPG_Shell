# Этап 59 — ручные проверки («База», Litestream)

Подготовка: `npm run dev` в своей комнате (не демо). Для Litestream — `brew install litestream`, конфиг по `docs/ops.md` §5а с репликой в папку (например, `~/zg-litestream`), `litestream replicate -config …` в отдельном терминале, `LITESTREAM_CONFIG` в `.env.development`, перезапуск dev.
