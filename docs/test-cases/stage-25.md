# Этап 25 — ручные проверки

Подготовка: `npm run dev`. Демо-комната: мастер на ноутбуке, игрок (Мира, с мечом) на телефоне, стол на ТВ («Анимация вкл.», не облегчённый режим). Мастер → «Противники» → у тролля «Сделать противником» и «Показать на столе». В своей комнате — то же для противника с фигуркой; у персонажа игрока должна быть фигурка.

| № | Шаги | Ожидание |
|---|---|---|
| T25.1 | Игрок бросает d10 «Всем». | На столе вместо кубика — сцена: небо, трава, «Мира против Тролль Каменного брода». Мира входит слева, подходит, бьёт мечом. Потом число над троллем и плашка внизу; число улетает в колонку «Броски». Всего около 4–5 с. |
| T25.2 | Бросать d10, пока не будут все исходы (силу тролля можно менять в «Противниках»). | Успех / сильный успех — искры, тролль вздрагивает. Критический — белая вспышка, экран дрогнул, тролля отбросило, он падает. «Лишь царапина» — пара серых искр, тролль не реагирует. Провал — тролль уклоняется, «мимо», затем бьёт в ответ, Миру отбрасывает (с осложнением — она падает). Исход и число совпадают с лентой мастера. |
| T25.3 | Игроку дать лук (вкладка «Фигурка»), бросить. | Мира стреляет с места, стрела летит к троллю; при промахе — пролетает мимо. Посох — светящийся сгусток. |
| T25.4 | Игрок бросает d20 (бросок удачи). | Обычный 3D-кубик, без сцены. |
| T25.5 | Бросок «Мне и мастеру»; скрытый бросок мастера. | На столе ничего. |
| T25.6 | Мастер убирает тролля со стола (портрет), игрок бросает d10. | Обычный кубик. Показать снова — снова бой. |
| T25.7 | Мастер делает противником другого (или вводит противника вручную на «Игре»), тролль остаётся на столе. | Обычный кубик: показанный противник не противник сессии. |
| T25.8 | У тролля «Убрать фигурку»; у игрока без фигурки — бросок. | Обычный кубик в обоих случаях. |
| T25.9 | Стол: «Анимация выкл.»; затем `/table?lite=1`. | Сцены нет, сразу плашка. |
| T25.10 | Два игрока бросают d10 почти одновременно. | Сцены идут по очереди, колонка обновляется сразу, у строки в очереди — «бросает…». |
| T25.11 | **Утечка.** DevTools стола: `/api/table/state`, WS-кадры `table:state` и событий ленты. | У противника: `name`, `image`, `figure`, `opponent`. Нет силы, заметок, `СЕКРЕТ-МАСТЕРА`. В броске — `figure` (описание деталей) и обычные поля, без силы и правила. |
| T25.12 | Вкладку стола скрыть на время броска, вернуть. | Очередь не встаёт: не дольше чем через 9 с бросок закончится плашкой. |
