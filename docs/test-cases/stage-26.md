# Этап 26 — ручные проверки

Подготовка: `npm run dev`. Удобнее всего демо-комната: «Посмотреть без входа» → «Мастер» на ноутбуке, «Игрок» на телефоне, «Стол» на ТВ. В своей комнате — `npm run seed:dev` (открыты часть Раздолья и несколько мест, есть тайник с `СЕКРЕТ-МАСТЕРА`). Первое открытие 3D-карты качает модели (~1,8 МБ), дальше — из кэша.

| № | Шаги | Ожидание |
|---|---|---|
| T26.1 | Игрок → «Карта» → «Раздолье» (ноутбук, Chrome и Safari). | Сначала «Строю мир…», затем объёмная карта: рельеф с горами и холмами, леса из деревьев, реки и дороги на земле, города из домов (у столиц — замок в кольце стен с воротами на юг), таблички с названиями. Закрытое — ровное облачное поле с облаками, без домов и деревьев. Наверху кнопка «Пергамент». |
| T26.2 | Тащить мышью, колесо над городом, правая кнопка — тащить вбок и вверх-вниз. | Земля «прилипает» к курсору; колесо приближает к точке под курсором; чем ближе, тем ниже камера (видно горизонт); правая кнопка поворачивает и наклоняет. Отпустить на ходу — карта ещё немного едет. За край карты камера не уходит. |
| T26.3 | Нажать на карту и клавиши: W A S D, стрелки, Q / E, + / −, пробел, N, Home. | Езда, поворот, масштаб; пробел — к отряду, N — север наверху, Home — вся карта. На экране мастера клавиши карты не открывают разделы (G-сочетания не срабатывают от WASD). |
| T26.4 | Телефон: один палец, два пальца (щипок и поворот). | Сдвиг, масштаб и поворот одновременно; страница не прокручивается, вкладки не листаются. Подписи не дрожат. |
| T26.5 | Отдалить на всю карту, потом приблизить. | Издали — только крупные подписи (столицы, города) и названия земель; ближе появляются остальные места, ещё ближе — деревни; названия земель вблизи гаснут. |
| T26.6 | «Найти» → набрать часть названия → ↓ / ↵ (или нажать строку). | Камера летит к месту. У мастера — открывается карточка места. Скрытые места у мастера помечены «· скрыто»; у игрока их в поиске нет. |
| T26.7 | Компас: повернуть карту (Q), посмотреть на стрелку, нажать компас. | Стрелка показывает север; нажатие плавно поворачивает север наверх. |
| T26.8 | Мини-карта (на узком экране — кнопка-карта в углу): двигать камеру; нажать на мини-карту. | Рамка вида двигается и поворачивается вместе с камерой; нажатие — перелёт туда. «×» прячет мини-карту. |
| T26.9 | «К отряду» (кнопка со знаменем). | Камера летит к зелёному знамени отряда. |
| T26.10 | Мастер открывает регион. | У игрока и на столе облака над ним за ~1,5 с расходятся, земля поднимается, появляются деревья и дома. Закрыть — уходят обратно в туман. |
| T26.11 | Мастер → «Карты» в 3D. | Тумана нет; скрытые регионы — бледная штриховка, скрытые места — бледные таблички с пунктиром. Перетащить табличку места или фигурку — встаёт туда, у игрока фигурка идёт, город перестраивается на новом месте. «Новое место», «Партия», «Фигурка» — нажатием по земле. |
| T26.12 | Мастер: «На стол: этот вид» в 3D. | Стол наезжает на тот же центр и масштаб, север наверху. На столе 3D, если стол не в облегчённом режиме; `/table?lite=1` — пергамент. |
| T26.13 | Стол с «Анимация выкл.»: мастер наезжает, открывает регион. | Камера встаёт сразу, туман исчезает сразу, без перехода. |
| T26.14 | «Пергамент» → обновить страницу → «3D». | Выбор запоминается на устройстве; пергамент работает как раньше (с новой панелью: поиск, масштаб, «К отряду», «Вся карта», мини-карта; компаса нет). |
| T26.15 | `?lite=1` у игрока или устройство без WebGL2. | Сразу пергамент, кнопки «3D» нет. |
| T26.16 | Фигурки в 3D: мастер двигает фигурку по Раздолью. | Фигурка у игрока и на столе идёт к новой точке по земле (поднимается на холмы), размер — по расстоянию до камеры. |
| T26.17 | **Утечка.** Игрок: DevTools → «Сеть» во время работы 3D-карты. | Запросы к API — те же, что у пергамента (`/api/player/maps/<id>`), новых нет; модели — `/models/world.glb`. В ответах нет скрытых регионов, мест и `СЕКРЕТ-МАСТЕРА`; в тумане на месте скрытого тайника нет ни дома, ни таблички. |
| T26.18 | «Авторы графики» (конструктор фигурки). | Есть строка о моделях карты: KayKit Medieval Hexagon Pack, Kay Lousberg, CC0. |
| T26.19 | Офлайн после первого открытия 3D: выключить сеть, открыть карту. | Модели — из кэша (карта рисуется, если данные карты уже были на экране). |
