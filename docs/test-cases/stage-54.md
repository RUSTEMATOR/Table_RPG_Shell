# Этап 54 — ручные проверки (поиск мастера)

Подготовка: `npm run dev`, `npm run seed:dev`; в кампании есть заметки сессии, слухи, письмо, глава, противник, запись дневника игрока и запись «только для меня» со словом, например, «кольцо».

| № | Шаги | Ожидание |
|---|---|---|
| T54.1 | Мастер → «Поиск» (G, S). | Поле в фокусе; без запроса — только подсказка. |
| T54.2 | Ввести «тракт». | Через долю секунды — результаты по группам («Места в городах», «Слухи и сказы»…), «Трактирщик» подсвечен. Адрес страницы — `/gm/search?q=тракт`. |
| T54.3 | Ввести «Ёжик» и «ежик». | Одинаковые результаты. |
| T54.4 | Ввести слово из записи «только для меня» игрока. | Этой записи в результатах нет (обычные записи с тем же словом — есть). |
| T54.5 | Ввести слово из заметки игрока о знакомом (этап 49). | Не находится. |
| T54.6 | Нажать результат «Письма». | Переход на «Письма». У персонажа — на страницу персонажа. |
| T54.7 | Добавить новый слух со свежим словом и сразу искать его. | Находится (индекс пересобрался по подписи). |
| T54.8 | Ввести `"*()` и прочие спецсимволы. | Без ошибки: «Ничего не нашлось» или результаты по оставшимся словам. |
| T54.9 | Палитра (Ctrl/Cmd+K) → набрать «кольцо» → «Искать «кольцо» везде». | Открывается «Поиск» с запросом. |
| T54.10 | Игрок или стол запрашивает `/api/gm/search?q=а`. | 403. |
| T54.11 | Перезапустить сервер, искать. | Работает (индекс пересобирается при первом запросе). |
