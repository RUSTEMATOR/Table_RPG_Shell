# Этап 39 — ручные проверки

Подготовка: `npm run dev` (миграция 0013 применится сама), `npm run seed:dev`. Мастер на ноутбуке — «Карты», Раздолье. Игрок 1 и игрок 2 (разные персонажи) — на телефонах или в разных браузерах, вкладка «Карта». Стол — `/table` с картой Раздолья («На стол: вся карта»).

| № | Шаги | Ожидание |
|---|---|---|
| T39.1 | Открыть «Карты» у мастера. | Справа карточка «Отряд»: имена персонажей, «Раздолье», переключатель видимости, «Разделить». На карте — один отряд без подписи, как раньше. |
| T39.2 | «Разделить» → отметить персонажа игрока 2 → «Отделить». | «Отряд разделился». Карточка — «Отряды», два отряда, новый выбран (в рамке). На карте у мастера, игроков и на столе — два маркера в одной точке, под каждым имена. |
| T39.3 | «Разделить» у отряда из одного персонажа; отметить всех персонажей отряда. | У одиночного кнопка недоступна (подсказка). Отметить всех — «Отделить» недоступна. |
| T39.4 | Выбрать отряд игрока 2, инструмент «Партия», нажать на карту далеко от первого. | Двигается только отряд игрока 2. У игрока 2 его отряд в золотой рамке, у игрока 1 — свой. Мини-карта: две точки, своя — в золотой обводке. |
| T39.5 | Игрок 1 и игрок 2 жмут «К отряду» (и пробел на компьютере). | Каждого камера везёт к своему отряду. |
| T39.6 | Игрок 1 открывает карточку города, у которого стоит его отряд; игрок 2 — того же города. | Игрок 1: «Войти в город», внутри — места, слухи, кто здесь. Игрок 2: «Войти можно, когда отряд будет рядом», внутренностей нет (DevTools → ответ без spots/rumors/here). |
| T39.7 | Игрок 2 открывает карточку другого места. | «От отряда: ≈ N дней» и золотой путь — от отряда игрока 2, не игрока 1. |
| T39.8 | Игрок 2 «Предложить мастеру идти сюда». | У мастера: «… предлагает идти в …» и «· отряд: <имена отряда игрока 2>». «Вести отряд» — идёт отряд игрока 2, отряд игрока 1 стоит. Ожидающее предложение игрока 1 (если было) не закрывается. |
| T39.9 | Карточка места у мастера → выбор отряда рядом с «Отряд — сюда» → отряд игрока 1 → «Отряд — сюда». | Идёт отряд игрока 1 (у игроков и на столе — анимация по дороге), второй стоит. |
| T39.10 | Выключить видимость отряда игрока 2. | Он пропадает у обоих игроков и на столе. Игрок 2: «Где сейчас твой отряд, на этой карте не видно», в город войти нельзя. Число маркеров ничего не выдаёт (DevTools: `parties` без скрытого). Включить обратно. |
| T39.11 | Перенести отряд игрока 2 на карту «Мир» (инструмент «Партия» на другой карте). | На Раздолье остался один отряд, без подписи. На «Мире» — отряд игрока 2. У мастера в списке — «Мир · другая карта»; нажатие по названию переводит на ту карту. |
| T39.12 | «Соединить с…» у отряда игрока 2 → основной. | «Отряды соединились». Один отряд в точке основного, без подписи; в составе оба персонажа. |
| T39.13 | Снова разделить, затем у основного «Соединить с…» → отделившийся. | Основной переезжает в точку отделившегося, отряд один. |
| T39.14 | Разделить на 6 отрядов (нужно 6 персонажей) и попробовать ещё. | «Разделить» недоступна: «Не больше 6 отрядов». |
