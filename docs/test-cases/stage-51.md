# Этап 51 — ручные проверки (открываемые оболочки)

Подготовка: `npm run dev` (миграция 0025 применится сама), `npm run seed:dev`, персонаж игрока 1 в теме, например, «Пергамент» (оболочка «Книга») или «Fallout» (оболочка «Терминал»). Игрок — «Карточка» → «Оформление». Мастер — страница персонажа → «Моменты и искры».

| № | Шаги | Ожидание |
|---|---|---|
| T51.1 | Игрок открывает «Оформление». | Сверху «Оболочки: открыто 2 из 16» (или 1, если тема персонажа — книжная), вехи со счётчиками. Темы «Книги» и оболочки персонажа без замка; остальные — с замком, приглушены, подписаны названием оболочки. |
| T51.2 | Нажать тему с замком при «можно открыть» = 0. | Подсказка «Оболочка «…» ещё закрыта — её откроют вехи кампании»; тема не меняется. |
| T51.3 | Мастер → «+1 открытие». | У мастера «можно открыть: 1». У игрока без перезагрузки на кнопке «· можно открыть оболочку», в листе «можно открыть ещё 1». |
| T51.4 | Игрок нажимает тему «Манга» → «Открыть». | «Оболочка «Манга» открыта», тема применилась, все темы «Манги» без замка, «можно открыть» = 0. У мастера «Открыто игроком: Манга». |
| T51.5 | Мастер выдаёт 2 памятных момента. | У игрока +1 открытие (вехи: моменты 2). |
| T51.6 | Игрок выбирал тему «Киберпанк» до этапа 51 (в localStorage `zg:player:cardTheme:*`). | После обновления карточка в теме персонажа, пока «Киберинтерфейс» не открыт; после открытия — снова «Киберпанк». |
| T51.7 | `POST /api/player/shells` с уже открытой оболочкой и при нуле доступных. | 409 `already` и 409 `none`. |
| T51.8 | Ответ `/api/player/character`. | `shells: {picked, available, earned}`; ничего мастерского. |
| T51.9 | Мастер и стол. | Не затронуты: мастер в «Книге», стол — своё оформление. |
