# Этап 49 — ручные проверки (знакомые)

Подготовка: `npm run dev` (миграция 0023 применится сама), `npm run seed:dev`. В открытом городе у мастера — «Кто здесь» с открытым жителем (например, трактирщик) и одним скрытым. Игрок 1 с персонажем — «Карта», отряд рядом с городом.

| № | Шаги | Ожидание |
|---|---|---|
| T49.1 | Игрок открывает «Карточку» до входа в город. | Карточки «Знакомые» нет. |
| T49.2 | Игрок входит в город («Войти в город»). | На «Карточке» появилась «Знакомые · 1» без перезагрузки: фигурка, имя, роль, «встречен в <город>, <дата>», «Не решил». Скрытого жителя в списке нет. |
| T49.3 | Мастер открывает скрытого жителя; игрок переоткрывает город. | Второй знакомый появился. У мастера в «Противниках» у обоих — «Знакомы: <персонаж>». |
| T49.4 | Игрок нажимает знакомого → «Друг»; пишет заметку → «Сохранить заметку». | Отношение на плашке «Друг»; у мастера «Знакомы: <персонаж> (друг)». Заметка видна игроку после перезагрузки. |
| T49.5 | Мастер: `GET /api/gm/npcs` в DevTools. | В `acquaintances` — `characterName, attitude, place, firstAt`; заметки нет. |
| T49.6 | Игрок без персонажа входит в город. | Знакомых нет, ошибок нет. `/api/player/acquaintances` → `{acquaintances: []}`. |
| T49.7 | Мастер переименовывает противника и меняет роль в «Кто здесь». | У игрока имя и роль обновились (после перечитывания списка). |
| T49.8 | Мастер удаляет противника из библиотеки. | Знакомый исчез у игрока. |
| T49.9 | Игрок 2 запрашивает `POST /api/player/acquaintances/<id игрока 1>`. | 404. |
| T49.10 | Ответ `/api/player/acquaintances`. | Поля `id, name, label, figure, place, firstAt, lastAt, attitude, note`; ни id противника, ни заметок мастера. В заметке мастера противника написать «СЕКРЕТ-МАСТЕРА» — у игрока маркера нет. |
| T49.11 | Стол запрашивает `/api/player/acquaintances`. | 403. |
