# Этап 11 — ручные проверки

Подготовка: `npm run dev`, игрок на телефоне (лучше установленное приложение), мастер на ноутбуке.

| № | Шаги | Ожидание |
|---|---|---|
| T11.1 | Игрок: «Дневник» → набрать текст, выбрать «Вопрос мастеру», не сохранять. Закрыть приложение (смахнуть), открыть снова → «Дневник». | Текст и вид записи на месте. |
| T11.2 | Включить авиарежим, набрать запись, нажать «Сохранить» → «Не сохранилось». Выключить авиарежим, «Сохранить». | Текст не потерялся, запись сохранилась, поле очистилось. После перезапуска приложения поле пустое. |
| T11.3 | Игрок на вкладке «Броски». Мастер отвечает на его вопрос. | На вкладке «Дневник» точка. Открыть «Дневник» — точка исчезла. |
| T11.4 | Игрок на «Броски». Игрок сам на другом устройстве правит свою запись (без ответа мастера). | Точки на «Дневнике» нет. |
| T11.5 | Игрок на «Броски». Мастер раскрывает черту. | Точка на «Карточке», после открытия исчезает. Перезагрузка страницы до открытия — точка остаётся. |
| T11.6 | **Утечка.** Игрок на «Броски», DevTools → WS Messages. Мастер меняет ступень **скрытой** черты и заметки мастера персонажа. | Точки нет. В WS у игрока нет кадра `character:updated`. |
| T11.7 | Мастер меняет то, что игрок видит (подсказку), — игрок на «Карточке». | Карточка обновилась, точек нет. |
| T11.8 | «Броски» → «Мои». Бросают двое. | В ленте только свои броски, включая сделанные с другого устройства. «Все» — снова все. Выбор помнится после перезагрузки. |
| T11.9 | **Утечка.** Черновик личной записи: DevTools → Network при наборе. | Ни одного запроса, пока не нажато «Сохранить». |
