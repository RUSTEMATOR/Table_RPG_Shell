# Этап 21 — ручные проверки

Подготовка: `npm run dev`, `npm run seed:dev` (открывает Раздолье на карте мира, Западное королевство, Сумеречный лес и пять городов с тремя деревнями; партия у Marblewolf; скрытое место с маркером `СЕКРЕТ-МАСТЕРА`). Мастер на ноутбуке, игрок на телефоне, стол на ТВ.

| № | Шаги | Ожидание |
|---|---|---|
| T21.1 | Мастер → «Карты» → «Мир», «Раздолье», «Замёрзшие земли». | Карты как в одобренных макетах: бумага, рельеф, реки, леса, горы, стена Заставы, Око бури, озеро. Скрытое заштриховано. Имена совпадают с набросками. |
| T21.2 | Игрок → вкладка «Карта». | Раздолье: открыты Западное королевство и Сумеречный лес, остальное — под туманом с мягким краем. Камера у маркера партии. Пять городов и три деревни с именами; Havenwall и прочие скрытые — нет. |
| T21.3 | **Утечка.** DevTools игрока и стола: ответы `/api/player/maps/*`, `/api/table/maps/*`, WS-кадры, DOM. | Нет `СЕКРЕТ-МАСТЕРА`, нет `noteGm`/`note_gm`, нет имён и контуров скрытых регионов и мест, нет ключей вида `razd-12`. В `/api/player/maps/frozen` — пустые списки. |
| T21.4 | **Утечка.** Мастер правит заметку мастера у скрытого места; игрок смотрит WS-кадры. | Игроку и столу ничего не приходит (`map:changed` уходит, только если открытая часть изменилась). |
| T21.5 | Мастер открывает регион «Восточное королевство». | У игрока и на столе за 1–2 с туман над ним расходится, подпись появляется. Закрыть — снова туман. |
| T21.6 | Мастер открывает Havenwall и Cliffspring. | Места и дорога между ними появляются у игрока. Открыт только один конец — дороги нет. |
| T21.7 | «Новое место» → нажать на карту → назвать, вид «Лагерь», заметка мастера → «Сохранить» → «Видно игрокам». | Место появляется у игрока без заметки мастера. Перетащить — переезжает у всех. «Удалить» дважды — исчезает. |
| T21.8 | Деревня без имени → дать имя, открыть. | У игрока подпись курсивом. |
| T21.9 | «Партия» → нажать на карту; потом переключить «видна». | Маркер у игрока переезжает вживую; спрятанный — пропадает. Маркер на другой карте — на этой его нет. |
| T21.10 | Игрок: «+ Заметка» → точка → текст → «Сохранить»; нажать булавку → изменить, удалить. | Булавка с номером; лист над клавиатурой. Мастер и стол заметку не видят (у мастера в «Картах» её нет; в ответах стола её нет). |
| T21.11 | Игрок на карте мира нажимает «РАЗДОЛЬЕ ›». | Открывается карта Раздолья, «Мир» в пути возвращает. Закрытый регион со ссылкой не нажимается (его не видно). |
| T21.12 | Мастер: «На стол: вся карта», затем у места — «На стол: наехать сюда». | На столе карта во весь экран, только открытое; камера медленно (около 2,5 с) наезжает на место. |
| T21.13 | Мастер показывает на столе сцену. | Карта со стола уходит, видна сцена. |
| T21.14 | Стол с «Анимация выкл.», мастер наезжает на место. | Камера встаёт сразу, без полёта. |
| T21.15 | Телефон: двигать карту пальцем, щипок, «+»/«−». | Плавно, без рывков страницы; вкладки при этом не листаются. После жеста подписи чёткие. |
| T21.16 | Ноутбук: колесо над картой мастера. | Масштаб у курсора, страница не прокручивается. |
| T21.17 | `npm run maps:load:dev` дважды. | Второй раз «добавлено записей — 0»; открытое и удалённое мастером не меняется. |
