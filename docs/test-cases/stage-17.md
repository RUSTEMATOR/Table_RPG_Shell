# Этап 17 — ручные проверки

Подготовка: `npm run dev`; игрок на телефоне (лучше Android — там есть вибрация) и мастер на ноутбуке с открытой лентой.

| № | Шаги | Ожидание |
|---|---|---|
| T17.1 | Игрок: «Броски» → d20 → «Бросить d20». 15 раз. | Кубик встряхивается, катится, ложится; на плашке число и исход. **Вверху грань с тем же числом, что в ленте мастера** — каждый раз. В консоли нет «Кубик: вверху …». |
| T17.2 | То же для d10, 15 раз. | Как T17.1; у d10 грани 1–10. |
| T17.3 | Секундомер или запись экрана: от нажатия до числа. | Не больше 1,2 с при хорошей связи. |
| T17.4 | Смахнуть по лотку в разные стороны, быстро и медленно. | Кубик летит от края в сторону смахивания; быстрое смахивание — сильнее. Короткий тап по лотку не бросает. |
| T17.5 | DevTools → Network → Slow 3G, бросить. | Кубик встряхивается, пока нет ответа сервера, потом ложится; число одно и то же у игрока и мастера. |
| T17.6 | Отключить сеть, бросить, «Повторить» после включения. | Один бросок в ленте мастера, не два. |
| T17.7 | Включить «Уменьшить движение» в системе. | 3D нет, число появляется сразу. |
| T17.8 | Тема персонажа «Туман», затем «Медальон», день/ночь. | Цвет граней и цифр — из темы, цифры читаются. |
| T17.9 | Android: бросок. | Короткие вибрации на ударах о лоток; у крита — свой узор. iPhone — без вибрации, без ошибок. |
| T17.10 | Network: открыть «Карточку», затем «Броски». | Чанк `DiceStage` и `physics.worker` грузятся только на «Бросках». После первого броска физика работает и без сети. |
| T17.11 | **Утечка.** Скрытый бросок мастера. | У игрока и на столе его нет; у мастера — с пометкой «скрыто». |
