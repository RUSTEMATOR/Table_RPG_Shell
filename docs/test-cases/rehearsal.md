# Генеральная репетиция перед первой игрой

Проводится на проде (после [ops.md](../ops.md), шаги 1–4), за несколько дней до настоящей сессии. Около часа.

## Состав
- Мастер — ноутбук.
- Стол — ТВ или второй ноутбук на `/table`.
- Телефон A — по мобильной сети, установленное приложение (PWA).
- Телефон B — по мобильной сети, браузер.
- Телефон C — домашний Wi-Fi.

Помощники могут играть игроков; можно одному человеку держать два телефона.

Строки с **Б** — блокирующие: если не прошли, на первую игру не выходим, сначала исправление. Остальное записываем и решаем по ходу.
На каждом телефоне игрока держать DevTools или Safari Web Inspector не нужно, кроме шагов поиска утечек: их делают с ноутбука, войдя игроком в приватном окне.
