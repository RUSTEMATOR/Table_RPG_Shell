# Этап 44 — ручные проверки (дела между сессиями)

Подготовка: `npm run dev` (миграция 0018 применится сама), `npm run seed:dev`, персонаж выдан игроку 1. Мастер — «Игра». Игрок 1 — телефон, вкладка «Дневник», уведомления включены.

| № | Шаги | Ожидание |
|---|---|---|
| T44.1 | Игрок открывает «Дневник». | Сверху карточка «До следующей сессии» с кнопкой «Выбрать дело». У игрока без персонажа карточки нет. |
| T44.2 | «Выбрать дело» → «Разузнать», текст → «Сохранить». | В карточке: «Разузнать — текст», «Мастер ещё не разобрал». У мастера на «Игре» появилась карточка «Дела между сессиями» с «1 не разобрано», без перезагрузки. |
| T44.3 | Игрок → «Изменить» → другой вид. | Вид сменился у игрока и у мастера. В базе одна строка `downtime` на персонажа и сессию. |
| T44.4 | Мастер: «Черновик Claude» с подсказкой (нужен ключ). | Текст итога в поле. В логе сервера — `claude: итог дела готов`. |
| T44.5 | Приложение игрока свёрнуто. Мастер → «Разобрать». | Push «Итог дела — <вид>»; в карточке игрока — итог, кнопка «Разобрано» недоступна. У мастера дело ушло в «Разобранные». |
| T44.6 | Игрок пытается `POST /api/player/downtime` после разбора. | 409 `resolved`. |
| T44.7 | Мастер → «Изменить итог» → сохранить. | У игрока итог обновился, нового push нет. |
| T44.8 | Мастер → «Начать новую сессию». | У игрока: «Выбрать дело» снова доступно, прошлое дело с итогом — ниже под «Прошлая сессия». Выбрать новое — прошлое скрылось. |
| T44.9 | Игрок выбирает дело, мастер начинает новую сессию, не разобрав. | У мастера дело осталось в списке с датой прошлой сессии; у игрока — «Прошлая сессия · Мастер ещё не разобрал» и можно выбрать новое дело текущей сессии. |
| T44.10 | Ответ `/api/player/downtime` в DevTools; в подсказке мастера для Claude написать «СЕКРЕТ-МАСТЕРА». | У игрока — только `id, kind, text, outcome, resolvedAt, current, updatedAt`; подсказки и черновика нет. Маркера в ответе и WS-кадре `downtime:changed` нет. |
| T44.11 | Игрок пишет в тексте дела «СЕКРЕТ-МАСТЕРА». | 400 (предохранитель ленты, как в дневнике). |
| T44.12 | Стол запрашивает `/api/player/downtime`. | 403. |
| T44.13 | Мастер на телефоне: «Игра». | Карточка дел читаема, поля помещаются. |
