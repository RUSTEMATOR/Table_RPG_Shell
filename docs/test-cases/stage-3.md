# Этап 3 — ручные проверки

Подготовка: этапы 1а и 2 настроены, `npm run seed:dev` выполнен, у двух игроков есть персонажи. `npm run dev`.
Сила персонажа меняется на его странице у мастера («Уровень силы»), противник — в разделе «Сессия» на экране мастера.

| № | Шаги | Ожидание |
|---|---|---|
| T3.1 | Мастер: персонажу игрока A сила 40; противник «Тролль», сила 400. Игрок A бросает d10, пока не выпадет 10 (или 6–9). | Эффект «Лишь царапина». У мастера в ленте: «Противник на 3 ступени выше (Обычный против Легендарного)… Без поправки: Критический успех». |
| T3.2 | Сила персонажа 45, противник 50. Бросать d10 до 10. | «Критический успех», обычный бросок. |
| T3.2а | Сила персонажа 400, противник 20. Бросать d10. | Успех → «Критический урон», провал → «Заметный урон». |
| T3.2б | Противника убрать. Бросить d10 и d20. | d10 — по таблице (1 осложнение, 2–5 провал, 6–8 успех, 9 сильный, 10 крит). d20 — «Бросок удачи», сила не учитывается. |
