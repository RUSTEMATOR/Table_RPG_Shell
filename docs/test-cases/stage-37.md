# Этап 37 — ручные проверки

Подготовка: `npm run dev`. Игрок на ноутбуке (Chrome и Safari), окно 1280, 1440 и 1920 px; игрок на телефоне; мастер на ноутбуке.

| № | Шаги | Ожидание |
|---|---|---|
| T37.1 | Игрок на ноутбуке, окно 1440 px. | Разворот: слева 5 закладок с номерами, в середине раздел, справа лоток и «Лента». Нижней панели и свайпа нет. |
| T37.2 | Нажимать закладки и клавиши 1–5. | Разделы переключаются; повторный щелчок по открытой закладке — к началу раздела. В поле ввода цифры печатаются, а не переключают. |
| T37.3 | «Броски». | В середине «Лента» с «Все / Мои», справа только лоток. На других разделах — лоток и «Лента» справа. Лоток не мигает и не перезагружается при смене раздела. |
| T37.4 | Бросить мышью: смахнуть по лотку; нажать «Бросить». | Оба способа работают. Подсказка: «Смахни мышью по лотку или нажми «Бросить»». |
| T37.5 | «Карта». | Правая колонка спрятана, карта на всю ширину и высоту. Город, карточка места, заметка — как раньше. |
| T37.6 | «Карточка» при 1440 px. | Карточка в две колонки, блоки не разрезаны между колонками. При 1100 px или телефоне — одна колонка. |
| T37.7 | «Фигурка». | Превью слева (не уезжает при прокрутке), части кнопками в несколько строк, варианты — сеткой справа. |
| T37.8 | «Дневник» → «Новая запись»; «Карточка» → «Оформление». | Панель справа, крестик, Esc, щелчок мимо закрывают. Черновик дневника сохраняется как раньше. |
| T37.9 | Сузить окно до 1000 px и обратно до 1440 px. | При узком — телефонная раскладка (пейджер, панель внизу, лист снизу), открыт тот же раздел; при широком — снова разворот. |
| T37.10 | Окно 2560 px. | Экран по центру, не шире ~1680 px. |
| T37.11 | Игрок на телефоне. | Всё как до этапа: пейджер, свайп, панель внизу, карта на весь экран, лист снизу. |
| T37.12 | iPad пальцем, альбомная ориентация. | Телефонная раскладка (не разворот). |
| T37.13 | Мастер на ноутбуке 1280 и 1440 px: «Стол», «Противники», «Новый персонаж», «Игра». | Колонки внутри страниц включаются по ширине колонки: на 1280 px ничего не сжато в узкие столбики. Правая колонка 320 px. |
| T37.14 | Мастер: «Заметки», «Запросы», «Активность», «Песочница Jev» на 1920 px. | Содержимое не шире ~880 px, по центру колонки. |
| T37.15 | Мастер: «Партия» и «Участники» на 1920 px. | Списки в две колонки. |
| T37.16 | Мастер: сайдбар «Сейчас в игре» при узком окне, превью игрока у персонажа. | На компьютере — панелью справа. |
| T37.17 | Мастер: «Активность» во время броска игрока на ноутбуке с раздела «Карточка». | «Карточка — бросает d20». |
