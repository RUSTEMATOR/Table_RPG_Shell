# Скорость карты и телефон — ручные проверки

Подготовка: dev-сервис на QA-хосте (`ZG_QA_HOST=… npm run dev`), iPhone (Safari и установленное приложение). Счётчик — адрес с `?perf=1` (один раз; `?perf=0` — убрать).

| № | Шаги | Ожидание |
|---|---|---|
| TP.1 | Игрок → «Карта» (пергамент), карту не трогать 30 с. | Счётчик — около 60 к/с, телефон не греется. Карта не «мерцает». |
| TP.2 | Тащить карту и масштабировать двумя пальцами (пергамент). | Плавно, худший кадр не больше ~50 мс; после отпускания — без долгой «прорисовки». Бумага, тон земель, туман — как раньше. |
| TP.3 | `?nobake=1` → то же; потом без него. | С живыми фильтрами заметно тяжелее; вид одинаковый (леса под реками — допустимая разница). |
| TP.4 | Мастер открывает регион. | У игрока туман над регионом плавно расходится (смена картинки), без рывка. |
| TP.5 | 3D (проба) → двигать, масштабировать, поворачивать. | Плавно; в движении картинка чуть мягче, после остановки — чёткая. В счётчике — вызовы и треугольники меньше вблизи, чем издали. |
| TP.6 | 3D: мир → Раздолье → мир → Раздолье. | Второй и дальше переходы — без «Строю мир…» (из кэша). |
| TP.7 | 3D: первый раз на устройстве (очистить кэш сайта). | Модели качаются ~0,5–0,9 МБ (в «Сети» — `world.glb?v=…-meshopt`). |
| TP.8 | iPhone вертикально: вкладка «Карта». | Шапки нет, карта от края до края; «‹ Мир», земли, «3D», «+ Заметка» поверх карты; справа — поиск, «К отряду», «Вся карта»; ничего не под «островом» и полосой «Домой»; вкладки внизу. Карта сразу заполняет экран (без полос). |
| TP.9 | Повернуть iPhone горизонтально. | Вкладки — узкая колонка значков слева, карта — всё остальное; кнопки справа не под вырезом. Переключение вкладок из колонки работает; на других вкладках колонки нет — обычная раскладка. |
| TP.10 | Горизонтально: нажать на место → «Войти в город». | Карточка — панель справа во всю высоту (прокручивается), экран города — меню слева, содержимое справа, «Покинуть город» виден. |
| TP.11 | Горизонтально: «Найти» в колонке справа. | Поле поиска раскрывается влево, список мест помещается. |
| TP.12 | Уйти с «Карты» на «Броски». | Шапка вернулась, раскладка обычная. |
| TP.13 | Компьютер, узкое окно (меньше 760 px) — то же, что на телефоне; широкое — прежняя раскладка с рамкой. | — |
