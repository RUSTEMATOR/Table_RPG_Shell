# Этап 56 — ручные проверки (диктовка и экспорт)

Подготовка: `npm run dev`. Игрок с персонажем, в дневнике есть обычная запись, «Только мне», вопрос с ответом мастера, письмо с ответом. Телефон с Chrome или Safari; ноутбук с Firefox для T56.4.

| № | Шаги | Ожидание |
|---|---|---|
| T56.1 | «Новая запись» → вид «Дневник» → «Диктовать», сказать пару фраз. | Запрос микрофона; пока говоришь — серый промежуточный текст, затем фразы дописываются в поле с заглавной буквы. «Стоп» — конец. |
| T56.2 | Переключить вид на «Только мне». | Кнопки нет, вместо неё — пояснение; если диктовка шла — остановилась. |
| T56.3 | Письмо → «Ответить» → «Диктовать»; анкета (игрок без персонажа) → «Откуда и что было до» → «Диктовать». | Работает так же. |
| T56.4 | Firefox. | Кнопки «Диктовать» нет нигде. |
| T56.5 | Запретить микрофон. | «Нет доступа к микрофону — разреши его в настройках браузера». |
| T56.6 | «Экспорт» → «Markdown (.md)». | Скачивается `<имя>.md`: заголовок — имя, черты, снаряжение, моменты, письма с ответами, все записи дневника по порядку (и «Только мне»), ответы мастера цитатами. |
| T56.7 | «Экспорт» → «PDF / печать». | Сразу открывается окно «Готовлю…», затем содержимое и диалог печати; «Сохранить как PDF» даёт аккуратный документ. |
| T56.8 | Запись дневника с текстом `<b>жирный</b><script>alert(1)</script>` → PDF. | В окне печати теги видны как текст, скрипт не выполняется. |
| T56.9 | DevTools «Сеть» при экспорте. | Только обычные `GET /api/player/character`, `/diary`, `/letters`; новых запросов к серверу нет. |
