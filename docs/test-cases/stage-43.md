# Этап 43 — ручные проверки (летопись)

Подготовка: `npm run dev` (миграция 0017 применится сама), `npm run seed:dev`, несколько публичных бросков и пара записей дневника (одна — «Только мне», одна — «Вопрос мастеру»), заметки сессии заполнены. Мастер — «Летопись» (G, C). Игрок 1 — телефон, уведомления включены.

| № | Шаги | Ожидание |
|---|---|---|
| T43.1 | Игрок открывает приложение. | Шесть вкладок: …, «Дневник», «Летопись», «Карта»; клавиши 1–6 на компьютере. «Летопись» пуста: «Глав пока нет…». |
| T43.2 | Мастер: «Новая глава» → «Черновик Claude» (нужен `ANTHROPIC_API_KEY`). | Заголовок и текст заполнились; в тексте нет содержания записи «Только мне» и текста вопроса мастеру; нет чисел бросков. В демо-комнате — «Черновики Claude выключены». |
| T43.3 | «Сохранить черновик». | «Черновик главы сохранён», в списке — «черновик». У игрока (`/api/player/chronicle`) главы нет. |
