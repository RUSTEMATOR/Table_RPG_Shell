# Этап 18 — ручные проверки

Подготовка: `npm run dev`; игрок на телефоне (iPhone и Android, если есть оба), мастер на ноутбуке. Часть проверок — в DevTools с режимом устройства 390×844.

| № | Шаги | Ожидание |
|---|---|---|
| T18.1 | Игрок: открыть экран. | Шапка сверху, панель вкладок внизу («Броски», «Карточка», «Дневник») над полосой «домой» iPhone. Экран не прокручивается целиком — только содержимое вкладки. |
| T18.2 | Нажимать вкладки по очереди. | Вкладка переезжает плавно, подложка под значком перетекает к выбранной. Повторное нажатие на открытую вкладку — к её началу. |
| T18.3 | Листать пальцем влево-вправо. | Вкладки листаются и встают ровно; панель внизу следует за ними. Вертикальная прокрутка вкладки не мешает листанию. |
| T18.4 | На «Бросках» смахнуть по лотку вбок. | Бросается кубик, вкладка не листается. |
| T18.5 | Закрыть и открыть приложение. | Открыта та же вкладка, без прыжка с первой. |
| T18.6 | Повернуть телефон. | Остаётся та же вкладка. |
| T18.7 | Игрок на «Бросках»; мастер раскрывает черту, потом отвечает на вопрос дневника. | Красные точки появляются пружиной у «Карточки» и «Дневника». Пролистать до «Карточки» — точка у неё гаснет, у «Дневника» остаётся. |
| T18.8 | Игрок на «Карточке» (уже открывал «Дневник»); мастер отвечает на вопрос. | Точка у «Дневника» появляется, хотя вкладка уже загружена. |
| T18.9 | Бросок d20 на телефоне, смотреть на ленту. | Своя строка появляется в ленте в момент, когда кубик лёг (не раньше), въезжает сверху, остальные плавно сдвигаются. У мастера бросок приходит сразу. |
| T18.10 | Броски другого игрока, пока свой кубик катится. | Чужие строки появляются сразу. |
| T18.11 | «Все» / «Мои». | Сегмент с перетекающей подложкой; «Мои» — только свои. Выбор запоминается. |
| T18.12 | «Карточка» → «Оформление · …». | Лист снизу с образцами тем в их цветах. Выбор применяется сразу, за листом видно новую тему. «Как у персонажа» возвращает тему мастера. Свайп вниз закрывает. |
| T18.13 | Прокрутить длинную карточку (Chrome 115+ / Safari 26). | Черты проявляются, въезжая снизу. В Safari 17–18 и при «Уменьшить движение» — сразу на месте, без пустых мест. |
| T18.14 | «Дневник» → «Новая запись», печатать. | Лист поднимается над клавиатурой (iPhone и Android), поле и кнопки видны. |
| T18.15 | Написать текст, закрыть лист свайпом. Закрыть приложение, открыть снова. | Кнопка называется «Черновик», текст на месте. |
| T18.16 | «Вопрос мастеру» → «Отправить мастеру». | Запись наверху списка, у мастера — запрос. Лист закрыт, черновик пуст. |
| T18.17 | «Изменить» у записи → сменить на «Только мне» → «Сохранить». | Подсказка «Мастер перестанет видеть эту запись.»; у мастера запись исчезает. Черновик новой записи не тронут. |
| T18.18 | Вопрос с ответом мастера → «Изменить». | Вида записи нет, только текст. |
| T18.19 | «Удалить» → «Точно удалить?». | Запись уходит с анимацией. |
| T18.20 | Выйти; вход по коду комнаты. | Шаги «Код» → «Кто вы?» → PIN сменяются сдвигом вперёд, «Назад» / «Другой код» — сдвигом назад. Неверный PIN — ошибка под полем. |
| T18.21 | Приглашение по ссылке (новое и уже использованное). | Новое: задать PIN дважды, при несовпадении — «Не совпадает с первым.». Использованное: ошибка и «Войти по коду и PIN». |
| T18.22 | «Уменьшить движение» в системе. | Вкладки, листы, лента, шаги входа меняются без движения. |
| T18.23 | **Утечка.** DevTools игрока: DOM всех трёх вкладок и ответы `/api/player/*`. | Нет `СЕКРЕТ-МАСТЕРА`, нет скрытых бросков мастера. |
| T18.24 | «Карточка» → «Снаряжение» → «Добавить», затем «Изменить» у вещи. | Лист снизу «Новая вещь» / «Вещь», над клавиатурой. «Сохранить» — вещь в карточке, у мастера в «Листе» сразу. |
