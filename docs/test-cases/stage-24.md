# Этап 24 — ручные проверки

Подготовка: `npm run dev`. Удобнее всего демо-комната: «Посмотреть без входа» → «Мастер» на ноутбуке, «Игрок» на телефоне, «Стол» на ТВ. В ней на Раздолье у Marblewolf уже стоят Мира и Ведьмачка, а тролль — скрытый — у границы с Восточным королевством. В своей комнате: дать персонажам и противнику фигурки (этап 23).

| № | Шаги | Ожидание |
|---|---|---|
| T24.1 | Мастер → «Карты» → «Раздолье». | На карте фигурки на подставках: зелёные — персонажи, красная — противник. Скрытый тролль бледный, подставка пунктиром. Справа список «Фигурки» с переключателями. |
| T24.2 | Игрок → «Карта» → «Раздолье». Стол: мастер «На стол: вся карта». | Мира и Ведьмачка видны; у своей фигурки игрока подставка золотая. Тролля нет нигде. |
| T24.3 | **Утечка.** DevTools игрока и стола: `/api/player/maps/razdolye`, `/api/table/maps/razdolye`, WS-кадры. | В `tokens` только видимые: `id`, `kind`, `name`, `figure`, `x`, `y`, `mine`. Нет id персонажей и противников, силы, заметок, `СЕКРЕТ-МАСТЕРА`. Скрытый тролль не встречается ни именем, ни счётом. |
| T24.4 | Мастер перетаскивает Миру на другой конец королевства. | У мастера фигурка стоит, где отпустили. У игрока и на столе за 1–2 с Мира идёт к новой точке (анимация ходьбы, повёрнута в сторону движения) и останавливается. |
| T24.5 | Мастер включает «видна» у тролля. | У игрока и на столе тролль появляется. Выключить — пропадает. |
| T24.6 | **Утечка.** Пока тролль скрыт, мастер его перетаскивает. | Игроку и столу не приходит `map:changed` (видимая часть не менялась). |
| T24.7 | «Фигурка» → «Кого поставить» → противник → нажать на карту, дважды в разных местах. | Две фигурки противника, обе скрытые («… на карте — пока скрыт»). |
| T24.8 | «Фигурка» → Мира → нажать в новом месте. | Мира переносится, второй фигурки не появляется. |
| T24.9 | Персонаж без фигурки → поставить на карту. | Круглый жетон с первой буквой имени. Карточка фигурки подсказывает, где собрать фигурку. Собрать её — на карте жетон сменяется фигуркой у всех. |
| T24.10 | Игрок меняет свою фигурку во вкладке «Фигурка» и сохраняет. | На карте у всех (мастер, другие игроки, стол) фигурка меняется. |
| T24.11 | Мастер переименовывает противника в «Противниках», пока его фигурка видна. | Подпись на карте меняется у всех. |
| T24.12 | Мастер удаляет противника из библиотеки. | Его фигурки исчезают со всех карт у всех. |
| T24.13 | Карточка фигурки → «Убрать с карты» дважды. | Фигурка пропадает у всех. |
| T24.14 | Стол с «Анимация выкл.»; мастер двигает фигурку. | На столе фигурка переставляется сразу, без ходьбы. |
| T24.15 | Телефон: двигать и масштабировать карту, касаясь фигурок. | Карта двигается как обычно: фигурки у игрока не перехватывают жесты. |
| T24.16 | **Права.** Игрок шлёт `POST /api/gm/maps/razdolye/tokens`, `POST /api/gm/maps/tokens/<id>`; мастер — `kind: "npc"` с чужим или выдуманным `refId`. | 403; 404. |
