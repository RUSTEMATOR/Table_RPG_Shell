# Этап 60 — ручные проверки (тактическое поле боя)

Подготовка: `npm run dev` (миграция 0029 применится сама), `npm run seed:dev`; у персонажей и пары противников есть фигурки. Мастер — «Бой» (G, F). Игроки 1 и 2 — «Броски». Стол — `/table`.

| № | Шаги | Ожидание |
|---|---|---|
| T60.1 | «Создать поле» 16×10, подпись. | Поле шестиугольников, «только у вас». У игроков и на столе ничего. |
| T60.2 | «Местность» → «Стена» по нескольким клеткам, «Вода», «Стереть». | Клетки окрашиваются и стираются. |
| T60.3 | «Поставить» → персонаж игрока 1 → клетка; противник → клетка; метка «Сундук» → клетка. | Фишки с фигурками/буквой и подписями; персонаж пропал из списка «Персонаж» (уже на поле). |
| T60.4 | «Фишки»: противника → выделить → «Скрыта (засада)». | Фишка полупрозрачная у мастера. |
| T60.5 | «Открыть игрокам и столу». | У игроков сверху «Бросков» — «Поле боя», на столе — поле во весь экран. Скрытого противника нет ни у игроков, ни на столе (DevTools: в `tokens` его нет). |
| T60.6 | Мастер двигает фишку. | У игроков и на столе фишка плавно переезжает. |
| T60.7 | Игрок 1 жмёт свою фишку при выключенных ходах. | Ничего не происходит, подпись «Фишки двигает мастер». |
| T60.8 | «Игроки двигают свои фишки» вкл. Игрок 1: своя фишка (золотая рамка) → свободная клетка. | Переезжает у всех. На стену или занятую клетку — «Туда нельзя». Чужую фишку выбрать нельзя. |
| T60.9 | Игрок 2 (его персонажа нет на поле). | «Твоей фишки на поле пока нет», ходить нечем. |
| T60.10 | Снять «Скрыта». | Противник появляется у игроков и на столе. |
| T60.11 | «Закончить бой» (двумя нажатиями). | Поле пропадает у всех; у мастера снова «Создать поле». |
| T60.12 | Ответы `/api/player/battle`, `/api/table/battle`. | `tokens[]` — `id, kind, name, figure, col, row, mine`; ни refId, ни силы, ни скрытых. СЕКРЕТ-МАСТЕРА нет. |
| T60.13 | Стол: удар по противнику сессии (этап 25) при открытом поле. | Анимация удара работает как раньше. |
| T60.14 | Мастер и игрок на телефоне. | Поле помещается в ширину, фишки нажимаются. |
