# Этап 42 — ручные проверки (письма)

Подготовка: `npm run dev` (миграция 0016 применится сама), `npm run seed:dev`, персонаж выдан игроку 1. Мастер на ноутбуке — «Письма» (G, L). Игрок 1 — на телефоне с включёнными уведомлениями (этап 41), вкладка «Дневник» или приложение свёрнуто.

| № | Шаги | Ожидание |
|---|---|---|
| T42.1 | Мастер: «Новое письмо», персонаж игрока 1, от «Матушка», текст, «Сейчас» → «Отправить». | «Письмо доставлено»; в списке — «доставлено». У игрока 1 сверху «Дневника» — «Письма · 1», карточка «Новое письмо · От Матушка» в рамке; на вкладке «Дневник» значок. |
| T42.2 | Приложение игрока свёрнуто, мастер отправляет письмо «Сейчас». | Push «Письмо — От <отправитель>»; нажатие открывает «Дневник». |
| T42.3 | Игрок открывает письмо. | Лист с текстом; у мастера состояние меняется на «прочитано» без перезагрузки; рамка у карточки пропала, значок снят. |
| T42.4 | Игрок → «Ответить» → текст → «Отправить»; затем «Переписать ответ». | Ответ виден под письмом у игрока; у мастера — «есть ответ» и текст, push «Ответ на письмо — <персонаж> — <отправитель>». После правки — новый текст у мастера. |
| T42.5 | Мастер: письмо «В назначенное время» через 2 минуты → «Запланировать». | «Письмо уйдёт <время>», состояние «ждёт». У игрока письма нет (DevTools: `/api/player/letters` без него). Через ≤2,5 мин — доставлено, игроку пришло. |
| T42.6 | Пока письмо «ждёт»: «Изменить» → другой текст и время → «Сохранить»; затем после доставки — «Заметка». | До доставки меняются текст, отправитель, время; после — форма «Заметка к письму», поля текста и отправителя недоступны. |
| T42.7 | «Удалить» доставленное письмо (двумя нажатиями). | У игрока письмо исчезает сразу, лист закрывается, если был открыт. |
| T42.8 | Письмо персонажу, никому не выданному; затем выдать персонажа игроку 2. | Предупреждение в форме; письмо «доставлено», но ни у кого не видно. После выдачи — у игрока 2 в «Письмах». |
| T42.9 | «Черновик Claude» с подсказкой (нужен `ANTHROPIC_API_KEY`); то же в демо-комнате. | Текст ложится в поле, «поправьте и отправьте». В демо — «Черновики Claude выключены». |
| T42.10 | В заметке мастера написать «СЕКРЕТ-МАСТЕРА», отправить письмо. | Игроку письмо приходит; в ответе `/api/player/letters` и в WS-кадре `letters:changed` — ровно `id, from, text, deliveredAt, readAt, reply, repliedAt`, маркера нет. В логе нет `GmLeakError`. |
| T42.11 | Игрок запрашивает `/api/player/letters/<id>/read` для чужого или недоставленного письма (id из DevTools мастера). | 404. |
| T42.12 | Стол запрашивает `/api/player/letters`. | 403. |
| T42.13 | Перезапустить сервер с письмом «ждёт» через минуту. | После перезапуска письмо доставляется вовремя (планировщик стартует сразу). |
| T42.14 | Игрок без персонажа открывает «Дневник». | Раздела «Письма» нет, ошибок нет. |
| T42.15 | Мастер на телефоне: «Письма». | Форма и список читаемы, выбор даты работает. |
