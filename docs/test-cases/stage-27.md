# Этап 27 — ручные проверки

Подготовка: `npm run db:migrate` (миграция `0010_places`), затем `npm run seed:dev` — наполнит названные места черновиками (в демо-комнате — при её создании; старую демо-комнату удалить вместе с базой разработки или проверять в своей комнате). Открыты Marblewolf, Oroak, Eriflower, Magewald, Castlefair; тролль «Тест: Тролль» — «кто здесь» у Старого моста Oroak.

| № | Шаги | Ожидание |
|---|---|---|
| T27.1 | Игрок → «Карта» → «Раздолье» → нажать табличку Marblewolf. | Камера летит к городу; справа (на телефоне — снизу) карточка: знамя красное, «Столица · столица · гильдия Widelan», правитель, фракция, население, описание, «Войти в город». |
| T27.2 | «Войти в город». | Экран города: слева «Обзор», «Мраморный замок», «Ряды Widelan», «Серый волк», «Храм Первого Света», «Слухи и задания»; справа — выбранное. В 3D за экраном камера опускается и кружит над городом. «Покинуть город» / Esc — обратно, облёт останавливается. |
| T27.3 | В городе «Слухи и задания». | Виден один слух (первый), остальных нет. |
| T27.4 | Мастер → «Карты» → Marblewolf → «Слухи» → «Открыть» у второго. | У игрока (экран города открыт) за 1–2 с появляется второй слух, после первого. «Скрыть» — пропадает. Открыть снова — встаёт в конец. |
| T27.5 | **Утечка.** DevTools игрока: `GET /api/player/maps/places/<id Marblewolf>`, WS-кадры; то же у стола `/api/table/maps/places/<id>`. | Нет `СЕКРЕТ-МАСТЕРА`, `noteGm`, `revealedAt`, `visible`, `npcId`, скрытого места «тайная комната» и скрытого слуха; нет полей, по которым можно сосчитать скрытое. |
| T27.6 | **Утечка.** Тот же запрос с id скрытого места (Havenwall) и с выдуманным id. | 404 в обоих случаях, одинаково. |
| T27.7 | Oroak → «Войти» → «Старый мост». | В описании моста — «Кто здесь»: «Тест: Тролль», роль «хозяин Старого моста», фигурка (если есть) или буква. Ни силы, ни заметок. |
| T27.8 | Мастер → «Кто здесь» у Oroak → выключить «Видно игрокам» у тролля. | У игрока тролль пропадает с экрана города без перезагрузки. |
| T27.9 | Мастер правит скрытое (место в городе со скрытым «Видно игрокам», скрытый слух, заметку). | Игроку и столу не приходит `map:place.changed` (WS-кадры). |
| T27.10 | Мастер → «Карточка» → «Картинка города» → загрузить картинку. | У игрока фон экрана города — эта картинка (затемнена слева). `/api/media/<файл>` у игрока — 200. Скрыть место — тот же адрес у игрока 404. |
| T27.11 | Мастер → новое место (Раздолье) → «Набросать» в описании (ключ Claude задан). | Через несколько секунд в поле — описание по-русски; не сохранено, пока не нажать «Сохранить карточку». «Набросать места» / «Набросать слухи» — список с «Добавить» у каждого; добавленные слухи — скрыты. |

| T27.14 | Стол в облегчённом режиме (`?lite=1`) → «На стол: город». | Пергамент, экран города поверх, без облёта. |
