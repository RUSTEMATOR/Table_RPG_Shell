# Этап 47 — ручные проверки (памятные моменты)

Подготовка: `npm run dev` (миграция 0021 применится сама), `npm run seed:dev`, персонаж выдан игроку 1. Мастер — «Игра» (лента) и страница персонажа. Игрок 1 — телефон, «Карточка», уведомления включены. Стол — `/table`.

| № | Шаги | Ожидание |
|---|---|---|
| T47.1 | Игрок 1 бросает d20 публично; мастер в ленте у этого броска → «Момент». | Форма: вид подставлен по исходу (крит → «Двадцатка», провал с осложнением → «Единица», иначе «Особый»), заголовок — подпись броска. У бросков мастера и бросков без персонажа кнопки «Момент» нет. |
| T47.2 | Мастер правит заголовок, добавляет пояснение → «Выдать». | «Момент выдан: <персонаж>». Стол: плашка слева внизу «<Имя>: <заголовок>» со значком, исчезает через ~10 с. Игрок: push «Памятный момент — <заголовок>» (если приложение свёрнуто); на «Карточке» внизу полка «Памятные моменты» со значком; на вкладке значок «есть новое». |
| T47.3 | Игрок нажимает значок момента. | Раскрывается: вид · дата. пояснение. Повторное нажатие сворачивает. |
| T47.4 | Мастер → страница персонажа → вкладка «Моменты». | Список с видом, заголовком, пояснением, заметкой (если была), датой; счётчик на вкладке. |
| T47.5 | Там же выдать вручную: вид «Спас товарища», заголовок, пояснение, заметка мастера → «Выдать момент». | Момент в списке и у игрока; плашка на столе; push. |
| T47.6 | «Убрать» момент (двумя нажатиями). | Исчезает у мастера и с карточки игрока без перезагрузки. |
| T47.7 | Ответ `/api/player/character` в DevTools. | `moments[]` — только `id, kind, title, text, at`; ни `noteGm`, ни `rollId`. В заметке мастера написать «СЕКРЕТ-МАСТЕРА» — у игрока и в WS-кадрах маркера нет. |
| T47.8 | Кадр `table:moment` на столе. | Ровно `character, kind, title, at`; пояснения нет. |
| T47.9 | Выдать момент персонажу без игрока. | Момент сохранён (виден на странице персонажа), push никому, плашка на столе есть. |
| T47.10 | Мастер на телефоне: лента → «Момент». | Форма помещается, выбор вида работает. |
