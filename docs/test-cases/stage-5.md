# Этап 5 — ручные проверки

Подготовка: мастер → «Участники» → пригласить «Общий экран», открыть ссылку на ноутбуке или ТВ. `npm run seed:dev` выполнен.
Сцены — у мастера в разделе «Стол».

| № | Шаги | Ожидание |
|---|---|---|
| T5.1 | Мастер: сцена с текстом для стола и заметками мастера `СЕКРЕТ-МАСТЕРА: засада за мостом` → «Показать на столе». На столе DevTools → Network (Fetch и WS) → поиск `СЕКРЕТ-МАСТЕРА`, `textGm`, `засада`. | На столе название, текст и картинка. Совпадений 0. |
| T5.2 | Мастер бросает «Скрытый», игрок — «Мне и мастеру», другой игрок — «Всем». | На столе только публичный бросок. |
| T5.3 | Загрузить к сцене фотографию 8 МБ (JPEG с телефона). Показать на столе. Network на столе: размер `/api/media/…`. | Картинка на ТВ за ≤2 с, передано меньше 600 КБ, у мастера подпись «… ×… , N КБ» со стороной не больше 1920. Портретное фото не повёрнуто набок. |
| T5.4 | Стол 30 минут без действий (ноутбук на питании, HTTPS — на этапе 1б). | Экран не гаснет (Wake Lock), индикатор зелёный. |
| T5.5 | Discord: «Демонстрация экрана» вкладки стола. Нажать «Анимация выкл.». Бросить несколько раз. | Новые броски появляются без анимации; кнопка запоминается после перезагрузки. |
| T5.6 | Мастер: «Партия» → перегрузка до глаз → «Показать столу». | На столе плашка «Имя: Глаза зеленеют», через 12 с исчезает. Числа нет. |
| T5.7 | Игрок в консоли: `fetch('/api/table/state').then(r=>r.status)` и прямой адрес картинки сцены. | `403` и `404`: картинки и сцены игрокам не отдаются. |
| T5.8 | Мастер: загрузить картинку к сцене, которая НЕ показана. Стол открывает прямой адрес этой картинки. | `404`: стол получает только картинку показанной сцены. |
| T5.9 | Мастер: «Убрать со стола». | На столе «Зеленогорье» без сцены. |
| T5.10 J | Текст для стола, который пересказывает скрытую черту одного из персонажей → «Показать на столе». | Предупреждение «похоже, выдаёт скрытую черту «…»», кнопки «Показать всё равно» / «Поправить». |
| T5.11 | Стол на телефоне вертикально и на ТВ горизонтально. | Вертикально броски под сценой, горизонтально — справа. Текст читается с дивана. |
