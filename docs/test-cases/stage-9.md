# Этап 9 — ручные проверки

Подготовка: `npm run dev` (миграция применится сама), `npm run seed:dev` — появится противник «Тест: Тролль» (сила 400, заметки с маркером). Стол открыт на ноутбуке, игрок на телефоне.

| № | Шаги | Ожидание |
|---|---|---|
| T9.1 | Мастер: «Противники» → «Новый» → имя, сила 120, заметки → «Сохранить» → «Добавить портрет» (фото с телефона). | Рядом с силой «Монструозный», портрет ≤1920 px, размер в КБ. |
| T9.2 | «Тест: Тролль» → «Сделать противником». Открыть «Игра» → «Сессия». | «Из библиотеки» — «Тест: Тролль · 400 (…)», поля «Противник» и сила заполнены. В «Противниках» у тролля «Противник сессии». |
| T9.3 | У персонажа игрока сила 40. Игрок бросает d10 до успеха. | «Лишь царапина», в ленте мастера «против «Тест: Тролль» 400». Тот же результат, что при ручном вводе (T3.1). |
| T9.4 | Пока тролль — противник, поменять ему силу на 45 → «Сохранить». | В «Сессии» сила сразу 45; следующий бросок игрока против 45. |
| T9.5 | В «Сессии» ввести противника руками → «Задать». | «Из библиотеки» — «не из библиотеки», у тролля пометки «Противник сессии» больше нет. |
| T9.6 | Тролль → «Показать на столе». | На столе портрет и имя. Вместе со сценой, если она показана. |
| T9.7 | **Утечка.** Стол: DevTools → Network (Fetch + WS) → поиск `СЕКРЕТ-МАСТЕРА`, `400`, `клад`, `notes`, `power`. | В ответах и кадрах стола только имя и ссылка на портрет. |
| T9.8 | **Утечка.** Игрок: DevTools во время T9.2–T9.6, поиск имени противника, `СЕКРЕТ-МАСТЕРА`, `npc`. Игрок в консоли: `fetch('/api/gm/npcs').then(r=>r.status)` и прямой адрес портрета. | Ничего в кадрах; `403` и `404`. |
| T9.9 | Стол открывает прямой адрес портрета другого, не показанного противника. | `404`. |
| T9.10 | «Убрать со стола» у противника; потом «Убрать портрет со стола» в шапке раздела. | Портрет исчезает со стола, сцена остаётся. |
| T9.11 | Удалить противника, который сейчас противник сессии и на столе («Точно удалить?»). | Со стола портрет пропал. В «Сессии» имя и сила остались как ручной ввод, «Из библиотеки» — «не из библиотеки». Ошибок в терминале нет. |
| T9.12 | Сцена с картинкой показана, противник показан: проверить, что картинка сцены по-прежнему открывается у стола (регресс после выноса конвейера картинок). | Картинка сцены и портрет на месте. |
