# Этап 53 — ручные проверки (фото сессии в летописи)

Подготовка: `npm run dev` (миграция 0026 применится сама). Мастер — «Летопись», сохранённая глава. Игрок 1 — «Летопись».

| № | Шаги | Ожидание |
|---|---|---|
| T53.1 | Мастер: новая глава до сохранения. | Вместо фото — «Фото сессии можно добавить, когда глава сохранена». |
| T53.2 | Глава сохранена, черновик → «Добавить фото», выбрать 3 фото с телефона (по 5–10 МБ). | Загрузка быстрая (сжатие в браузере), «Фото сессии · 3 из 24», превью в сетке. У игрока ничего нет (глава — черновик). |
| T53.3 | Игрок запрашивает `/api/media/<файл фото>` черновика (имя из DevTools мастера). | 404. |
| T53.4 | Мастер → «Опубликовать». | У игрока: глава с фото под текстом, «Альбом · 3» над главами. Нажатие на фото — целиком; в альбоме заголовок — название главы, подпись ниже. |
| T53.5 | Мастер пишет подпись (уход фокуса сохраняет). | У игрока подпись обновилась без перезагрузки. |
| T53.6 | Мастер удаляет фото. | Пропало у игрока; в `data/media` нет ни `<id>.webp`, ни `<id>.t.webp`. |
| T53.7 | Мастер снимает главу с публикации. | Глава и её фото исчезли у игрока, «Альбом» уменьшился; файлы отдают 404 игроку. |
| T53.8 | Удалить главу с фото. | Файлы фото удалены из `data/media`. |
| T53.9 | Попытка добавить 25-е фото. | «Не больше 24 фото в главе». |
| T53.10 | Стол запрашивает файл фото опубликованной главы. | 404. |
| T53.11 | Ответ `/api/player/chronicle`: у главы `photos[]` — `id, caption, image{url, thumb, hash, w, h}`. | Так; ничего лишнего, СЕКРЕТ-МАСТЕРА нет. |
