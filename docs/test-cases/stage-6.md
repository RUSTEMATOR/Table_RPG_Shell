# Этап 6 — ручные проверки

Подготовка: добавить в `~/.config/zelenogorye/.env.development` строку `ANTHROPIC_API_KEY=…` (ключ из Console, с месячным лимитом), перезапустить `npm run dev`.
Модели по умолчанию: `claude-sonnet-5-5` — «Написать», `claude-haiku-4-5` — «Быстрый черновик». Поменять можно через `ANTHROPIC_MODEL_SUMMARY` и `ANTHROPIC_MODEL_DRAFT`.
Сводки — на странице персонажа-попаданца у мастера, блок «Сводки».

| № | Шаги | Ожидание |
|---|---|---|
| T6.1 | У персонажа с несколькими скрытыми чертами: «Вступление для игрока» → «Написать». Прочитать. | В тексте нет скрытых черт, их признаков и названий. В основе — только раскрытое (вступление строится из `projectForPlayer`). |
| T6.2 | Не публикуя, открыть карточку у игрока и `/api/player/character` в DevTools. | Вступления нет нигде. |
| T6.3 | Поправить текст руками → «Сохранить правку» → «Опубликовать игроку». | Перед публикацией Jev проверяет (с ключом Jev). Если он нашёл выдумки или утечку — предупреждение и «Опубликовать всё равно». После публикации игрок видит текст в карточке за 1–2 с. |
| T6.4 | «Переписать» опубликованное вступление. | Новый текст сразу становится неопубликованным: игрок больше не видит старый и не видит новый до «Опубликовать». |
| T6.5 | «Сцена перехода» → «Написать» → «Опубликовать игроку». | Jev проверяет текст на утечку скрытых черт (сцена строится с признаками скрытых черт, без названий). При совпадении — предупреждение. |
| T6.6 | «Сводка для мастера» → «Написать», затем «Проверить выдумки». | Сводка с «## Зацепки» и «## Куда это может привести». Проверка показывает подозрительные предложения или «ничего не нашёл». Кнопки публикации у сводки мастера нет. |
| T6.7 | «Быстрый черновик» для любой сводки. | Текст приходит быстрее, под ним `claude-haiku-4-5…`. |
| T6.8 | Поиск ключей: `grep -r "sk-ant" web/dist server/dist logs` и `git log -p \| grep -c "sk-ant"`. | 0 совпадений. |
| T6.9 | Испортить `ANTHROPIC_API_KEY`, перезапустить, «Написать». Потом выключить Wi-Fi и «Написать». | «Claude API не принял ключ.» / «Нет связи с Claude API.» Сервер работает, броски идут. |
| T6.10 | Убрать `ANTHROPIC_API_KEY` совсем. | На странице «Ключ Claude API не задан», кнопки «Написать» неактивны, править и публиковать готовый текст можно. |
