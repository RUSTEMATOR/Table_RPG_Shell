# Этап 45 — ручные проверки (слухи по расписанию, сказы)

Подготовка: `npm run dev` (миграция 0019 применится сама), `npm run seed:dev`. Мастер — «Карты» → открытый город → «Слухи». Игрок 1 и игрок 2 — в городе (отряд рядом, «Войти в город»), уведомления включены. Стол — «На стол: город».

| № | Шаги | Ожидание |
|---|---|---|
| T45.1 | Мастер: у скрытого слуха «Открыть в…» → время через 2 минуты → «Запланировать». | Бейдж «откроется <время>». У игроков слуха нет (`/api/player/maps/places/<id>` без него). Через ≤2,5 мин слух открыт, игрокам пришёл push «<Город> — Новый слух», слух появился в «Слухах и заданиях» без перезагрузки. |
| T45.2 | Запланировать и затем «Снять»; запланировать и «Открыть» руками. | После «Снять» — «скрыт». После ручного открытия расписание снято (бейдж «Открыт», в базе `reveal_at` NULL). |
| T45.3 | Перезапустить сервер с запланированным слухом на минуту вперёд. | Открывается вовремя (планировщик стартует сразу). |
| T45.4 | Игрок 1 открывает «Слухи и задания» в городе, затем игрок 2. | У обоих под слухом «Первым услышал(а): <персонаж игрока 1>»; у мастера в карточке слуха — то же. Повторное открытие ничего не меняет. |
| T45.5 | Игрок снаружи города (отряд далеко) шлёт `POST /api/player/maps/rumors/<id>/heard`. | 404. |
| T45.6 | Игрок 2 → «Рассказать сказ» → текст → «Отправить мастеру». | У игрока 2 — «Твой сказ · ждёт мастера»; у игрока 1 и на столе ничего нет; мастеру push «Сказ игрока — <персонаж> — <город>», в «Слухах» сверху карточка «сказ · <автор>» с «Принять» / «Отклонить». |
| T45.7 | Мастер → «Принять». | Слух открыт, у всех игроков и на столе — с подписью «рассказал(а) <персонаж игрока 2>»; игроку 2 push «Сказ принят»; у него пометка «ждёт мастера» исчезла. |
| T45.8 | Ещё один сказ → «Отклонить». | Удалён; игроку 2 push «Сказ не принят»; у него сказ пропал из списка. |
| T45.9 | Игрок отправляет четвёртый ожидающий сказ в том же городе. | 429 `too_many`, подсказка «Не больше трёх…». |
| T45.10 | Мастер правит текст принятого сказа. | Текст меняется у игроков, подпись автора остаётся. |
| T45.11 | Ответ `/api/player/maps/places/<id>` и `/api/table/maps/places/<id>`. | В `rumors` — `id, kind, text, by, firstBy`; ни id участников, ни `proposed`, ни `revealAt`; ожидающих сказов нет. В `by`/`firstBy` — имена персонажей. СЕКРЕТ-МАСТЕРА нет. |
| T45.12 | В тексте сказа написать «СЕКРЕТ-МАСТЕРА». | 400. |
| T45.13 | Удалить персонажа автора сказа (или снять его с игрока). | Сказ остаётся, подпись — имя участника. |
| T45.14 | Письма (этап 42) по-прежнему доставляются по расписанию. | Да: общий планировщик обслуживает и письма. |
