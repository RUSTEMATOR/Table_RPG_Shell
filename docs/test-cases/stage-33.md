# Этап 33 — ручные проверки

Подготовка: `npm run dev`, `npm run seed:dev`. Мастер на ноутбуке, игрок на телефоне, стол на ТВ.

| № | Шаги | Ожидание |
|---|---|---|
| T33.1 | Мастер: «Противники» → «+ Фигурка». | Вверху «Человек / Существо», открыто «Человек» — конструктор как раньше. |
| T33.2 | «Существо». | Сетка из 10 существ с картинками и подписями; у глаза, большого червя, тыквенного короля — «издали». Превью сверху меняется по нажатию; повороты и позы «Стоит / Идёт / Удар / Ранен» работают у каждого (призрак «Ранен» — полупрозрачный). |
| T33.3 | Выбрать летучую мышь → «Сохранить фигурку»; закрыть и открыть снова. | Открывается «Существо», выбрана мышь. На кнопке у противника — мышь. |
| T33.4 | Переключить «Человек», поменять волосы, обратно «Существо». | Выбор существа и собранный человек не теряются при переключении. «Случайно» в «Существе» даёт случайное существо. |
| T33.5 | Карты: поставить мышь на карту, открыть её игрокам, перетащить. | У игрока и на столе мышь летит к новой точке, повернувшись по движению; на 3D-карте — тоже. Цветок-людоед — крупнее человека, пчела — меньше. |
| T33.6 | Город: мышь «Кто здесь». | В экране города у игрока — фигурка мыши. |
| T33.7 | Бой: противник сессии — змея с фигуркой, показан на столе; игрок с фигуркой бросает «Всем» (успех, крит, провал). | Игрок подходит и бьёт, змея на ответном ударе делает выпад. Противник «глаз» — атакует с места (лазер). |
| T33.8 | Игрок: вкладка «Фигурка». Мастер: страница персонажа → «Фигурка». | Переключателя «Человек / Существо» нет. |
| T33.9 | **Права.** Игрок: `POST /api/player/character/figure` с телом `{"v":1,"creature":"bat"}`. Мастер: то же в `/api/gm/characters/<id>/figure`. | 400 оба раза. |
| T33.10 | **Утечка.** Игрок: `GET /api/player/maps/razdolye` с открытой мышью на карте. | У жетона `figure` — ровно `{"v":1,"creature":"bat"}`; ни силы, ни заметок, ни id противника. |
| T33.11 | Старые фигурки персонажей и противников. | Открываются и рисуются как раньше. |
| T33.12 | «Авторы графики». | Абзац «Существа противников — [LPC] Monsters: Charles Sanchez (CharlesGabriel), bagzie, bluecarrot16 …». |
