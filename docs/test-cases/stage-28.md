Подготовка: `npm run db:migrate` (миграция `0011_travel`), `npm run seed:dev`. Отряд — у Marblewolf; открыты Marblewolf, Oroak, Eriflower, Magewald, Castlefair (между некоторыми есть открытые дороги). Мастер на ноутбуке, игрок на телефоне, стол на ТВ с картой Раздолья.

| № | Шаги | Ожидание |
|---|---|---|
| T28.1 | Игрок → «Карта» → навести мышь на табличку Oroak (на телефоне — открыть карточку). | Подсказка «… · ≈ N дней пешком». В карточке: «От отряда: ≈ N дней пешком · ≈ M дней верхом», «по дорогам» или «часть пути — без дороги»; на карте золотая линия от знамени до Oroak по дорогам. Закрыть карточку — линия пропадает. |
