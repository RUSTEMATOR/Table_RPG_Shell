# Этап 40 — ручные проверки (свои шрифты, лёгкие картинки)

Подготовка: `npm run dev` (миграция 0014 применится сама; при запуске сервер досчитает превью старых картинок — в логе «media: превью и хэши досчитаны»). Игрок — на телефоне, мастер — на ноутбуке, стол — `/table`. В DevTools открыть «Сеть».

| № | Шаги | Ожидание |
|---|---|---|
| T40.1 | Открыть экран игрока, в «Сети» отфильтровать `googleapis`, `gstatic`. | Ни одного запроса к Google. В `index.html` нет `preconnect` к Google. |
| T40.2 | «Карточка» → «Оформление» → несколько тем из разных оболочек (Книга, Летопись, Терминал, Манга, Пиксель). | Шрифты темы и оболочки появляются как раньше. В «Сети» — файлы `/assets/<семейство>-cyrillic-…woff2` с своего хоста, по 4–40 КБ. |
| T40.3 | Тема с набором украшений (например, «Пергамент» или «Руны»). | Шрифт заголовков набора (Ruslan Display, Cormorant Unicase…) грузится с своего хоста. |
| T40.4 | «Карта» (пергамент и 3D). | Названия земель — Cormorant SC, мест — Cormorant Garamond, с своего хоста. |
| T40.5 | Установленное PWA: открыть приложение, посмотреть несколько тем, включить авиарежим, перезапустить приложение, вернуться к тем же темам. | Шрифты просмотренных тем на месте без сети (кэш `zg-fonts`). Непросмотренная тема — запасными шрифтами, без ошибок. |
| T40.6 | DevTools → Application → Cache Storage после установки. | В предкэше (workbox-precache) из woff2 только `lora-*` и `poppins-*` (11 файлов). Остальные — в `zg-fonts` по мере показа. |
| T40.7 | Мастер → «Противники» → загрузить с телефона фото 8–15 МБ (JPEG). | Загрузка быстрая: в «Сети» тело запроса ≈ 1–2 МБ. Портрет появляется; у ответа `image` есть `thumb` и `hash`. |
| T40.8 | Там же загрузить HEIC с iPhone. | Принимается как раньше (сервер читает HEIC); портрет на месте. |
| T40.9 | Мастер → «Карты» → карточка города → «Картинка города». Игрок открывает карточку этого города (сеть DevTools — «Slow 3G»). | Сначала размытое цветовое пятно картинки, затем проявляется сама. Запрос `/api/media/<id>.webp` (полный файл — это фон). |
| T40.10 | Мастер → «Противники», список с портретами; «Стол» → сцена с картинкой; «На столе» в боковой панели. | Маленькие рамки берут `<id>.t.webp` (превью), не полный файл. Размер превью — десятки КБ. |
| T40.11 | Игрок с противником сессии (рамка портрета в «Бросках»). | Портрет из превью, с размытым пятном до загрузки. |
| T40.12 | Игрок без входа запрашивает `/api/media/<id>.t.webp` картинки скрытого места или не показанного противника. | 404, как и для полного файла. Открыть место / показать противника — превью отдаётся. |
| T40.13 | Ответы `/api/player/maps/...` (карточка места) и `/api/table/state` в DevTools. | `image` — ровно `url, thumb, hash, w, h`; ничего лишнего, СЕКРЕТ-МАСТЕРА нет. |
| T40.14 | Удалить картинку сцены / противника / города. | В `data/media` исчезают оба файла: `<id>.webp` и `<id>.t.webp`. |
| T40.15 | Стол: показать сцену с картинкой, сменить на другую. | Как раньше: новая появляется после полной загрузки, плавный переход. |
| T40.16 | `npm run build`. | Собирается; в `dist/assets` ≈ 150 файлов woff2 (~3 МБ), `sw.js` содержит правило `zg-fonts`. |
