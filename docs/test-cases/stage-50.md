# Этап 50 — ручные проверки (бестиарий)

Подготовка: `npm run dev` (миграция 0024 применится сама), `npm run seed:dev`. Мастер — «Противники»: у двух противников включить «В бестиарии», одному написать описание, «Сохранить». Игрок 1 — «Летопись», уведомления включены.

| T50.1 | Игрок открывает «Летопись». | Сверху «Бестиарий · открыто 0 из 2»: два силуэта «?». До включения флагов карточки не было. |

| T50.4 | Мастер → «Начать новую сессию», снова делает то же чудище противником. | «бои: 2» у мастера и в листе игрока. |
