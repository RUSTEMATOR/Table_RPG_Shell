# Этап 23 — ручные проверки

Подготовка: `npm run dev`, `npm run seed:dev`. Игрок на телефоне, мастер на ноутбуке. Можно и гостем: «Посмотреть без входа» → «Игрок» / «Мастер».

| № | Шаги | Ожидание |
|---|---|---|
| T23.1 | Игрок → вкладка «Фигурка» (между «Карточкой» и «Дневником»). | Превью на клетчатом фоне: фигурка по центру идёт на месте. До первого сохранения — стандартная фигурка (каштановые длинные волосы, зелёная рубаха, штаны, сапоги). Кнопка «Сохранить фигурку» неактивна. |
| T23.2 | Стрелки «‹» «›» у превью; «Стоит» / «Идёт» / «Удар» / «Ранен». | Фигурка поворачивается на четыре стороны. «Удар» — анимация оружия (без оружия — взмах рукой), «Ранен» — падает. Пиксели чёткие, без размытия. |
| T23.3 | Части: «Тело» → «Мужское»/«Женское», кожа; «Лицо» → орк, скелет, волк и т. д. | Миниатюры вариантов показывают фигурку с этой деталью. Телосложение меняет и голову человека. Кожа меняет тело, голову и босые ноги. При выборе головы не-человека кожа сама становится её цвета (орк — зелёный, волк — бурый), потом её можно поменять. |
| T23.4 | «Волосы», «Одежда», «Броня», «Ноги», «Обувь», «На голове», «Плащ», «Борода»: варианты и цвета. | Выбранный вариант в рамке; кружки цветов перекрашивают деталь; «Нет» у необязательных частей убирает деталь. Детали, которых нет для выбранного телосложения, не показываются. |
| T23.5 | «Оружие»: меч, булава, копьё, лук, посох и т. д.; поза «Удар». | Под миниатюрой — вид удара (удар, выпад, выстрел, заклинание). Меч и булава бьют крупным замахом за пределы клетки; у лука летит стрела. |
| T23.6 | «Случайно» несколько раз → «Сохранить фигурку». | Каждый раз новая цельная фигурка. После сохранения — «Фигурка сохранена», кнопка снова неактивна. Перезагрузить страницу — фигурка та же. |
| T23.7 | Мастер → «Партия» → персонаж этого игрока → вкладка «Фигурка». | Та же фигурка. Изменить, «Сохранить фигурку» — у игрока во вкладке обновляется за 1–2 с (если игрок в этот момент сам ничего не менял). «Убрать фигурку» — у персонажа снова стандартная. |
| T23.8 | Мастер → «Противники» → у противника «+ Фигурка». | Лист с конструктором. Собрать (например, скелет с копьём) → «Сохранить фигурку». В карточке противника на кнопке — маленькая фигурка, подпись «Фигурка». «Убрать фигурку» — снова «+ Фигурка». |
| T23.9 | Внизу конструктора «Авторы графики». | Лист со списком художников LPC и лицензиями; «полный список по файлам» открывает `/lpc/CREDITS.csv`. |
| T23.10 | **Утечка.** Игрок: DevTools → `/api/player/character`, WS-кадры. | Поле `figure` — только описание деталей (`v`, `body`, `skin`, `parts`). Нет `СЕКРЕТ-МАСТЕРА`, нет полей мастера. |
| T23.11 | **Права.** Игрок шлёт `POST /api/gm/npcs/<id>/figure` и `POST /api/gm/characters/<id>/figure`; стол шлёт `POST /api/player/character/figure`. | 403. |
| T23.12 | **Проверка данных.** `POST /api/player/character/figure` с лишним полем, с `"v": 2`, с id детали `"../x"`. | 400, фигурка не меняется. |
| T23.13 | Игрок без персонажа → «Фигурка». | «Фигурку можно собрать, когда мастер выдаст тебе персонажа.» |
| T23.14 | Первая загрузка экрана игрока (вкладка «Броски»), DevTools → Network. | Картинки `/lpc/…` и чанк конструктора не грузятся, пока не открыта «Фигурка». После открытия листы кэшируются (повторно — из кэша `zg-figures`). |
| T23.15 | Телефон без сети после того, как фигурка уже открывалась. | Фигурка показывается из кэша. Детали, которые ни разу не открывались, — пустые миниатюры, без ошибки экрана. |
