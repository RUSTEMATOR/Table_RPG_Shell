# Этап 58 — ручные проверки (модели 3D-карты)

Подготовка: `npm run dev`; на карте открыты места видов «Крипта», «Культ», «Лагерь вампиров», «Храм» (или создать их у мастера в «Картах»). Игрок или мастер — «Карта» → 3D.

| № | Шаги | Ожидание |
|---|---|---|
| T58.1 | Подлететь к крипте. | В центре — каменный склеп (по высоте как храм), вокруг — могилы и надгробия, 2–3 мёртвых дерева, фонарный столб, отрезок кованой ограды. Модели стоят на земле, не висят и не тонут. |
| T58.2 | Цвета на склепе, могилах, деревьях. | Похожи на камень, дерево, землю — без кислотных пятен и «радуги». Если какая-то модель выглядит плохо — записать её id (`crypt_h`, `grave_a`…) для удаления из набора. |
| T58.3 | Культ. | Помост с алтарём со свечами, кольцо камней, флаг, шатры, фонари, мёртвое дерево. |
| T58.4 | Лагерь вампиров. | Руина, шатры, бочки, два гроба, фонари, мёртвые деревья. |
| T58.5 | Храм. | Рядом 3–4 надгробия. |
| T58.6 | Деревни и города. | Без изменений. |
| T58.7 | Первая загрузка 3D-карты после обновления (DevTools «Сеть»). | `world.glb` качается заново (новая версия в `?v=`), ~960 КБ. |
| T58.8 | «Авторы графики». | Есть ссылка на KayKit Halloween Bits. |
