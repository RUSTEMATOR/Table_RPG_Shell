# Этап 19 — ручные проверки

Подготовка: `npm run dev`; мастер в Chrome на ноутбуке (окно на весь экран, потом уже), игрок на телефоне.

| № | Шаги | Ожидание |
|---|---|---|
| T19.1 | Мастер: окно 1440 px, `/gm`. | Слева разделы со значками, в середине «Противник сессии», «Бросок мастера», «Партия»; справа «Сейчас в игре»: лента с мини-лотком, «Запросы», «На столе». Кнопки «Сейчас в игре» в шапке нет. |
| T19.2 | Переходить по разделам. | Правая колонка не мигает и не перезагружается, лента остаётся прокрученной. Активный раздел подсвечен. |
| T19.3 | Сузить окно до ~900 px, потом до ~600 px. | ~900: колонки справа нет, в шапке «Сейчас в игре» — открывает лист с той же колонкой; на «Игре» появилась «Лента». ~600: разделы вкладками сверху. |
| T19.4 | Игрок задаёт вопрос в дневнике. | Число у «Запросов» в навигации и у кнопки «Сейчас в игре» растёт сразу; вопрос в колонке. После ответа — пропадает. |
| T19.5 | ⌘K (Ctrl+K в Windows/Linux), набрать «мост». | Палитра по центру, сцена «Мост…» в списке; ↵ — уведомление ««…» на столе», на столе сцена. Esc закрывает. |
| T19.6 | Сцена, текст которой выдаёт скрытую черту; показать её из палитры. | Уведомление «Страж Jev сомневается…», открывается «Стол», на стол сцена **не** ушла. |
| T19.7 | Палитра → «Бросок d20 скрытно». | Уведомление «d20 скрытно: N — …», бросок в ленте мастера «скрыто». У игрока и на столе его нет. |
| T19.8 | Палитра → персонаж → открыть; палитра → противник «в сессию». | Страница персонажа; противник сессии сменился, уведомление. |
| T19.9 | `G` затем `R`; `G` затем `I`. Курсор в поле заметок — `G` `R`. | «Запросы», «Игра». В поле — просто печатаются буквы. |
| T19.10 | Страница персонажа, 1440 px. | Путь «Партия › Имя», шапка, вкладки «Черты · N / Лист / Сводки / Заметки»; справа «Как увидит игрок». «Сейчас в игре» — кнопкой в шапке. |
| T19.11 | Ступень «+» у черты. | Название ступени меняется сразу, без ожидания; у игрока — за 1–2 с. |
| T19.12 | Отключить сеть (DevTools → Offline), нажать «+». | Ступень на миг меняется, затем уведомление «Нет связи: изменение не сохранилось», после включения сети — страница как на сервере. |
| T19.13 | «Раскрыть черту», ползунок ступеней, «Показать цену». | Переключатели срабатывают сразу; «Игрок видит: …» обновляется; предпросмотр справа — после ответа сервера. |
| T19.14 | Сохранить подсказку, выдающую другую черту. | Предупреждение стража, «Сохранить всё равно» / «Поправить» — как раньше. |
| T19.15 | «Лист»: добавить запись, выключить «видна игроку». | Запись с пунктирной рамкой; у игрока её нет. |
| T19.16 | «Сводки»: «Опубликовать игроку». | Проверка Jev, затем уведомление «Сводка опубликована игроку». |
| T19.17 | Узкое окно, страница персонажа → «Как увидит игрок». | Лист снизу с карточкой игрока. |
| T19.18 | «Заметки» в двух вкладках, править в обеих. | Значок «Есть изменения» → «Сохраняю» → «Сохранено»; во второй вкладке — окно «Заметки изменились…», закрывается только выбором. |
| T19.19 | «Стол»: «Показать на столе», «Убрать со стола», новая сцена, удаление. | Уведомления; карточки появляются и исчезают плавно; показанная сцена с рамкой и значком «Сейчас на столе». |
| T19.20 | «Противники»: «Сделать противником», «Показать на столе». | Значки «Противник сессии», «Портрет на столе»; уведомления. |
| T19.21 | «Участники»: создать ссылку, «Копировать». | Ссылка в зелёной рамке, уведомление «Ссылка скопирована». |
| T19.22 | Игрок бросает d20, мастер смотрит на правую колонку. | В мини-лотке катится кубик, после посадки — плашка «Имя N Исход»; три броска подряд проигрываются по очереди. Свои броски мастера в мини-лотке не появляются. |
| T19.23 | Узкое окно (колонка скрыта), игрок бросает. | Ничего не просчитывается (DevTools → Performance: нет работы WebGL), лента обновляется. |
| T19.24 | «Новый персонаж»: попаданец, местный, импорт. | Режимы сегментом; списки открываются, «не указано» / «не выбрана» работают; после сохранения — страница персонажа и уведомление. |
| T19.25 | Тема «Ночь» и «День» на всех страницах. | Цвета, рамки, значки читаются; списки и палитра в цветах темы. |
| T19.26 | **Утечка.** Игрок: DevTools → Network, сетевые ответы и WS-кадры, пока мастер работает с палитрой, ступенями, листом. | Ни `СЕКРЕТ-МАСТЕРА`, ни скрытых бросков, ни заметок мастера. Чанки `GmLayout`, `cmdk` у игрока не грузятся. |
