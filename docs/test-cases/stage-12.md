# Этап 12 — ручные проверки

Подготовка: `npm run dev`. Персонаж «Life in Tearz» (импорт из рандомизатора, Сайлент Хилл, с портретом) у игрока «Life in Tearz»; для сравнения — тот же персонаж в артефакте «Переход в Зеленогорье», вид «Мой персонаж».

| № | Шаги | Ожидание |
|---|---|---|
| T12.1 | Игрок «Life in Tearz» → «Карточка». Рядом открыть артефакт. | Оформление «Туман»: фон, шрифт имени, орнамент со знаком, рваные края карточек, ступени с насечкой, значки категорий — как в артефакте. Сначала «Вступление», потом черты. |
| T12.2 | Нажать на портрет, несколько раз подряд. | Портрет поворачивается с отскоком; нажатие во время поворота добавляет ровно один поворот. |
| T12.3 | Нажать в разные места карточки. | Круги и частицы пепла от точки нажатия; фоновые частицы медленно летят. В системе включить «Уменьшить движение» → частиц нет, портрет при нажатии только мигает. |
| T12.4 | Аня (персонаж «Мира») → «Карточка». | Тема по её вселенной или жанру; без портрета — круглый знак темы, он тоже поворачивается. |
| T12.5 | Телефон, узкий экран. | Портрет над именем, ничего не вылезает по ширине, кнопки снаряжения нажимаются. |
| T12.6 | «Снаряжение» → «Добавить», «Изменить», «Удалить». | Работает как на этапе 10, в оформлении темы. |
| T12.7 | Мастер → персонаж → «Как увидит игрок». | Та же карточка в теме, без частиц. |
| T12.8 | **Утечка.** Аня: DevTools → Console: `fetch('/api/characters/<id Life in Tearz>/portrait').then(r=>r.status)`. Стол: то же. | 404 в обоих случаях. Владелец и мастер получают картинку. |
| T12.9 | **Утечка.** Игрок с скрытыми чертами (Борис): Network → `/api/player/character`, WS-кадры `character:updated`. | Нет `catKey`/`setting` для нераскрытых черт, число черт не выдаёт скрытые. Поиск `СЕКРЕТ-МАСТЕРА` — 0 совпадений. |
| T12.10 | DevTools → Network → Request blocking: `fonts.googleapis.com`. Перезагрузить, открыть «Карточку». | Карточка в запасных шрифтах, вёрстка не ломается, оформление и частицы работают. |
