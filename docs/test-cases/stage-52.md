# Этап 52 — ручные проверки (отклики на стол)

Подготовка: `npm run dev`. Игрок 1 — телефон, «Броски». Стол — `/table`.

| № | Шаги | Ожидание |
|---|---|---|
| T52.1 | Игрок открывает «Броски». | Под лотком «Отклик на стол»: «Ох!», «Брр…», «Ха!», «Ура!» со значками. У мастера в лотке этого ряда нет. |
| T52.2 | Игрок нажимает «Ха!». | Кнопка коротко подсвечивается, на Android — вибрация. На столе снизу всплывает значок с «Ха!» и именем персонажа, тает за ~3 с. |
| T52.3 | Игрок жмёт 10 раз подряд быстро. | На столе — не больше 6 значков за 10 секунд; остальные не появились. Ошибок на телефоне нет. |
| T52.4 | Два игрока жмут одновременно. | Значки разных игроков всплывают в разных местах по горизонтали. |
| T52.5 | Игрок без персонажа. | Под значком — имя игрока. |
| T52.6 | Стол с «Анимация выкл.». | Значки появляются и исчезают без полёта. |
| T52.7 | DevTools мастера и другого игрока. | Событий `table:reaction` у них нет. В базе ничего не появилось. |
| T52.8 | Отправить `player:react` с `{kind: "boo"}` или с текстом. | Отброшено, на столе ничего. |
