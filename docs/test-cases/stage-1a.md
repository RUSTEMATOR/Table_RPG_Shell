# Этап 1а — ручные проверки

Подготовка (один раз):
1. `npm install`
2. `npm run setup:dev` — название комнаты, имя мастера, пароль. Запишите код комнаты.
3. `npm run dev`. Vite напечатает адреса: `Local` (для Mac) и `Network` (для телефона в той же Wi-Fi).

Вход мастера: открыть адрес → код комнаты → своё имя → пароль.

| № | Шаги | Ожидание |
|---|---|---|
| T1.7 | Мастер: «Пригласить» → имя «Тест», роль «Игрок» → скопировать ссылку. На телефоне открыть, задать PIN, войти. Потом открыть ту же ссылку ещё раз (в другом браузере или после выхода). | Первый раз — вход, экран игрока. Второй раз — «Ссылка уже использована» и кнопка «Войти по коду и PIN». |
| T1.7а | Новая ссылка для игрока → отправить себе в Telegram, дождаться превью → открыть. | Страница «Войти как …» открывается, вход работает. |
| T1.8 | На экране входа выбрать игрока A, ввести неверный PIN 6 раз. Затем с того же устройства выбрать игрока B и войти правильно. | На 6-й попытке A — «Слишком много попыток…». B входит нормально. |
| T1.8а | Игрок A после блокировки ждёт 15 минут. | A снова может войти. |
| T1.9 | Телефон игрока: включить авиарежим на 30 с, выключить. | Индикатор: зелёный → жёлтый или красный → снова зелёный без перезагрузки страницы. |
| T1.11 | В приватном окне открыть `/gm`. DevTools → Network. | Переход на `/login`. В Network только `/api/me` с 401, никаких `/api/gm/*`. |
| T1.11а | Войти игроком, в адресной строке открыть `/gm`, затем `/gm/jev`. | Возврат на `/player`. |
| T1.11б | Игроком в консоли браузера: `fetch('/api/gm/members').then(r => r.status)` | `403`. |
| T1.13 | `npm run dev` работает, проверить, что `data/dev.sqlite` создан, а прод-база не трогалась. | Есть только `data/dev.sqlite`. |
| T1.15 | Мастер: «Новая ссылка» для уже вошедшего игрока, игрок входит по ней с другого телефона и задаёт новый PIN. | Старый PIN больше не подходит, новый подходит. |
| T1.16 | Стол: мастер создаёт участника с ролью «Общий экран», ссылку открыть на ноутбуке. | Экран стола без кнопки «Выйти», без запроса PIN. На экране входа по коду стола в списке нет. |
| T1.17 | Выйти и войти обратно на экране мастера. | После «Выйти» — экран входа; код комнаты подставлен сам. |

PWA, Wake Lock, HTTPS, перезагрузка Mac и внешний доступ проверяются на этапе 1б: для них нужен HTTPS и домен.
