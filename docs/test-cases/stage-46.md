# Этап 46 — ручные проверки (расписание и явка)

Подготовка: `npm run dev` (миграция 0020 применится сама), `npm run seed:dev`. Мастер — «Игра» → «Расписание». Игрок 1 и игрок 2 — телефоны, «Дневник», уведомления включены.

| № | Шаги | Ожидание |
|---|---|---|
| T46.1 | Игроки открывают «Дневник» до каких-либо действий мастера. | Карточки «Следующая игра» нет. |
| T46.2 | Мастер добавляет вариант (дата через неделю, 4 ч, заметка). | У игроков push «Когда играем?» и карточка «Когда играем?» с вариантом и заметкой, без перезагрузки. У мастера вариант под «Голосование». |
| T46.3 | Мастер добавляет второй вариант. | Второго push нет; у игроков два варианта по времени. |
| T46.4 | Игрок 1 — «Буду» у первого, «Не смогу» у второго; игрок 2 — «Может быть» у первого. | Под вариантами имена персонажей по ответам; на кнопках счётчики; у мастера то же. Повторный ответ меняет прежний (один на участника). |
| T46.5 | Мастер → «Назначить» первый. | Push «Игра назначена — <дата>»; у игроков «Следующая игра» с датой и «через N дней», кнопки явки сброшены (без ответа), «В календарь». Второй вариант исчез везде. У мастера — «назначена», явка пустая, «без ответа: <имена>». |
| T46.6 | Игрок 1 — «Буду»; скачать «В календарь». | У мастера явка обновилась, «без ответа» — только игрок 2. Файл `.ics` открывается календарём: событие «Зеленогорье — игра (<комната>)», время и длительность верны, заметка в описании. |
| T46.7 | Мастер → «Напомнить сейчас». | Push «Напоминание об игре — <дата>» игрокам. |
| T46.8 | Назначить игру через 23 часа (новый вариант → «Назначить»), подождать до минуты. | Push «Игра завтра — <дата>» один раз (в логе `schedule: напоминания отправлены`); флаг `reminded_day` в базе. Перезапуск сервера повторного push не даёт. |
| T46.9 | Назначить игру через 50 минут. | Push «Игра через час» один раз; «Игра завтра» не приходит (до игры меньше часа). У игрока отсчёт «через N минут». |
| T46.10 | Назначить игру на уже прошедшее время нельзя (поле `min`); в базе руками поставить прошедшую — открыть «Дневник». | Слот исчез из карточки и из базы (прошедшие удаляются при чтении). |
| T46.11 | Мастер → «Отменить». | Push «Игра отменена»; карточка у игроков пропала. |
| T46.12 | Ответы `/api/player/schedule` в DevTools. | `planned`/`options` с `id, startsAt, durationMin, note, answers[{name, answer}], my`; имена — персонажей, id участников нет. СЕКРЕТ-МАСТЕРА нет. |
| T46.13 | Стол запрашивает `/api/player/schedule` и `/api/schedule/<id>/ics`. | 403 на оба. |
| T46.14 | Мастер на телефоне: «Расписание». | Поля даты, часов и заметки помещаются; кнопки читаемы. |
