# Этап 41 — ручные проверки (push-уведомления)

Подготовка: `npm run vapid:dev` (один раз), перезапустить `npm run dev` (миграция 0015 применится сама; в логе «push: уведомления enabled: true»). Телефон игрока — через QA-хост (HTTPS); на iOS — приложение добавлено на экран «Домой». Мастер — на ноутбуке в Chrome. Второй браузер без ключей не нужен: для T41.1 временно убрать `VAPID_*` из `.env.development`.

| № | Шаги | Ожидание |
|---|---|---|
| T41.1 | Запустить dev без ключей VAPID. Экран игрока и мастера. | Колокольчика в шапке нет. `GET /api/push/key` → `{"enabled":false,"key":null}`. «Позвать за стол» у мастера отвечает «На сервере нет ключей VAPID…». |
| T41.2 | `npm run vapid:dev` дважды. | Первый раз: «Ключи VAPID записаны…», в `.env.development` появились две строки (ключи в терминал не печатаются). Второй: «уже есть — ничего не менял». |
| T41.3 | С ключами: игрок нажимает колокольчик. | Запрос разрешения браузера → колокольчик становится «включён» (сплошной). `POST /api/push/subscribe` → `{ok:true}`; в базе строка `push_subscription` с label вида «Safari на iPhone». |
| T41.4 | Игрок сворачивает приложение. Мастер → «Карты» → по предложению игрока «Вести отряд». | На телефоне уведомление «Отряд идёт — Идём в <место>». Нажатие открывает приложение на вкладке «Карта». |
| T41.5 | Игрок держит приложение открытым на экране. Мастер отклоняет другое предложение. | Уведомления нет (приложение на экране, событие пришло по сокету); «Предложение отклонено» видно в карточке места. |
| T41.6 | Приложение свёрнуто. Мастер → «Запросы» → ответить на запись игрока. | Уведомление «Мастер ответил — Ответ на запись в дневнике», без текста ответа. Нажатие — вкладка «Дневник». |
| T41.7 | Свёрнуто. Мастер открывает слух в открытом городе; затем открывает слух в скрытом месте. | Первый: «<Город> — Новый слух» (у задания — «Новое задание»). Второй: ничего. |
| T41.8 | Свёрнуто. Мастер → «Игра» → «Позвать за стол», затем сразу ещё раз. | Уведомление «Игра начинается — Мастер зовёт за стол» у всех подписанных игроков; второе нажатие — «Не чаще раза в минуту». |
| T41.9 | Мастер включает колокольчик у себя, сворачивает окно. Игрок пишет «Вопрос мастеру»; другой игрок предлагает место. | Мастеру: «Вопрос мастеру — Вопрос от <игрок>» и «Предложение — <игрок> предлагает идти в <место>». Нажатие — «Запросы» / «Карты». |
| T41.10 | Игрок пишет запись «только для меня» и обычную запись дневника без вопроса. | Мастеру уведомлений нет (запрос — только у «Вопроса мастеру»). |
| T41.11 | Игрок выключает колокольчик. | `POST /api/push/unsubscribe`, строка из базы исчезла; уведомления больше не приходят. |
| T41.12 | Игрок в Safari на iPhone (не установлено) нажимает колокольчик. | Подсказка «Добавьте приложение на экран „Домой“…», подписки нет. |
| T41.13 | Запретить уведомления для сайта в настройках браузера, перезагрузить. | Колокольчик перечёркнут, нажатие — «Уведомления запрещены в настройках браузера». |
| T41.14 | Значок на иконке: установленное приложение свёрнуто, мастер отвечает на запись. | На иконке «1» (где API есть: iOS 16.4+, Android Chrome, macOS Chrome/Safari). Открыть «Дневник» — значок пропал. |
| T41.15 | Любой push в DevTools (Application → Service Workers → Push с телом `{"title":"СЕКРЕТ-МАСТЕРА","body":"x","url":"/","tag":"t"}`) — это тест воркера, не сервера; и отдельно: в заметке gm_* написать «СЕКРЕТ-МАСТЕРА» и открыть слух. | Сервер в тело берёт только имена, уведомление о слухе — без маркера. Лог сервера без `GmLeakError`. |
| T41.16 | Удалить подписку в системе (сбросить разрешение) и дать мастеру ответить. | В логе «push: подписка удалена» (404/410), строки в базе нет. |
| T41.17 | `npm run build`. | `dist/sw.js` содержит `importScripts("push-sw.js")`, `dist/push-sw.js` есть; `server/dist/vapid.mjs` собран. |
| T41.18 | Стол (`/table`) запрашивает `/api/push/key`. | 403. |
