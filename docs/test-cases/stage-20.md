# Этап 20 — ручные проверки

Подготовка: `npm run dev`; стол на ТВ или ноутбуке во весь экран (`<IP мака>:5173/table`), мастер на ноутбуке, игрок на телефоне.

| № | Шаги | Ожидание |
|---|---|---|
| T20.1 | Открыть стол. | Тёмный экран своей палитры, сверху тихая строка (комната, связь, «Анимация вкл.»). Пока состояние не пришло, заставка не мигает. |
| T20.2 | Мастер показывает сцену с картинкой, потом другую. | Картинка появляется целиком, без построчной загрузки; старая перетекает в новую около 1,5 с. Картинка медленно наплывает. «Сцена», название и текст появляются по очереди. |
| T20.3 | Сцена без картинки; убрать сцену. | Тёмный фон с зеленоватым свечением; без сцены и противника — «Зеленогорье». |
| T20.4 | Мастер показывает портрет противника, убирает. | Портрет раскрывается из полосы по центру, имя крупно следом; уходит плавно. Сила и заметки на экране не появляются. |
| T20.5 | Игрок бросает «Всем». | Над сценой катится большой кубик (дольше, чем на телефоне, не больше 2,5 с); после посадки плашка «число — исход — имя · d20»; затем число улетает в колонку «Броски». Пока катится — в колонке «бросает…». **Число на кубике = число в колонке и в ленте мастера.** |
| T20.6 | Три броска подряд от разных игроков. | Проигрываются по очереди, колонка сразу показывает все три строки («бросает…» у тех, что ждут). |
| T20.7 | Бросок «Мне и мастеру» у игрока, скрытый бросок мастера. | На столе нет ни кубика, ни строки. |
| T20.8 | «Анимация выкл.». | Кубика, спор, наплыва и переходов нет; броски — сразу плашкой, сцены меняются мгновенно. После перезагрузки — выключено. |
| T20.9 | `/table?lite=1`. | В строке сверху «облегчённый режим»; без 3D, спор и наплыва. |
| T20.10 | Слабый ТВ / DevTools → Performance → CPU 6× slowdown, подождать 5 с. | Стол сам переходит в облегчённый режим, надпись появляется. |
| T20.11 | Мастер: «Показать столу» перегрузку двух персонажей. | Плашки въезжают справа стопкой; «Глаза зеленеют» — жёлтая, «Кожу покрывает изумруд» — зелёная со свечением; через 12 с уходят. |
| T20.12 | Телефон вертикально, `/table`. | Броски сверху (три), сцена внизу во всю ширину, портрет по центру. |
| T20.13 | Тема игрока «Ночь»/«День» на других устройствах. | Стол не меняется. |
| T20.14 | **Утечка.** DevTools стола: Network, WS-кадры. | Ни `СЕКРЕТ-МАСТЕРА`, ни текста мастера к сцене, ни силы противника, ни скрытых бросков. Чанки мастера не грузятся. |
