# Этап 4 — ручные проверки

Подготовка: этапы 1а–3 настроены, `npm run seed:dev`, два игрока с персонажами, мастер на ноутбуке, игроки на телефонах. `npm run dev`.
Разделы мастера: «Игра», «Партия», «Запросы», «Заметки», «Участники».
Проверки с Jev (помечены J) работают, если в `.env.development` включены `JEV_*` и ключ рабочий.

| № | Шаги | Ожидание |
|---|---|---|
| T4.1 | Мастер: у персонажа задать подсказку к скрытой черте, не раскрывая её. Игрок открывает «Карточка», DevTools → поиск маркера. | У игрока «Что-то происходит» с текстом подсказки, без названия и категории. Маркера нет. |
| T4.2 | Мастер: раскрыть черту, потом снять «Раскрыть черту» и стереть подсказку. | У игрока черта появилась, потом исчезла полностью. |
| T4.3 | Мастер: «Партия» → +1 перегрузки трижды. Игрок в DevTools ищет в WS-кадрах `overload`, `eyes`, `Глаза`. | У мастера «Глаза зеленеют». У игрока ни одного кадра про перегрузку. |
| T4.4 | Мастер: «Показать столу». На ноутбуке открыт стол (`/table`, этап 5) и DevTools игрока. | Стол получает только признак («Глаза зеленеют»), без числа. Игрокам не приходит ничего. |
| T4.5 | Игрок: «Дневник» → «Вопрос мастеру» → «Можно узнать, что со мной происходит в лесу?». Засечь время. | У мастера в «Запросах» появляется за секунду, с пометкой «ждёт ответа». |
| T4.6 | Мастер отвечает «Ответить и закрыть». | У игрока под записью «Мастер: …», пометка «вопрос, есть ответ». |
| T4.7 | Игрок: запись «Только для меня». Мастер: «Запросы», снять «только запросы». Мастер в консоли: `fetch('/api/gm/diary').then(r=>r.json())` и поиск текста записи. | Записи нет ни на экране, ни в ответе API. |
| T4.7а | Игрок меняет обычную запись на личную (через повторное сохранение, если появится правка) или удаляет её. | У мастера запись исчезает сразу. |
| T4.8 | Игрок A пытается прочитать дневник B: `fetch('/api/player/diary')` отдаёт только свои; других способов запросить чужой нет. Мастер-API игроку: `fetch('/api/gm/diary').then(r=>r.status)`. | Только свои записи. `403` на мастерский API. |
| T4.9 | Мастер: «Заметки» — набрать текст, подождать секунду, обновить страницу. Игрок: `fetch('/api/gm/notes').then(r=>r.status)`. | «Сохранено», после обновления текст на месте. Игрок — `403`. |
| T4.10 | Мастер в двух вкладках. Во вкладке 1 поменять противника, бросить, поменять перегрузку, ответить на запрос. | Вкладка 2 обновляется сама. |
| T4.10а | Заметки в двух вкладках: набрать текст в первой, дождаться «Сохранено», потом набрать во второй. | Вторая подхватила текст первой. Если писать в обеих одновременно — «В другой вкладке заметки изменились» и выбор версии, ничего не теряется молча. |
| T4.11 J | Мастер: подсказка, которая пересказывает свою скрытую черту почти дословно → «Сохранить подсказку». | Предупреждение «почти раскрывает эту черту», кнопки «Сохранить всё равно» / «Поправить». |
| T4.12 J | Подсказка нейтральная («Тебе снятся странные сны»). | Сохраняется сразу, без предупреждения. |
| T4.13 J | Подсказка, которая описывает другую скрытую черту этого же персонажа. | Предупреждение «похоже, выдаёт другую скрытую черту «…»». |
| T4.14 J | Испортить `JEV_API_KEY`, перезапустить, сохранить подсказку. | «Проверка недоступна», сохранить можно. |
| T4.15 J | Игрок пишет в дневник (не личное) явное проявление своей скрытой черты. | Через несколько секунд у мастера под записью «Похоже, нащупал: «…»». |
| T4.16 J | Игрок пишет личную запись с тем же текстом. | У мастера ничего. В базе: `sqlite3 data/dev.sqlite "select count(*) from ai_judgment where subject_ref = '<id записи>'"` → 0 (id видно в ответе `/api/player/diary`). |
| T4.17 J | Игрок бросает d10 с текстом «Загадываю зелени, чтобы мост выдержал». | В ленте мастера под броском «Похоже на зелёную магию» и кнопка «+1 перегрузки». Нажать — счётчик вырос. |
