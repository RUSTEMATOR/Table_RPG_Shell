# Этап 57 — ручные проверки (атмосфера стола)

Подготовка: `npm run dev` (миграция 0028 применится сама). Мастер — «Стол» → «Атмосфера». Стол — `/table` на ТВ или ноутбуке, звук стола включён.

| № | Шаги | Ожидание |
|---|---|---|
| T57.1 | Мастер: «Дождь». | На столе — косые штрихи дождя и лёгкое затемнение поверх сцены (и карты); через 1–2 с — шум дождя. Лента бросков и плашки поверх дождя, читаются. |
| T57.2 | «Гроза». | Дождь гуще, раз в 7–20 с — вспышка; гром вскоре после начала и потом реже. |
| T57.3 | «Снег», «Пепел», «Туман». | Хлопья вниз; тлеющие искры вверх; медленно плывущие пятна тумана. Звук — ветер (снег, пепел), туман — по времени суток. |
| T57.4 | Время суток: «Рассвет», «Сумерки», «Ночь». | Тёплый, лиловый, тёмно-синий оттенок с виньеткой; плавный переход. Ночь без осадков — сверчки. |
| T57.5 | Звук: «Костёр», «Море», «Тишина». | Треск и гул; волны; тишина (плавное затухание). |
| T57.6 | На столе выключить звук, затем включить. | Фоновый звук гаснет и возвращается. |
| T57.7 | «Анимация выкл.» на столе. | Частиц и вспышек нет, остаётся дымка и цвет времени суток. |
| T57.8 | Перезагрузить стол. | Атмосфера та же (с сервера). |
| T57.9 | Ответ `/api/table/state`. | `atmosphere: {weather, daytime, ambient}`; ничего мастерского. Игроки атмосферу не получают. |
| T57.10 | Мастер на телефоне: «Атмосфера». | Шесть кнопок погоды помещаются в ширину. |
