# Этап 2 — ручные проверки

Подготовка:
1. Этап 1а настроен (`npm run setup:dev`), создано два игрока по приглашениям.
2. `npm run seed:dev` — создаст трёх тестовых персонажей и раздаст свободным игрокам:
   - «Тест: Пример (сид 2026)» — две черты раскрыты, одна намекнута, остальные скрыты;
   - «Тест: всё скрыто (сид 777001)» — шесть черт, все скрыты;
   - «Тест: местная травница» — местный персонаж.
   Во всех мастерских полях стоит маркер `СЕКРЕТ-МАСТЕРА`.
3. `npm run dev`.
