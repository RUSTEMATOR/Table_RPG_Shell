# Этап J0 — песочница Jev, ручная проверка на русском

Открыть: мастер → «Инструменты» → «Песочница Jev» (`/gm/jev`).
Каждое нажатие «Спросить» — один платный запрос (копейки, но без пакетных прогонов).

## Что прогнать руками

Для каждой функции 20–30 своих примеров, записывая в таблицу ниже: ожидание, ответ, уверенность.

1. **Страж утечек.** Взять 3–5 настоящих черт. Для каждой написать:
   - подсказку, которая черту выдаёт (пересказ своими словами, без названия);
   - подсказку-намёк средней силы (отметить черту «намекнута»);
   - нейтральный текст сцены.
   Смотреть «Выдаёт …» (вероятность «да») и для намекнутых — оценку 0–4.
2. **Дневник → черта.** 3–5 скрытых черт, записи дневника: явное проявление, смутное ощущение, запись о другом.
3. **Заявка → бросок.** Заявки: рискованные действия, азартные, разговорные, бессмысленные. С раскрытыми чертами и без.
4. **Зелёная магия.** Сначала поправить определение под канон. Заявки: колдует зелёной магией, другой магией, говорит о зелёной магии, не колдует вовсе.
