# Этап 32 — ручные проверки

Подготовка: `npm run dev`; стол — на ТВ (или ноутбуке со звуком), игрок — на телефоне, мастер — на ноутбуке. Для боя: противник сессии с фигуркой показан на столе, у игрока есть фигурка.

| № | Шаги | Ожидание |
|---|---|---|
| T32.1 | Открыть стол впервые. | В строке сверху «Звук выкл.». Броски идут без звука. |
| T32.2 | Нажать «Звук выкл.». | Кнопка «Звук вкл.». В Network — 17 файлов `/sfx/*.m4a` (или `.ogg`), один раз. |
| T32.3 | Игрок: d20 «Всем» несколько раз. | Звук броска, когда кубик полетел; стук на каждом ударе о пол, громче на сильных; на крите — колокол, на провале и осложнении — глухой удар; на успехе — только стук. Звук совпадает с картинкой. |
| T32.4 | Игрок: «Мне и мастеру»; мастер: «Скрытый». | На столе ни броска, ни звука. |
| T32.5 | «Анимация выкл.» (или `?lite=1`), бросок «Всем». | Без кубика: звук броска и сразу за ним исход (колокол или глухой удар), плашка. |
| T32.6 | Бой: игрок с фигуркой бьёт показанного противника — успех, крит, царапина, провал. | Замах, затем удар (крит — громче и колокол, царапина — тише); на провале — ответный удар противника. Отдельного звука исхода кубика нет. |
| T32.7 | Мастер: сменить сцену на столе; затем «На стол: город». | Шелест страницы; при городе — дверь. Скрыть и показать ту же сцену — шелест только при смене. |
| T32.8 | Перезагрузить стол со «Звук вкл.». | Кнопка «Звук: нажмите» (выделена). Нажать в любое место экрана — «Звук вкл.», следующий бросок со звуком. Нажать прямо на кнопку — тоже «Звук вкл.» (а не выкл.). |
| T32.9 | ТВ-браузер (Samsung/LG) или Safari: всё то же. | Звук играет (m4a). Записать, нужен ли после перезагрузки клик пультом. |
| T32.10 | «Звук вкл.» → «Звук выкл.» посреди броска. | Звук сразу обрывается, дальше тишина. |
| T32.11 | Телефон игрока, экран мастера. | Звуков нет. |
| T32.12 | Прод (nginx): открыть `/sfx/nope.m4a`. | 404, а не страница приложения. |
