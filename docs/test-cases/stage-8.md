# Этап 8 — ручные проверки

Подготовка: `npm run seed:dev`, `npm run dev`. Мастер на ноутбуке, игрок на телефоне.

| № | Шаги | Ожидание |
|---|---|---|
| T8.1 | Мастер: «Заметки» — написать текст. «Игра» → «Сессия» → «Начать новую сессию» → «Точно начать новую?». | «Сессия с <сейчас>», противник пуст. В «Заметки» пустой лист, ниже «Прошлые сессии» с прежним текстом и датами. |
| T8.1а | Нажать «Начать новую сессию» один раз и кликнуть мимо. | Кнопка вернулась к «Начать новую сессию», сессия не сменилась. |
| T8.2 | Две вкладки мастера: во вкладке 1 «Заметки», набрать текст и сразу (до «Сохранено») во вкладке 2 начать новую сессию. | Во вкладке 1 «Началась новая сессия, а здесь остался несохранённый текст.» и выбор: «Перенести мой текст в новую» / «Открыть новую, мой текст выбросить». Молча ничего не теряется и не попадает в чужую сессию. |
| T8.3 | Игрок: «Дневник» → у записи «Изменить» → поправить текст → «Сохранить». | Текст обновился у игрока и у мастера в «Запросах» без перезагрузки. |
| T8.4 | Игрок: обычную запись перевести в «Только для меня». Мастер смотрит «Запросы» и `fetch('/api/gm/diary').then(r=>r.json())`. | Запись исчезла у мастера сразу и не находится в ответе API. |
| T8.4а J | Как T8.4, но сначала дождаться у мастера «Похоже, нащупал». Потом сделать запись личной. В терминале: `sqlite3 data/dev.sqlite "select count(*) from ai_judgment where subject_ref = '<id записи>'"`. | `0`. |
| T8.4б J | Игрок пишет обычную запись с явным проявлением черты и сразу (за 1–2 с) делает её личной. | У мастера запись не появляется снова через несколько секунд, «Похоже, нащупал» нет. |
| T8.5 | Игрок: «Удалить» → «Точно удалить?». | Запись исчезла у игрока и у мастера. |
| T8.6 | Игрок: вопрос мастеру, мастер отвечает. Игрок → «Изменить». | Кнопок вида записи нет: вопрос с ответом остаётся вопросом. Текст поправить можно. |
| T8.7 | Игрок задаёт два вопроса мастеру. Мастер на любом разделе. | В навигации «Запросы · 2». После «Ответить и закрыть» на одном — «Запросы · 1». |
| T8.8 | Мастер: «Партия» → персонаж → «Назад». «Новый» → «Назад». «Песочница Jev» → «Назад». | Возврат в «Партия», «Партия», «Участники» соответственно. |
| T8.9 | **Утечка.** Игрок: DevTools → WS Messages во время T8.1–T8.7. Поиск `СЕКРЕТ-МАСТЕРА`, `notes`, `session`. | Ни заметок, ни сессий, ни счётчиков в кадрах игрока. |
