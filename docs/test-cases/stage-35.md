# Этап 35 — ручные проверки

Подготовка: `npm run dev`. Мастер на ноутбуке — «Активность» (`/gm/activity`, G+A). Игрок 1 на телефоне (Vite 5173 в локальной сети), игрок 2 — на втором телефоне или в другом браузере. В seed-персонажах есть приглашённый, но ни разу не входивший игрок (или создать его в «Участниках»).

| № | Шаги | Ожидание |
|---|---|---|
| T35.1 | Открыть «Активность» до входа игроков. | Все игроки комнаты: серая точка, «не в сети, ещё не входил» (или «был N … назад» по прежнему входу). Мастер и стол в списке не показываются. |
| T35.2 | Игрок 1 открывает приложение. | Через секунду-две: зелёная точка, «в сети», вкладка, открытая у игрока, «уже меньше минуты». В журнале одна строка. |
| T35.3 | Игрок 1 листает вкладки пальцем, затем нажимает на панель вкладок через несколько вкладок. | У мастера — каждая вкладка, на которой игрок остановился; промежуточные при нажатии не мелькают. |
| T35.4 | «Броски» → «Бросить» d20, затем d10. | «Броски — бросает d20», после падения — «Броски»; то же с d10. Подпись броска нигде не видна. |
| T35.5 | «Карточка» → «Оформление»; закрыть; «Добавить вещь»; открыть существующую вещь. | «выбирает оформление», «добавляет вещь», «правит вещь»; после закрытия листа — просто «Карточка». Текст вещи не виден. |
| T35.6 | «Фигурка» → переключать части. | «Фигурка — часть «Волосы»», затем выбранная часть. |
| T35.7 | «Дневник» → «Новая запись» по очереди с видом «Дневник», «Вопрос мастеру», «Только мне»; затем «Изменить» у старой записи. | Всё время одинаково: «Дневник — пишет запись». Ни вида, ни текста, ни «правка». |
| T35.8 | «Карта» → сменить карту; «+ Заметка»; открыть карточку места; войти в город, пройти разделы. | «Карта — Мир / Раздолье / Замёрзшие земли», «ставит заметку», «карточка «…»», «в городе «…», Обзор / место в городе / Слухи и задания / Кто здесь». Текст заметки и поиска не виден. |
| T35.9 | Игрок свернул приложение (на главный экран), через минуту вернулся. | Жёлтая точка «свёрнуто» сразу; в журнале «свернул (…)»; после возврата — снова «в сети» и прежняя вкладка. |
| T35.10 | Игрок перезагрузил страницу. | Статус не мигает «не в сети», в журнале нет «вышел». |
| T35.11 | Игрок включил авиарежим (или закрыл приложение совсем). | Через несколько секунд после разрыва соединения (иногда до ~45 с) — «не в сети, был меньше минуты назад»; через 30 с счётчик растёт. В журнале «вышел». |
| T35.12 | Игрок 1 открыл приложение на двух устройствах, на одном свернул. | Бейдж «2 устройства»; показывается то, что открыто на несвёрнутом. |
| T35.13 | Перезапустить сервер (`npm run dev` заново). | После переподключения игроков статусы вернулись; журнал начат заново. |
| T35.14 | Утечки: у игрока и на столе DevTools → Network → WS. | Событий `gm:presence.changed` нет. Ответы `/api/player/*` и `/api/table/*` без изменений; СЕКРЕТ-МАСТЕРА нигде. Игрок: `fetch('/api/gm/presence')` в консоли → 403. |
| T35.15 | Подмена: у игрока в консоли отправить в сокет `player:activity` с лишним полем или текстом вместо перечисления. | У мастера ничего не меняется; в логе сервера «player:activity: неверный формат». |
| T35.16 | «Активность» на телефоне мастера. | Раздел во вкладках сверху; строки и журнал читаются без горизонтальной прокрутки. |
