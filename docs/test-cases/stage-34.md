# Этап 34 — ручные проверки

Подготовка: `npm run db:migrate` (миграция `0012_npc_model3d`), `npm run dev`. Мастер на ноутбуке (3D-карта: «3D (проба)»), игрок на телефоне в 3D, стол с картой, отправленной из 3D.

| № | Шаги | Ожидание |
|---|---|---|
| T34.1 | Мастер: «Противники» → у противника «На 3D-карте» → «Рыцарь». | Тост «На 3D-карте — Рыцарь»; после перезагрузки выбор на месте. |
| T34.2 | Мастер: «Карты» → 3D → «Фигурка» → поставить этого противника. | На месте жетона — рыцарь на рельефе, ростом с фигурку, с мечом и щитом; подставка и имя — как у фигурок; скрытый — полупрозрачный. Network: `/models/units/knight.glb` один раз. |
| T34.3 | Открыть жетон игрокам; у игрока и на столе — 3D-карта. | Рыцарь виден у игрока и на столе. На пергаменте — фигурка (или буква). |
| T34.4 | Мастер перетаскивает жетон. | У игрока и на столе рыцарь идёт к новой точке (анимация шага), повернувшись по ходу; на месте — стоит. |
| T34.5 | Пройти все 9 моделей. | Каждая загружается и стоит на земле (не висит и не тонет), у варвара топор и щит, у мага посох, у разбойника ножи, у разбойника в капюшоне арбалет; скелеты — без оружия (так и задумано, записать, как выглядят). |
| T34.6 | «На 3D-карте» → «Фигурка». | Везде снова фигурка. |
| T34.7 | **Утечка.** Скрытый жетон с моделью. Игрок: `GET /api/player/maps/<карта>`. | Жетона нет вовсе. У открытого — `model: "knight"`, у жетонов персонажей — `model: null`; ни силы, ни заметок. |
| T34.8 | **Права.** Игрок: `POST /api/gm/npcs/<id>/model3d` `{"model":"knight"}`; мастер — `{"model":"dragon"}`. | 403; 400. |
| T34.9 | iPhone, 3D-карта `?perf=1`: 3–5 моделей рядом, покрутить и подвинуть. | Записать кадры и худший кадр до и после (без моделей / с моделями). В покое карта не перерисовывается постоянно (счётчик кадров стоит). |
| T34.10 | Отряд и персонажи игроков на 3D-карте; бой на столе с противником-рыцарем. | Отряд и персонажи — фигурки; бой — фигурки (как раньше). |
| T34.11 | «Авторы графики». | Упомянуты KayKit Character Pack: Adventurers и Skeletons, CC0. |
