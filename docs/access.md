# Зеленогорье — адреса и входы (dev и QA)

Только тестовые данные dev-базы. Ключи API (Jev, Claude), `.env` и прод-пароли сюда не пишутся и в репозиторий не попадают — они лежат в `~/.config/zelenogorye/` (см. `CLAUDE.md`, правило 9).

## Адреса

| Что | Адрес |
|---|---|
| QA-хост (снаружи, через Cloudflare) | https://qc-zelenogorye.qa-temple-of-serenity.cc |
| Вход | https://qc-zelenogorye.qa-temple-of-serenity.cc/login |
| Игрок / мастер / стол | `/player`, `/gm`, `/table` на том же адресе |
| Локально на Mac | http://localhost:5173 (мастер), http://127.0.0.1:5173 (игрок), http://192.168.0.7:5173 (стол) |
| Витрина компонентов (dev) | http://localhost:5173/dev/ui |
| Проект на Mac | `~/Desktop/Zelenogorie` (git, ветка `main`, удалённого репозитория нет) |

Один браузер = одна сессия на адрес, поэтому для мастера, игрока и стола удобно разные адреса или окна (обычное и приватное).

## Гостевой вход — для проверки интерфейса посторонними

На странице входа: «Посмотреть без входа» → «Мастер», «Игрок» или «Стол». Отдельная «Демо-комната» (код `DEMO26`) с тестовыми данными; рабочую комнату гость не видит, ИИ выключен. Пароль не нужен. Сменить роль — «Выйти».
