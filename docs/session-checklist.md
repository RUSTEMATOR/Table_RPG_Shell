# Чек-лист сессии (для мастера)

Как пользоваться экранами — [manual.md](manual.md). Установка и обслуживание сервера — [ops.md](ops.md).

## За день до игры
- [ ] Выложить все правки: закоммитить → `bash ops/scripts/deploy.sh`. Во время игры не выкладывать без нужды.
- [ ] «Участники» → «Состояние»:
  - «Последний бэкап» не старше суток;
  - nginx «в порядке»;
  - IP Cloudflare обновлены не больше недели назад.
- [ ] У каждого игрока есть персонаж («Партия» → «Персонажи», справа имя игрока). Нужное раскрыто, подсказки сохранены.
- [ ] Игроки, которые будут с нового телефона, получили «Новая ссылка».
- [ ] Картинки сцен загружены заранее («Стол»), тексты для стола прошли проверку.

## За полчаса
- [ ] Mac mini и роутер на питании (ИБП), интернет дома работает: без него игра встаёт и для сидящих за столом.
- [ ] ТВ или ноутбук стола открыт на общем экране, индикатор «На связи». Для Discord — «Анимация выкл.».
- [ ] «Игра» → «Сессия» → «Начать новую сессию» (дважды). Старые заметки уйдут в «Заметки» → «Прошлые сессии», противник сбросится.
- [ ] Ноутбук мастера на питании, вкладка мастера открыта.
- [ ] Игроки вошли, у каждого «На связи». Кто не может войти — «Участники» → «Новая ссылка».

## Во время игры
- Противник для бросков: «Игра» → «Сессия» → «Задать». Когда бой кончился — «Убрать противника».
- Ошибся в броске: «Исправить» под броском в ленте.
- Вопросы игроков — «Запросы · N» в навигации.
- **Обрыв у игрока:** ничего делать не нужно, всё догонится само. «Нет ответа от сервера.» → «Повторить».
- **Стол погас или отключился:** обновить страницу; если просит вход — «Новая ссылка» для стола.
- **Jev или Claude не отвечают:** игра идёт; проверки пишут «Проверка недоступна», решайте сами.
- **Сервер не отвечает** (у всех «Переподключение…» дольше минуты):
  - на Mac `bash ops/scripts/status.sh`;
  - сервер сам поднимается через 10–15 с после падения;
  - если нет — смотреть `~/srv/zelenogorye/logs`.

## После игры
- [ ] Ответить на открытые запросы или закрыть их.
- [ ] Дописать заметки (сохраняются сами).
- [ ] Бэкап сделается сам в течение 30 минут. Перед правками на сервере можно вручную, команда — [ops.md](ops.md), раздел 5.
- [ ] Стол: «Стол» → «Убрать со стола».
