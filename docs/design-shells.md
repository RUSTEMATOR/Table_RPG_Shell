# Оболочки: тема → стиль экрана

Решение Рустема (2026-10-08): у темы не только цвета и украшения, а своя метафора экрана — «оболочка». Книга годится сказке,
но аниме — это манга, киберпанк — интерфейс, Fallout — Пип-Бой на руке. Оболочка задаёт устройство экрана: навигацию,
панели, заголовки, лоток кубика, ленту, шрифты-роли, материал. Тема внутри оболочки даёт палитру, шрифты, набор
украшений (`docs/design-packs.md`). Макеты — на холсте Claude Design «Зеленогорье — сказочный вид».

Правила для всех оболочек:
- Телефон и компьютер — та же оболочка в двух раскладках (на компьютере — разворот: раздел в середине, лоток и лента справа).
- Текст читается: 4,5:1 на фоне панели в каждой теме; эффекты (развёртка, сбой, свечение) — только на украшениях, не на тексте; «Уменьшить движение» выключает анимацию.
- Мастер — оболочка «Книга» в теме «Зеленогорье» (рабочее место, плотнее); стол (ТВ) — своя тёмная сцена, украшения — от темы показанной сцены.
- Оболочка — слой поверх токенов: компоненты те же (`web/src/ui/*`), меняется оформление по `data-shell` на `<html>`.
