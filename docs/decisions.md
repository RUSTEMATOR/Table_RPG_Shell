# Решения

Формат: дата — решение — почему.

## 2026-10-05

- **Разработка на самом Mac mini, в `~/Desktop/Zelenogorie`.** Прод будет жить в `~/srv/zelenogorye/releases/<время>` с симлинком `current` (этап 1б, 7). Desktop для прода не годится из-за ограничений доступа macOS (TCC) для launchd.
- **Dev и прод разделены.** Dev: порт 3001, база `data/dev.sqlite`, env `~/.config/zelenogorye/.env.development`. Прод: порт 3000, env `~/.config/zelenogorye/.env`.
- **Node 24 из nvm** (`~/.nvm/versions/node/v24.13.1`), а не из Homebrew. В plist этапа 1б путь к node указывать абсолютный, из `which node`.
- **Сервер собирается esbuild в `server/dist`**, зависимости остаются внешними, `@zg/shared` вшивается. Dev — `tsx watch`.
- **Один BUILD_ID на сервер и клиент** (`scripts/build.mjs`). Клиент шлёт его в `sync:hello`; при несовпадении перезагружается один раз на версию.
- **Вход.** Приглашение гасится только POST-запросом по кнопке; GET безопасен для превью-ботов. Игрок задаёт 6-значный PIN при входе по приглашению. Вход по коду комнаты: выбор участника из списка (имена игроков и мастера видны тому, кто знает код комнаты; стол в списке не показывается) + PIN или пароль.
- **Rate limit.** 5 неудачных попыток за 15 минут на участника + 50 любых попыток за 15 минут на IP. В памяти процесса, после перезапуска сбрасывается. Следствие: кто знает код комнаты, может временно заблокировать вход конкретному игроку пятью неверными PIN — для домашней игры приемлемо.
- **Мастер входит паролем** (от 8 символов), он задаётся в `npm run setup`. У стола секрета нет: стол входит только по приглашению, мастер может выдать новую ссылку.
- **Предохранитель утечек** (`server/src/visibility/guard.ts`) блокирует ответ не-мастеру, если в нём маркер `СЕКРЕТ-МАСТЕРА` или ключи `gm_*`, `*_gm`, `gmXxx`, `xxxGm`. Следствие для кода: в DTO игрока и стола нельзя называть поля так, даже безобидные.
- **Jev.** SDK `@typesafe-ai/sdk` 0.6.0: параметры клиента `defaultModel` и `retry` (а не `model`/`retries`). Модель закреплена `jev-1.13.0`. `logLevel: 'warn'`, потому что `debug` печатает тела запросов с мастерскими текстами.
- **Мастерские тексты и черты уходят во внешний API TypeSafe** (как и в Claude API). Записи дневника «только для меня» не уходят никуда.
- **Определение зелёной магии для Jev** в `server/src/ai/jev/questions/greenMagic.ts` — черновик, его нужно привести к канону мира. В песочнице его можно править на лету.
- **Известное ограничение:** если дома пропал интернет, игра встаёт и для сидящих за столом — весь трафик идёт через Cloudflare.
