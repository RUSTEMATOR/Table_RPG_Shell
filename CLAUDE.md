# Зеленогорье — платформа для сессий НРИ
Сервис на Mac mini за nginx и Cloudflare: PWA игрока, экран мастера, общий экран /table.

## Стек (менять только с записью в docs/decisions.md)
Node 24 LTS, TypeScript strict, Fastify 5 (только 127.0.0.1:3000, dev 3001), Socket.IO 4,
better-sqlite3 + Drizzle, Zod 4, React 19 + Vite + vite-plugin-pwa, nginx перед Node.
ИИ только на сервере: Claude API (тексты), TypeSafe Jev (суждения, server/src/ai/jev/).

## Команды
npm run dev | build | typecheck (после каждого шага) | db:generate | db:migrate | seed

## Безопасность данных
1. Мастерские данные: character_secret, green_overload, session_note, ai_judgment, поля gm_* и *_gm.
2. Игроку и столу — только через server/src/visibility/*, белый список полей.
3. Каждый DTO игрока/стола: z.strictObject на всех уровнях вложенности, .parse() перед отправкой.
4. Никаких прямых socket.emit/io.emit — только publish(). Предохранитель в publish() и onSend не отключать.
5. Каждый gm:* обработчик первой строкой проверяет role === 'gm'.
6. Скрытые черты не выдают даже своё количество: seq по аудитории, наружу только nanoid, без пропусков в порядке.
7. Записи дневника «только для меня» не видит мастер и не отправляются ни в Jev, ни в Claude.
8. Результаты Jev — только мастеру. Jev советует, состояние игры меняет человек.
9. Не читать, не выводить и не коммитить ~/.config/zelenogorye/ и ключи.

## Процесс
- Работать по docs/plans/stage-N.md; один шаг — один коммит.
- Расхождение с планом: остановиться и описать, не импровизировать.
- НЕ писать тесты и тестовый код, НЕ запускать прогоны ради проверки; проверка — ручные кейсы в docs/test-cases/, их выполняет Рустем.
- Субагентов запускать только когда без них не обойтись. Без эмодзи.
- В конце шага: typecheck и короткий отчёт, что проверить руками.

## Тестовые данные
Во всех мастерских полях seed-персонажей — маркер СЕКРЕТ-МАСТЕРА.
Его появление в ответе игроку или столу — блокирующий дефект.

## Где что
- Мастер-план: zelenogorye-plan.md. Решения: docs/decisions.md. Ручные проверки: docs/test-cases/.
- Dev: `npm run dev` (сервер 127.0.0.1:3001 + Vite 5173 в локальной сети), env — ~/.config/zelenogorye/.env.development.
- Первый запуск dev: `npm run setup:dev`, приглашения — `npm run invite:dev -- --name "Имя"` или экран мастера.
